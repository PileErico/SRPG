| `TerrainDB.gd` | **地形注册表**（仿 ItemDB：`preload`+静态变量单例）：读 `terrains.json`，做编辑器/战斗共用的 **O(1) 查表**（`palette()`/`entry_for(tile)`/`color_of`…） |

## 应用框架：开始菜单 + 沙盒模式（布置 → 开始游戏）🔒
> 整个工程是**游戏本体**，不再只是沙盒/编辑器。各功能挂在开始菜单下；跨场景传参用静态单例（仿 DB，不用 autoload/class_name）。

**场景流**：`StartMenu`（**主场景**，12 按钮全启用：战役·新开局 / 战役·继续〔无档灰〕/ 编辑器(编辑·试玩) / 沙盒模式 / 地图编辑 / 物品·角色·技能编辑器〔技能⇄效果库互切〕/ 外观·地块工坊 / 设置〔SettingsOverlay：音频·分辨率，GameSettings 持久化 user://settings.cfg〕/ 退出）→
- 「沙盒模式」→ `MapSelect`（列 `maps/*.json`，选一张/双击）→ `Sandbox`（带所选地图，停在**布置阶段**）。
- 「地图编辑」→ `MapEditor`（编辑器顶栏新增「主菜单」按钮返回，带未保存确认）。
- 切换全走 `change_scene_to_file`；地图路径经 `SandboxConfig.map_path`（静态变量，跨场景存活）传递，空则用 Sandbox 默认 `MAP_PATH`（**故 `.bat` 直接跑 `Sandbox.tscn`/`MapEditor.tscn` 仍可用**）。

**沙盒两阶段**（`Sandbox.gd` 上 `var phase`：`deploy`/`battle`）：
- **deploy（布置）**：`_ready` 只 setup（地形/地图/UI），**不自动 `_spawn_units`/`_start_battle`**；`units`（=上场参战集）由布置操作填。回合/AI 整条链不触发（关键：不调 `_start_battle`，且 `_begin_active_turn` 顶部 `phase!="battle"→return` 双保险）。
- **battle（战斗）**：`begin_game()`（开始游戏按钮）→ 已布置 `units` 非空校验 → `phase="battle"` → 收起底部栏/编辑器 → 复用 `_start_battle()`，回合按速度序开跑、AI 正常。
- **退出战斗 / 重开**：战斗期右栏「⏹ 退出战斗（回布置）」按钮、或胜负后按 **R** → `exit_battle()`：场上单位收回待命（**`roster` 保留**、回满生命）、回合状态归零、回到 deploy 重新布置。挂起的敌方 AI 协程靠 `phase=="battle"` 兜底立即收手。

**底部「可用单位」横栏 `RosterBar.gd`**（布置期；战斗期隐藏）：管理 **roster（已准备单位）**——
- 末尾 **`＋`** → 菜单选 **内置原型**（`unit_prototypes.json`：比路兹/维肯/帝国步兵/轻步兵 + 空白单位 5/5/5/5）/ **已存预设** / **★默认阵容（全部加入）**；选中即把该配置加入 roster（**待命**，未落子）。
- 每个单位槽：**拖到地图空格 = 布置/移动**（拖拽源＝`RosterSlot`，落点＝`SandboxCanvas._can_drop_data/_drop_data` → `host.deploy_drop` → `place_roster_unit`）；**点选 = 右侧编辑**；**✕ = 移出 roster**；槽下显示「待命 / 在(x,y)」。**地图上右键已布置单位 = 撤下回待命**（`deploy_right_click`→`recall_roster_unit`）。
- **部署区限制**（地图 `kind:"deploy"` 区域 → `_deploy_cells`）：布置阶段画布**蓝色高亮部署区**（`SandboxCanvas._draw_deploy_zone`）；**玩家方（我方/友方）单位只能放区内**，区外提示「只能放部署区内」；**敌方/中立、以及没画部署区的图＝任意放**（不挡调试 / 关卡摆敌）。已 headless 验证（区外拒、区内准、敌方不受限）。

**右侧「单位编辑器」`DeployPanel.gd`**（布置期；战斗期整面板隐藏）：编辑底部栏选中的那个单位——
- 名字 / 阵营 / 等级·经验 / 种族底值+差异覆盖（面板级差异编辑待做）/ 可改基础属性（`StatMeta.EDITOR_STATS` 全列）/ 特性（`TraitDB`）/ 技能学/升（`SkillDB`）/ 物品装备（`ItemDB`，**`equip` 失败提示需求未满足**）。
- **「保存为预设」**：把当前单位的**配置**（属性/特性/装备/技能/阵营，**不含场上位置**）存进 `user://unit_presets.json`（命名、同名覆盖）；之后底部栏 `＋` 菜单可再取。**「开始游戏」** → `begin_game()`。

**roster / 预设 API（`Sandbox.gd`）**：`roster`（全部已准备单位）；`add_roster_unit(proto)`（待命）/`place_roster_unit`/`recall_roster_unit`/`remove_roster_unit`/`is_placed`/`select_roster_unit`；`make_unit(proto,faction,col,row)`（统一造单位工厂，支持 `stats` 覆盖 + `skills` 字典等级）；`_unit_to_proto`/`save_unit_preset`/`load_unit_presets`/`roster_sources`。**预设＝单位配置，与场上位置无关**。

**新增文件**：`StartMenu.gd/.tscn`、`MapSelect.gd/.tscn`、`SandboxConfig.gd`（静态 `map_path`）、`DeployPanel.gd`（单位编辑器）、`RosterBar.gd`（底部可用单位栏）、`data/unit_prototypes.json`。

**已验证（headless）**：启动停 deploy（roster/units 空）→ `＋`加空白+维肯（待命，col=-1）→ 拖放落子/撤下/再落子（units 增减正确）→ 维肯装备/特性生效（atk 9、双手占 2 槽）→ **存预设→重读→`make_unit` 复原**保真（特性/装备齐全）→ `begin_game` 翻 battle（turn_order 正确）。`RESULT=PASS`；四场景 headless 0 报错。

## Meta 层 M3：EventEngine 事件引擎（2026-07-02 ✅）
> 需求 §1.2：在既有触发器框架上生长、不另起炉灶。

- `EventEngine.gd`（DB 范式）＝**when/do 事件单一源**，三块职责：
  - **① 动作元数据注册表**：id/中文名/参数字段（`fields`: key/label/type/default/min/max）。**运行时执行与编辑器表单同源**——加新动作只登记 `ACTIONS` + 宿主实现原语，编辑器菜单/缺省值/表单自动跟上（编辑器/运行时动作表不分叉）。
  - **② 执行**：`execute_action` 参数解析（默认值/clamp）单一处 → **宿主原语转发**（`event_log/event_activate_aggro/event_set_weather/event_spawn_unit`，鸭子类型 + `has_method` 守卫——宿主没实现的能力＝警告跳过，大地图宿主可不支持战斗动作）。
  - **③ 评估**：`check_enter_region`（战斗现状迁入）/ `check_enter_tile`（col/row 缺省＝任意格；大地图 M4 主用）/ `check_timer`（世界时间节拍 `every_hours`，跨大步只触发一次不补触发）。
- **闸门体系**：硬闸（once/fired → 冷却 `cooldown_hours` → 全局间隔 `global_gap`+`GLOBAL_EVENT_GAP_HOURS=24` 占位）→ 软闸 `chance`（0~100 概率，BB 式；timer 的 chance 不中＝本节拍已消耗）。**once 缺省按事件类型**：enter_*＝true（现状契约）、timer＝false（周期语义）。
- **fired/冷却状态两层分离 🔒**：战斗局部＝Sandbox `_fired_triggers`（每战清零、无冷却，评估传 ws=null）；世界持久＝`WorldState.event_fired/event_timer_last/event_cooldown_until/last_world_event_hours`（随档落盘，读端 int 化兜底）。
- **Sandbox**：触发器评估/执行全走 EventEngine，本地只留四个宿主原语；AI 走位同样过评估钩子（`by_faction:"any"/"enemy"` 覆盖 AI 侧移动）；`event_spawn_unit` 战中随即 `_recompute_vision()`（新单位迷雾态即时正确）。
- **MapEditor**：动作菜单/缺省值/参数表单**注册表数据驱动**（`_build_action_field` 控件工厂：text/int/proto/faction/weather 五型）。

**已验证（headless）**：`tools/test_eventengine.gd` 全 PASS（注册表/执行转发含守卫/enter_region·enter_tile·timer 评估/闸门/事件状态存档往返）。
