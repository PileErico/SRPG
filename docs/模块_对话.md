## ✅ 已实现

### 功能

**数据（`data/dialogues.json`＝对话单一源；schema 同步维护于其 `_note`）**

| 结构 | 字段 | 语义 |
|---|---|---|
| dialogue | `id,label,nodes[]` | 首节点＝`nodes[0]`（入口约定）；坏 id/空对话＝警告＋直接 finished |
| node | `id,speaker,side,portrait?,text` ＋ `next` 或 `choices` | 无 choices＝纯演出，点击任意处推进 `next`；有 choices＝分支（点击不推进、必须选） |
| choice | `text,next,set_flags?,rep?,actions?` | 选中先落效果再跳转：`set_flags` 写 `ws.flags`；`rep`＝`{faction:delta}` 经 `FactionDB.add_rep` 累加（钳 [-100,100]）；**`actions`＝结果动作数组（2026-07-19）**——与触发器 do 同一张 EventEngine 注册表（给物品/给钱/设flag/改声望/开战斗/连锁对话…），按开对话宿主的 `event_*` 原语执行（无 ws 也走、宿主缺原语＝警告跳过、无宿主＝警告跳过） |

- 示例数据：`dlg_merchant`（纯演出，大地图游商触发器）/ `dlg_elder_astra`（分支 set_flags＋rep empire±，挂阿斯特拉城「交谈」）。

**DialogueUI（通用对话控件，一份三场景共用）**
- **播放核心 ⟂ UI**：`start/advance/choose` 纯逻辑（headless `new()` 即测、不进树 `_ready` 不跑，UI 刷新全 null 守卫）；UI 进树 `_ready` 才建。
- UI＝全屏模态吞输入：压暗层＋底部对话条＝左右立绘（说话方点亮、另一侧记忆上次立绘变暗〔VN 惯例〕、右侧镜像）＋说话人＋正文＋选项按钮/「▼ 点击继续」。
- 效果落点 `ws`＝WorldState；**无档（纯沙盒）＝效果跳过仅警告**；结束发 `finished` 信号自毁。

**三触发场景（唯一接口＝EventEngine `dialogue` 动作 → 宿主原语 `event_dialogue(id)` 单一缝）**

| 场景 | 接线 |
|---|---|
| 大地图事件 | `Overworld.event_dialogue`；行进中触发＝`_travel` 暂停 `await finished` 播完再走 |
| 地点交谈（据点 NPC） | 地点面板「交谈」直调（`locations.dialogue_id`）→ [模块_营地后勤.md](模块_营地后勤.md) M7 |
| 战场内（火纹式） | `Sandbox.event_dialogue`（需求预判「唯一有额外接口成本」的场景，实际＝一个原语十行） |

- EventEngine 注册表加 `dialogue` 动作 → 编辑器触发器表单自动跟上（注册表数据驱动，零编辑器改动）。

**对话编辑器（`DialogueEditor.gd/.tscn`，2026-07-19）**
- 双宿主一份代码：StartMenu「💬 对话编辑器」独立场景（返回主菜单）/ MapEditor 触发器「开对话 ✎」**浮层内嵌**（`embedded=true`，关闭发 `closed`→触发器下拉即时刷新；浮层开着时地图快捷键休眠）。
- 左栏＝过滤＋对话列表＋新建/复制/删除；右栏（form_scroll 定宽）＝对话 id·名称 → 节点序列（行标 `→next`/`⑂分支`/`■结束`；增删上移下移，**nodes[0]＝开场**）→ 节点表单（id/说话人/立绘位置/立绘选图＋预览/台词多行 wrap/推进目标下拉）→ 玩家选项（文本/跳转下拉/**结果动作**＝`EditorUI.event_action_menu`+`event_action_field` 注册表驱动/删除）。
- 便利与守护：新增节点自动接上一末节点的空 next（顺撰免手连）；**节点 id 改名自动同步全对话 next/choices.next 引用**；删除节点清空指向它的跳转；保存前 lint（id 重复/悬空跳转＝警告不拦存）；脏跟踪（● 保存钮黄字）＋离开守卫（不保存离开＝`DialogueDB.reload_data()` 回滚 live 表）。
- 写盘＝`DialogueDB.save()`（保留顶层 `_note`/`format_version`；`reindex()` 重铸 by_id——对话 id 是触发器引用键，改名即时生效）。

**布局守则 ⚠️**：DialogueUI `_ready` 铺满用 `set_anchors_and_offsets_preset`（已进树的控件须锚点与 offsets 一起设才能真正撑开）。

### 代码架构

| 类/文件 | 职责 | 关键成员 |
|---|---|---|
| `DialogueDB.gd` | 对话注册表（DB 范式 preload＋static）＋编辑侧写盘 | `all_dialogues`（live 引用）/`dialogue(id)`/`node(dlg,node_id)`/`first_node`/`reindex`/`save`（保 `_root` 顶层字段） |
| `DialogueUI.gd` | 播放核心＋全屏模态 UI＋选项效果 | `start(id,ws,host)`/`advance`/`choose(i)`/`is_active`/`current_node`·信号 `finished`（自毁）；host＝结果动作执行宿主 |
| `DialogueEditor.gd/.tscn` | 对话可视化编辑（双宿主：独立场景/浮层） | `embedded`/`select_dialogue`/`_rename_node`（引用同步）/`_lint`·信号 `closed` |
| `data/dialogues.json` | 对话单一源 | schema＝`_note` |
| `EventEngine.gd` | `dialogue` 动作注册（`dialogue` 字段类型＝下拉）；choice.actions 同表执行 | `execute_action`→宿主转发 |
| `EditorUI.gd` | 动作字段/菜单渲染单一实现（触发器 do 表单与对话选项结果共用） | `event_action_field`（text/int/proto/faction/weather/dialogue）/`event_action_menu` |
| `Overworld.gd` / `Sandbox.gd` | 宿主原语（new＋add_child＋start(id,ws,self)） | `event_dialogue(id)`（大地图行进 await / 战场内） |
| `FactionDB.gd` | 选项 rep 唯一写口 | `add_rep`（钳制/默认值在它那）→ [实现现状.md](实现现状.md) M9 |
