# 编辑器创作路线（✅ 主体完成，留前瞻 schema + 决策）

> 「地图编辑器 × 战斗沙盒 → 游戏内置编辑器」的规划文档。**四图层关卡创作 + 双模式试玩已完成**（实录见 [实现现状.md](实现现状.md)）；本篇现留 **定位 🔒 + 决策状态 + 前瞻 schema 草案**。架构级约定见 [架构.md](架构.md)。

## 编辑器 ≠ 沙盒（定位 🔒）
两者**本质不同、不揉成一个**，但**共用底层**（Unit / 物品 / DB / 画布基类）：
- **编辑器** = 创作「可玩的关卡」（authoring）：地形 + 这一关的单位 + 触发器 + 目标。
- **沙盒** = 自由测试场（testing）：任意召唤单位/物品验证机制手感，维持独立身份。
- 编辑器「试玩本关」用内存直传跑当前关卡；沙盒的自由测试是另一个入口，不混。

## 已完成（详见 [实现现状.md](实现现状.md)）
`MapIO` 统一读写 → 单位进地图（schema v3 `units`）→ `Game.tscn` 双模式（✎编辑/▶试玩）内存直传 → 四图层齐（地形 / 区域〔含 `kind` 部署·触发〕/ 单位〔含 placed 深编 via `UnitFactory`〕/ 触发器）→ 全局地形数据（`TerrainDB` 写回 `terrains.json`）+ 图级 `terrain_overrides` → `ItemEditor`（武器/防具/饰品，写回 `res://data/`）。

## 地图 json schema（现状 + 前瞻字段）
> 兼容套路：**加字段 + 读端 `.get(key, default)` 兜底**，旧图零影响。`format_version` 仅人读标记。坐标序对照见 [架构.md](架构.md)。

```jsonc
{
  "format_version": 3,
  "map_type": "battle",                                          // overworld/battle（缺省 battle）
  "tiles":   [ [ {"terrain":"plain","variant":"grassland"} ] ],   // [row][col] 行优先
  "regions": [ {"id","label","color","kind":"aggro|deploy","cells":[[x,y]]} ],
  "units":   [ {"proto":{/* UnitFactory.unit_to_proto 输出 */}, "col":10, "row":7, "faction":"enemy"} ],
  "triggers":[ {"id","label",
     "when":{"event":"enter_region|enter_tile|timer", ...闸门 once/chance/cooldown...},
     "do":[ {"action":"spawn_unit|activate_aggro|show_message|set_weather|dialogue|start_battle|add_rep|set_flag", ...} ] } ],
  "terrain_overrides": { "forest": { "move": {"cost": 3} } },     // key="terrain/variant"，只覆盖本图
  "environment": { "time":"night", "weather_table":[{"weather","weight","min_rounds","max_rounds"}] },
  "locations": [ {"id","type","label","col","row","battle_map?","dialogue_id?"} ],

  // ===== 前瞻草案（未做）=====
  "effect_templates":  { "tpl_burning": { "label":"燃烧", "tags":["flammable","hazard"],
                          "effects":[ {"name":"灼烧","when":{"occupant_lacks_tags":["fire_immune"]},
                                       "grant":{"stat":"HP","layer":"dot","percent":-5,"nature":"debuff"}} ] } },
  "cell_tags": { "10,7": ["on_fire"] }                            // 远期：实例级 tag（稀疏 key="x,y"）
}
```
