## 心智模型
- **属性**＝能被加减乘的**数值**（HP、攻击、移动…）。
- **tag**＝是否属于某类的**布尔标签**（火、重甲、飞行、中毒…）。
- **强化 / 效果 ＝ 条件（查 tag 或属性）→ 改动（改属性 / 加减 tag）**。
- 养成＝永久改动；战斗内 buff/环境＝本战改动；战斗交互＝即时改动。三者共用同一套「修正管线 + tag 判断」，效果全做成数据。
- 单位 / 地块 / 效果**共用同一张 tag 词表**，互相可查。

## 第一层属性（已定，纯物理）

> **口径标注**（沿用「修正三层」）：
> - **面板**：单位基础值。下列都是面板属性，**默认值可以是 0**——凡战斗数值 = 面板(可为0) + 修正，体系统一，不区分“天生有的”和“只能 buff 给的”。
> - **调整值（补正）**：可**固定**、可**百分比**；其**百分比基于基础面板**计算（例：`闪避 ×(1+Σ%) + Σ固定`，固定值不被百分比放大）。
> - **效能**：作用在派生结果上的最终乘数层，**通常以百分比表达**（如 +15%→×1.15、−15%→×0.85），同结果连乘。

### 进攻面板
| 属性 | 说明 |
|---|---|
| 攻击 ATK | 物理伤害基数 |
| 命中 ACC | 命中判定（vs 闪避，配地块 hit_factor） |
| 暴击率 | 触发暴击的概率（默认可为 0） |
| 暴伤倍率 | 暴击触发后的增伤倍率（基础值待定，如 1.5×） |

### 防御 / 生存面板
| 属性 | 说明 |
|---|---|
| 生命 HP | 归零阵亡 |
| 闪避 EVA | 规避，降低对方命中 |
| 格挡率 | 触发格挡 / 招架的概率（默认可为 0；多由盾 / 武器提供） |
| 格挡性能 | 格挡触发后的全域百分比减伤 |
| 人抗（通用） | 减「进血量」的伤害；挂在人身上。属性分项（火 / 冰…）随元素系统（第二层）接入 |

### 行动面板
| 属性 | 说明 |
|---|---|
| AP | 时间预算，基础 2（见「行动经济」） |
| 移动力 | 一次移动动作买到的移动点数（移动效率） |
| 速度 Speed | 出手顺序（按速度从大到小；同速玩家优先） |

### 来自装备（不是人自带）
- **护甲池 + 甲抗（通用）** ← 防具：护甲先于 HP 承伤、不分部位（破甲流成立）；甲抗减「进护甲」的伤害（和人无关）。属性甲抗随元素系统接入。
- **基础攻击 skill** ← 武器（携带攻击 / 命中补正）。

**移动型（tag，不是数值）**：地面 / 飞行 / 灵体 —— 写在 `Unit.tags`，决定怎么读地块的 `move`（通行性 `passable_by` + 成本 `cost`/`tag_cost`）与地块效果（如森林对飞行态不生效）。地块属性 **tag 驱动**：见 [实现现状.md](实现现状.md)「战斗属性」🔒。

## 回合结构（已定 🔒：round/turn 双层 + 速度行动序列）

### round / turn 双层
- **turn（小轮次）**：单个单位的一次行动窗口，各算各的。单位结束行动 = 一个 turn 结束。
- **round（大轮次）**：场上所有存活单位各完成一次 turn。
- **单位级效果**挂 turn 边界：DoT 结算、自身状态时长递减，都在该单位 `OnTurnEnd`。
- **场级效果**挂 round 边界：如全体回能，在 `OnRoundStart` / `OnRoundEnd`。
- **不变量**：每单位每 round 恰好一个 turn（被眩晕则跳过）。**时长一律按 round 计数**。
- “急速 → 本 round 额外行动”是**未来机制，现在不做**；真做时再把时长改成按 turn 计。

### 出手顺序 = 速度行动序列（不用 AV，直接比速度）
- 屏幕上显示**行动序列**：本 round 尚未行动的单位，按**速度从大到小**排列。
- **同速 → 玩家优先**（玩家单位排在同速敌方之前）。
- **同速的多个玩家单位**：都可行动，玩家**随时自由选择**先动哪个（同速簇内自由编排）。
- 跨速度严格按速度（更快的敌人会先于你较慢的单位行动）。
- 单位结束 turn → 标记已行动、移出序列，取序列最前的下一个。

### turn 结束
- 默认**玩家显式结束**：点击地面弹出菜单，最后一项「结束回合」（火纹式）。
- 设置开关：**无可用 AP 时自动结束 turn**（玩家可启用 / 不启用）。

### 延后（特定能力，非通用机制）
- 不是人人能延后；**延后是某些单位的特定能力**。
- 机制：**降低自身速度 → 立刻重排行动序列**，于是本 round 排到更后、稍后再动（turn 未结束，带剩余 AP）。
- 待定：延后的降速是仅本 round 还是持续（默认仅本 round 用于重排）。

## 行动经济：单 AP + 移动力（已定 🔒）
> 心智模型（桌游式）：一个 turn = 一段**固定时间**。**AP = 这段时间的预算**（用它完成的事）；**移动力 = 单位时间内能走多远**（移动效率）。两者解耦——同花 1 AP，骑兵比步兵走得远。急速（动作如潮）= 未来给「+AP」，即同样时间做更多事。

- **单一 AP 池**：每 turn 开始刷新到上限（基础 **2**）；不结转、用不完作废。攻击 / 技能 / 道具 / 移动都从这一个池花 AP。（延后自身不结束 turn → 不刷新 AP，带剩余 AP 续动。）
- **移动 = 一个动作**：选择移动 → **立即扣 1 AP**（不论之后实际走多远，这 1 AP 都已消耗），同时获得 **移动力** 点「移动点」。
  - 移动点是回合内预算：可**分批花、与其它动作交错**（走一段 → 攻击 → 再走剩下的），用完为止；零头到 turn 末作废。
  - 移动点支付地块 `move_cost`（草原 1 / 森林 2 / 山地 3…）。
  - **没有保底免费移动**：要移动就得花这 1 AP 的移动动作。
- **AP 富余可再买一次移动**（再花 1 AP 得一批移动点）→ 单位**最大位移 = AP × 移动力**（全投移动）。
- **单向自动成立**：移动点只买移动、花了不退，天然不可反向（不能存着去多打）。
- 示例·骑兵（AP 2、移动力 6、攻击设 1 AP）：
  `选移动(−1AP) 得 6 点 → 走 4 贴近 → 攻击(−1AP) 砍 → 走剩 2 拉开`。打带跑成立，机动性 = 移动力越高、一次移动动作的点数越多。

## 护甲与生命（BB 式）
- 单位有 **HP** 与 **护甲值** 两条。受击时**先扣护甲，破甲后扣 HP**。
- 不分部位（无头/身分离）。
- **穿甲（破甲）是特定 skill 的效果**，不是通用属性（详见“攻防计算”）。

## 攻防计算（修正三层 + 命中 + 伤害）

### 修正三层（通用架构，所有战斗数值共用）
1. **面板 (stat)**：单位自身基础值。
2. **补正 (modifier)**：**逐属性**，分两种、都相对**基础**计——
   - **百分比补正**：彼此相加（20%+20%=40%）→ `×(1+Σ%)`；
   - **固定补正**：彼此相加 → `+Σ固定`；
   - → 某属性调整后 = `面板 ×(1+Σ百分比补正) + Σ固定补正`（例：基础闪避 ×1.4 + 20；固定值不被百分比放大）。
3. **效能 (multiplier)**：作用在**派生结果**（命中率 / 伤害 …）上的最终乘数层，**通常以百分比表达**（如 +15%→×1.15）；同一结果的所有效能**连乘**。
   - “命中效能”（攻方抬升，如 +15%→×1.15）与“闪避效能”（守方压低，如 15%→×0.85）是**同一层、按来源口头区分**，一起连乘；地块 hit_factor 也是其一。
- 补正通常来自当前 skill；效能来自 skill / 地形 / buff；buff 可给补正或效能。

### 修正 = 对象（不是裸数字）
- 每条 补正 / 效能 是一个**对象**：携带 数值、层（补正% / 补正固定 / 效能）、**载体（挂在谁身上）**、**buff/debuff 性质**、来源、时长（按 round）。
- 结算时按管线合并相乘；但**载体与 buff/debuff 性质必须保留**——数学等价不代表游戏等价：
  - “我 +15% 命中”（自身 buff）与“敌 −15% 命中效能”（敌身 debuff）命中率相同，但 驱散/净化、“对中 debuff 者增伤”、免疫 等机制会区别对待。
- 这就是 tag / 效果系统的根基：效果 = 条件 → 改动，改动以对象形式挂在载体上。

### 判定序（已定 🔒）：命中 → 格挡 → 暴击
- 攻击按序 roll 三道判定，**判定与结算解耦**：每道判定只决定“往哪个池子注入一个修正对象”，数值留到伤害结算统一算。
  1. **命中**（先判，未命中即结束）。
  2. **格挡**（守方）：roll 中格挡率 → 向【减伤池】注入一条「格挡性能」。
  3. **暴击**（攻方）：roll 中暴击率 → 向【增伤池】注入一条「暴伤倍率」。
- 判定型机制统一拆成 **触发率 + 触发效果**（两个独立属性，可分别养成 / 堆叠）：

| 机制 | 触发率 | 触发效果 |
|---|---|---|
| 格挡 / 招架（同算法、别名；同时只一条生效，**取高**） | 格挡率 | 格挡性能（全域百分比减伤） |
| 暴击 | 暴击率 | 暴伤倍率（增伤，多来源**加算**） |

### 命中判定（已定 🔒）
- `命中调整 = 面板命中 ×(1+Σ%命中补正) + Σ固定命中补正`
- `闪避调整 = 面板闪避 ×(1+Σ%闪避补正) + Σ固定闪避补正`
- `基础命中率 = 命中调整 − 闪避调整`（百分比尺度；面板为百分制）
- `命中率 = clamp( 基础命中率 × Π命中效能 , 5%, 95% )`
  - **Π命中效能** = 攻方命中效能、守方闪避效能、守方所在**地块效果**贡献的闪避效能 … 同桶连乘（命中 / 闪避效能同层、按来源区分）。
- 例：基础命中率 100%，命中效能 +15% 且 闪避效能 15% → `×1.15×0.85 ≈ 97.75%` → 钳制 95%。
- 树林 = 地块效果「森林掩蔽」给占据者 +15% 闪避效能（= 敌命中 `×0.85`），仅对**地面态**目标生效（飞行态不享受）；**伤害结算时惰性读取**所在地块 `effects`，不材质化成持久 buff。

### 攻方输出伤害（已定 🔒）
```
输出伤害 = ( 攻击 + 攻击调整 ) × 暴击伤害倍率 × 攻击效能
```
- **攻击调整**：百分比（以**基础攻击面板**算，和命中 / 闪避同口径）+ 固定，整体加到攻击上。
- **暴击伤害倍率**：多来源**加算**；未暴击 = 1；同名 buff 不叠加（id / tag 去重）。
- **攻击效能（最终增伤）**：多条**乘算**（连乘）。
- 三层合并规则一锤定音：补正%（基于基础面板、相加）/ 暴伤（加算）/ 效能（乘算）。

### 攻击来自武器（已定 🔒）
- 玩家**基础攻击 = 所装备武器的基础 skill**（携带该攻击的命中 / 伤害补正）。
- 换武器 = 换基础攻击 skill。单位的 命中 / 攻击 面板是底，武器 skill 提供补正。

### 转换 / 分流层（已定 🔒，增伤后、减伤前）
- 输出伤害先成一个总数；进减伤前可被拆成带 **(通道, 属性)** 标签的分量，每个分量各自走减伤链。
- **附魔类**：按比例转成别的属性（如 50% 物理 + 50% 火焰）。
- **穿甲类**：按比例 `p` 拆成「对人部分」与「对甲部分」（走各自通道的抗性）。**穿甲 = 特定 skill 才有，普通攻击无穿甲。**
- 两类可叠加组合（最终每个分量都带 (通道, 属性) 标签）。

### 护甲与抗性（已定 🔒）
- 防具**不给笼统防御力**，只有两条基础属性：
  - **护甲（池）**：等效血量的承伤池；受击**先扣护甲，破甲后扣 HP**。
  - **护甲抗性（甲抗）**：护甲承伤时的减免系数；可含**属性甲抗**（火甲抗…）；属于防具、**和人无关**。
- 抗性分两套命名空间，各管一条通道：

| | 挂在 | 减免 | 子项 |
|---|---|---|---|
| **甲抗** | 护甲（和人无关） | 进**护甲**的伤害 | 通用 + 各属性 |
| **人抗** | 角色本人 | 进**血量**的伤害 | 通用 + 各属性 |

- buff 明确标注强化「人」还是「防具」；**对人**的抗性 buff 才减血量伤害。
- **无甲 = 无甲抗**（甲抗是防具属性，没甲就直接走人通道）。
- **破甲** = 某些 skill 造成伤害时**额外再对护甲打一份伤害**（加伤形式，不是“清除抗性”）。

### 减伤链（已定 🔒，全乘算）
- **全域减伤** `G = (1-格挡性能) × 减伤效能`：格挡性能、减伤效能均**全域**，对人 / 甲两通道都套；只有**抗性**按通道各取（甲抗 / 人抗，按分量属性取对应那条）。减伤效能为乘算。
- **固定减伤**：在**最后**做减法，分 **甲固减 / 人固减** 两套，各减各通道；封底 0（不能负）。

### 伤害结算（已定 🔒）
- **溢出不浪费**：一击打爆护甲，超出池的部分落到人身上，**要再过人抗（+ 人固减）**——即溢出被甲、人两层都减。
- 每个伤害分量各跑一遍：

```
输出 = 攻击面板 × 技能伤害系数 × 暴击倍率 × 攻击效能
G    = (1 - 格挡性能) × 减伤效能           ← 全域，整击只算一次

【非穿甲分量 → 先进甲】
  到甲 = max(0,  输出 × G × (1 - 甲抗[属性]) − 甲固减 )
  若 到甲 ≤ 护甲池:  池 -= 到甲
  否则(破甲):       溢出 = 到甲 − 池;  池 = 0
                    到血 = max(0,  溢出 × (1 - 人抗[属性]) − 人固减 )
                    HP -= 到血

【穿甲分量(比例 p)】
  人部分 = 输出 × p     → 到血 = max(0, 人部分 × G × (1 - 人抗) − 人固减) → HP
  甲部分 = 输出 × (1-p) → 走上面「非穿甲分量」的甲流程

【无护甲时】 直接走人通道：到血 = max(0, 输出 × G × (1 - 人抗) − 人固减)
```

- **攻击面板 / 技能伤害系数（🔒）**：`攻击面板 = effective_stat("atk")`（已含装备/buff 加值）。**技能伤害系数** = 每个攻击/技能自带的乘率（武器的基础攻击也是 skill）；普通单体 ≈ 1，**AoE / 多目标通常 <1**（如「突刺·龙枪」打一条直线两格 = `0.85`）。系数、暴击倍率、攻击效能三者均**乘算**。（旧写法「攻击 + 攻击调整」的加算调整已并入攻击面板，由修正管线产出。）
- **验算**（输出 50，甲抗 50%，护甲池 20，人抗 20%，G=1，固减=0）：
  `到甲 = 50×0.5 = 25 → 25 > 20 破甲，溢出 5，池→0 → 到血 = 5×0.8 = 4 → 护甲 0 / HP −4`

## tag 体系
1. **特性 tag（驱动协同 / 养成）**：元素(火/冰/雷/光)、护甲类(重甲/轻甲)、种族(人类/亡灵/机械/野兽)、距离(近战/远程)、移动(飞行/灵体)。→ 支撑“所有亡灵 +X”“对重甲 +Y 伤害”这类强化。
2. **状态 tag（临时增减益）**：着火/中毒/眩晕/减速/护盾/嘲讽/狂暴…。→ 与地块着火、效果系统共用判断。
3. **移动型 tag**：地面/飞行/灵体（见上）。
4. **阵营立场 tag**：`player` / `ally` / `enemy` / `neutral` —— 决定敌友判定、出手优先、AI、范围筛选（友伤/群体目标）。真值挂在 `Unit.tags`，`Unit.faction` 是便捷读写口（改 faction = 换立场 tag，可被魅惑/策反等机制动态改）。

## 元素 / 魔法系统（设计已定 🔒；实现在物理战斗跑通后接）

> ⚠️ 本节的**两套抵抗轨 / 抗性项（共 6）/ 理术 MAG** 已被 [属性与成长系统.md](属性与成长系统.md) §4/§5 **作废**（现役＝四轨 `res_phys`/`res_nature` + `will_fort`/`body_fort` 强韧豁免；异常按 `fort_will`/`fort_body` tag 归轨）；**四元素及其自带异常（火 DoT / 冰减速 / 雷麻痹 / 光驱散）的内容构想保留为 🟡**，供元素内容轮参考。

### 两条伤害来源
- **攻击 ATK** → 武器 skill 的**物理**伤害。
- **理术 MAG** → 魔法 spell 的**伤害** + **施加异常**的强度。

### 两套抵抗轨（决定一条「异常」吃哪种抗性）
- **元素自带异常 → 吃对应元素抗性**：元素魔法的伤害与其**附带异常**，都由该元素抗性减免（火抗减火伤＋火 DoT；冰抗减冰伤＋冰冻；以此类推）。
- **纯异常攻击 → 吃异常抗性**：非元素的状态攻击（毒 / 腐蚀 / 普通眩晕…，多由理术施加）由**异常抗性**抵抗。
  - 推论：**毒 / 腐蚀不是元素**，属纯异常一轨（吃异常抗性），不占元素位。

### 四元素（每个 = 一种元素伤害 + 自带异常，均吃自身元素抗性）
| 元素 | 伤害类型 | 自带异常 | 打的支柱 |
|---|---|---|---|
| 火 | 火焰 | **DoT**（持续掉血） | 生命 |
| 冰 | 冰冻 | **减速**（行动速度↓），叠满 → **冻结**（减速 + 失 1 AP） | 行动 |
| 雷 | 雷电 | **麻痹**（命中↓ 闪避↓） | 精准 |
| 光 | 神圣 | 对【亡灵】tag **额外伤害**；对【人类】**驱散**——攻击性光魔法**未被抵抗**则随机移除目标身上**任意一条修正**（增/减益皆可能） | 净化 / 克亡灵 |

- 光的「驱散」直接落在「**修正 = 对象**」体系：移除目标的一条修正对象，不分 buff/debuff（双刃：可能误删自己挂在敌方身上的 debuff）。
- **抗性项（共 6）**：物理 / 异常 / 火焰 / 雷电 / 冰冻 / 神圣。
- **效能层上面板化**：单位面板带「攻击效能 / 防御效能」（基线 100%），即修正三层里的最终乘数层基值。

## 装备 / 修正管线（设计规格，待实现；顺序：管线 → equipment.json → UI）

> **地基**：单位有效属性 = 面板基础 + Σ修正对象。装备 / buff / 养成 / 地块效果 / 元素，**都只是“挂修正对象”的不同来源**。先有管线，其余皆数据——否则每个系统各写一遍直接改 stats，必返工。
> **实现现状（2026-07-01 管线三步已落地）**：`Unit.modifiers` + `effective_stat()`（flat/pct，**同源去重取高**）+ **eff 效能桶** `eff_mult`/`eff_reduce`（乘算、下限0）；伤害走 **`CombatResolver`** 分量化减伤链（甲抗 `armor_res_*`/人抗 `res_*`/固减 `dr_flat_*`，破甲溢出保留元素）；**buff↔modifier 桥**（`_add_effect` 挂/摘属性修正）。战斗判定序 `_resolve_one` 与状态页均读 `effective_stat`。以下为设计规格；**剩内容**（具体元素技能/附魔/防具甲抗数据/`def_eff` 接G/`triple_vs`/地块effect→eva_eff）见 [路线图.md](路线图.md)「技术债」。

### 修正对象 Modifier（运行时对象）
| 字段 | 含义 |
|---|---|
| `stat` | 作用属性键（`atk` / `eva` / `res_nature` …） |
| `layer` | 层级：`pct`（补正%，基于基础面板、相加）/ `flat`（固定补正、相加）/ `eff`（效能，派生结果上连乘） |
| `value` | 数值 |
| `source` | 来源：`equip:<iuid>:<n>` / `buff:着火` / `prof:<域>` / `skill:…` / `terrain:森林掩蔽` |
| `nature` | `buff` / `debuff` / `neutral`（驱散·免疫·“对带debuff者增伤”按此区分；数学等价 ≠ 游戏等价） |
| `tags` | 本修正自带 tag（元素/属性…，供条件查询） |
| `duration` | 时长（按 round；养成/装备=常驻） |

### `effective_stat(key)` 解析（按修正三层 🔒）
- **调整值** = 面板 ×(1+Σpct) + Σflat（pct 基于基础面板相加；flat 相加，不被百分比放大）。
- **派生层**（命中率 / 伤害 …）再 ×Π(eff)（效能连乘）。
- 战斗判定序（`_resolve_one`）、角色状态页、token 一律读 `effective_stat`（仅 HP/armor 等运行时量除外）——已落地。
- 实现：unit 持 `base_stats`（现 `stats`）+ `modifiers: Array[Modifier]`；增删修正后重算（可缓存）。

### 装备 = 数据（**按类分文件**，仿 `terrains.json`）🔒
- **文件**：`data/weapons.json` / `data/armor.json` / `data/accessories.json`（将来 `consumables.json`），各一个数组。`ItemDB`（`ItemDB.gd`，静态注册表）读全部 → 合并成**按 id 查**的表（`ItemDB.get_item(id)`）；"单一数据源"在**代码层**成立、文件层按类分。
- **槽位（6 槽 🔒，下划线命名）**：`main_hand`(主手) / `off_hand`(副手) / `head`(头部) / `body`(身体) / `accessory_1` / `accessory_2`（双饰品）。武器分主/副手、护甲分头/身两部位（部位命名 head/body，与 stat `armor/armor_max` 护甲值区分）。
- **条目**：`{ id, name, slot, two_handed?, icon, tags, requires?, mods:[{stat,op,value,nature}], attack? }`。
  - **稀有度作 tag**（`special/common/uncommon/rare/epic/legendary`），不另设字段——便于商店/宝箱按 tag 筛、tooltip 展示。见 [标签词典.md](标签词典.md)。
  - **`requires`**：装备需求 tag 列表，单位须**全部具备**才能装（专属/职业/属性门槛）。如龙之灾祸 `requires:["char_veiken"]` → 只有带 `char_veiken` 的维肯能装；可卸下、可给别人，但别人装不上。
  - **`two_handed`**：双手武器，装上占 `main_hand`+`off_hand` 两槽；UI 副手显示同图标 + 灰滤镜。
- **武器**额外带「基础攻击 skill」`attack`：`{ name, icon, coeff(技能伤害系数), range, ap_cost, damage_kind, tags, aoe? }`——装备武器 = 设定该单位的基础攻击（兑现"换武器 = 换攻击 skill"🔒）。
- **防具**：`armor_pool`（护甲池）+ 甲抗 mods（甲抗挂防具、和人无关 🔒）。
- **装备/卸下** = 把条目的 mods 实例化成修正对象（`source="equip:<主槽>"`）挂上 / 按 source 移除（`Unit.equip/unequip/can_equip`）。

### 实现顺序
1. ✅ **修正管线 + eff 效能桶 + 分量化减伤链 + buff桥**（2026-07-01 全落地）：`Unit.modifiers`/`effective_stat`（去重取高）+ `eff_mult`/`eff_reduce`（乘算·下限0）+ `CombatResolver`（分量化）+ `_add_effect` 桥。战斗判定序 `_resolve_one` 全程读 `effective_stat`、对上本文档减伤链验算。剩内容见 [路线图.md](路线图.md)「技术债」。
2. 🟡 **数据 + 装备/卸下**：`ItemDB` + `data/weapons.json`（龙之灾祸）+ `Unit.equip/unequip/can_equip`（双手占两槽、requires 门槛）已做；防具/饰品文件、更多条目待填。
3. 🟡 **UI**：装备槽显示已装图标（双手副手灰）已做；**交互装/卸、背包物品、给予转移、物品图标 tooltip** 待做。

## 敌方 AI 警觉 / 仇恨（已定 🔒 基础模型，实现见 实现现状「敌方 AI」）

- **三种触发方式（数据驱动，任一满足即激活、可组合）**：
  - **① 威胁感知 `ai_threat`**：敌人进入其**威胁范围 =「一批移动力 + 攻击距离」**（= 它这回合能移动过去打到的范围）就激活。**纯看本单位自己的移动/攻击能力**、逐单位自动算（如移动6+攻击1=7）。默认开。

## ZOC 控制区 + 借机（已定 🔒 + 已实现，见 实现现状「ZOC」）
- **ZOC**：每个单位对**自身周围一圈（6 格）**形成控制区，作用于**敌对**移动者。
- **进入 ZOC → 中断移动**：敌对单位移动**踏入** ZOC 即停下（经典 SRPG）。落到可达计算里＝ZOC 格是「终点」，不能从它继续往外扩（**起点格除外**——起点在 ZOC 里仍可尝试离开）。
- **离开 / 在 ZOC 内移动 → 触发借机（AoO）**：
  - 借机 = ZOC 拥有者对移动者打一次（用其基础攻击，**不耗拥有者 AP**）。
  - **命中（未闪避未格挡）→ 本次移动无效**：移动力清空、移动者**留在原地（仍在 ZOC 内）**。
  - **被闪避 / 被格挡 → 移动者顺利离开**。
  - **一次移动尝试只触发一次借机**：取**第一个**符合条件的 ZOC 拥有者，其它不同时打。
  - **每 round 每「拥有者→移动者」只触发一次**：触发过（无论命中与否）的拥有者，本 round 内不再对该移动者触发（含被闪/格后免疫）。→ 被一个敌人拦下后，**再花 1 AP** 移动就不会被它拦（但会被同格的**另一个**敌人拦）。
- **关键简化（实现用）**：因「进入 ZOC 即终点」，一次移动动作里**只有起点可能在 ZOC 内**（其余路径格都是开阔格、终点可能是新踏入的 ZOC 格）。故**借机只需在「离开起点」时判一次**：起点在敌对 ZOC 内 → 取第一个未用拥有者打一次；命中则钉住（移动力清空、停在起点），闪/格则放行；该拥有者标记本 round 已用。多 AP 重试 = 新移动动作 = 新判定（已用的拥有者跳过）。
- **数据**：`zoc_triggered[(owner,mover)]` 每 round 清空；可达计算加「ZOC 终点」规则（玩家移动 + 敌方 AI 走位都走同一套）；借机复用判定序 `_resolve_one`（需返回 命中/格挡/闪避 结果）。
- **待定**：是否所有单位都有 ZOC（暂定是）；飞行/灵体是否无视 ZOC；借机是否可暴击（暂定走完整判定序）。
