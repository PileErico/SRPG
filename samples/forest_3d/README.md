# 林地哨站 / 粗像素 3D 场景美术样板

独立视觉实验，用于比较低模三维地形、粗像素材质与二维像素角色的组合；不代表正式项目的美术路线已经确定。像素质感来自素材本身的低分辨率图案和少色色板，场景以窗口原生分辨率清晰绘制。

双击项目根目录 `run_3d_sample.bat` 启动当前的 `PixelOutpostSample.tscn`。`run_3d_sample_plain.bat` 打开同布局的纯色低模 `OutpostSample.tscn` 作对照。原来的 37 格基础小样 `ForestSample.tscn` 也保留。

`run_3d_props.bat` 打开 `PixelPropsPreview.tscn`：水井、双木桶与路牌的近景陈列，使用同一套素材、人物参照和镜头操作。三件新物件也已放入哨站庭院，各占一格、不可通行，当前不提供破坏或使用功能。

`run_3d_world.bat` 打开 `samples/world_3d/WorldMapSample.tscn`：91 格世界地图「山海之间」，北部连绵山脉接丘陵带，河谷跨格绕出大弯、穿过桥下后汇入海湾，弯曲道路连接松风村、苔丘村、海角村。`WorldMapLayout.gd` 用固定种子生成半径 5 的地域布局，包含 14 格山地、11 格丘陵、15 格森林、22 格草原、10 格河谷和 19 格海湾；海水按近岸与远岸区分深浅。一格表示一片地域；`WorldRelief.gd` 生成连绵地表，`WorldMapKit.gd` 制作树群、聚落与小桥，复用场景的 32 色与低分辨率纹理。陆地基准高 0.25，平原、森林及聚落可随邻域略微隆起，山丘由地面自身形成；邻水岸回到基准高度，河海水面低于岸边 0.25，岸边及地图外缘补齐侧壁。地形、道路、聚落分别记录；这是独立视觉样板，尚未连接正式战役、旅行、遭遇生成或存档。

双尺度表达：世界地图以连续陆地与地域地标保证辨识，战斗地图保留具体地形高度和占格物件。战斗通行须结合阻挡物体与单位移动能力，例如水生单位下水、飞行单位飞越；视觉高低不独立定义所有单位的禁行区域。现有战斗小样的移动仅用于演示，尚未接入这些正式单位能力。

世界地表 🔒：平原/平地为低、丘陵为中、山地为高。所有陆地共用邻域影响原则：低于自身的邻格比例越大，目标高度越低；高于自身的邻格比例越大，目标高度越高；同级聚集回到该类高度基准。仅统计实际存在的六邻，图外不补作低地；用地形等级一次计算，不递归使用已生成高度。平地目标起伏限于 0～0.12，丘陵目标起伏限于 0.10～0.40，山地限于 0.75～2.40，保持缓丘与高山的区别；相邻山地之间生成连接山脊。岩色过渡高度为 0.50～0.90。相邻丘陵共边保持高于平地，丘陵接山地继续升高，接低地时平缓衔接，邻水岸回到陆地基准。山地高于丘陵，山脚草色逐渐过渡到岩石色。`WorldRelief.gd` 用共享世界坐标高度场构建各格三角网，共边同高；高度查询采用实际网格插值，地表、碰撞、侧壁、格线与高亮使用同一结果。地表不加独立物件描边。`WorldReliefMaterial.gd` 与专属 shader 用现有 grass/stone 六色、16×16 纹理和最近邻采样，以世界坐标像素色簇随高度逐渐替换草色为岩色；面朝向只切换已有色阶，不产生连续新颜色，也不降低渲染分辨率。

河谷先定路径再构面：`WorldRiverPath.gd` 接收有序相邻河格、上游入口和下游海格，按每格入口/出口生成直段、60°缓弯或120°急弯；跨格共用边中点和切线，三次曲线按不大于 0.06 的步长采样，河槽半宽 0.40。桥格经过格心并保留短直段，桥梁、坡道和两侧道路沿局部河道的垂直方向连接。河岸只有与直接相邻的陆地格存在实际共边长度时才保留；只邻河海、图外或仅接角的岸条降为河床并补齐水面，河口向海湾展开。判断不依赖固定格坐标或镜头左右。河床高 -0.24，高于近岸海床 -0.48 与远岸海床 -0.62，河海水面统一为 0。`WorldRiverSurface.gd` 将河岸/河床构成单份细分三角网，加入岸顶、坡脚和水线折点，水面按实际三角形裁切；材质、碰撞、高度查询、格线和选中轮廓共用该网格，海口也继承河侧共边的全部折点。`WorldWater.gd` 用已有 iron/cloth/cloth_light 三色生成 16×16 静态波纹，不用透明、连续渐变或低分辨率视口。

低地海岸由 `WorldCoast.gd` 生成：平原、森林与海格的共边保持陆地高 0.25，在海格内用约 0.85 宽的岸坡逐渐下降至水下，复用土色像素材质。各海格共用世界空间高度场，海口接收河岸、河床与水线折点，逐渐衔接较深的海床。水面按实际坡面三角形裁切，露出水面的岸坡不会被水覆盖；海床、岸坡、点选与格线共用实际网格高度，海格外缘的水体截面也随岸坡裁切。

道路以相连格中心及共边中点为锚，用三次曲线形成缓弯，跨边切线与地图出口保持对齐，岔口圆滑并合为单个平面轮廓。道路按实际地表三角形裁切并贴坡铺设；河槽处裁掉陆路，由带短坡的木桥连接两岸，南向支路接至海角村。道路格留出开敞走廊。树群中的每棵树、村落中的每座房屋和田地按各自锚点刚性落地，接触影网格也贴合坡面；旅团标记和多个地名标签跟随所在位置高度。

世界小样左键选中地域并高亮现有六邻格，底栏显示周边地形数量；树冠、屋顶也可选中所属地域。右键拖动环绕（25°～80°俯角）、中键平移、滚轮按比例缩放（最近为 7，最远为整图取景的 1.5 倍）、Q/E 每次转 60°、C 恢复整图取景、G 开关格线、O 开关模型描边、Esc 退出。平移范围和默认取景根据地图边界确定。旅团旗帜是固定的队伍位置参照，选格不推进旅行。

世界样板已验证 91 格与奇列中心、16 格道路组成连通无环网、三村有路、仅桥格跨水，以及河流首尾延展、河口接海、远边地块拾取和相机缩放/平移限幅/C 复位。平地、丘陵、山地均已验证邻域等级升高时的实际高度趋势与各自限幅；陆地采用每格 384 三角形，共边顶点与法线共享，表面高度查询与实际三角面一致，重复生成结果稳定。扩大地图的陆地共边误差不超过 0.000011，道路三角形中点贴地误差不超过 0.000075；接触影贴地、格线离地余量和地表点选沿用同一表面查询。河床/海床/水位、真实裁槽碰撞、水面/桥面点选、跨格河面与河口保持一致。默认预览已实绘检查，为 `samples/world_3d/preview.png`。

河岸邻接规则已验证：岸条只有与直接陆地邻格共边时才保留，仅接角不会保留；河口与海湾水面连通。移除区域的水面/河床查询、悬停/选中/格线高度使用同一岸形。

河道曲线已检查奇/偶列、六个方向、直段/缓弯/急弯及桥格组合，半宽 0.40 的河槽保持在指定地域内。当前大弯已检查中心线与两侧水面连续性、实际岸坡查询、桥梁横跨方向及落岸、道路贴地和弯道点选；整图预览为 `samples/world_3d/preview.png`，较高俯角的河道预览为 `samples/world_3d/river_preview.png`。

- 左键地面：沿六边形邻接移动；树占格不可穿行，一次最多跨一层高度。
- 左键相邻树木：砍成树桩，原格恢复通行。
- 左键相邻裂墙：破坏这一段，缺口可走；其他墙段保留且不可破坏。道路上的门洞可以直接通过。
- 右键拖动：自由环绕及调整俯角（15°～80°）；中键拖动：沿地图平面平移。拖动观察不触发单位移动。
- Q / E：每次转动 60°；滚轮缩放（正交镜头范围 7～24）。
- G：显示/隐藏六边形格线；C：复位转向、俯角、平移与缩放。近景陈列使用自己的复位构图。
- O：显示/隐藏场景模型的黑色描边；重新生成后保留开关状态，人物的阵营色遮挡轮廓独立保留。
- 人物精灵完整朝向镜头，旋转时仍显示同一张正面图。被树木、墙体或高地遮挡的部分显示蓝色轮廓，未遮挡部分保持原图；敌方红色配色使用同一轮廓材质（当前小样只有一个己方角色）。
- R：保留哨站、林缘与道路构图，调整树形、大小和外围林木分布，并重置人物与已破坏物件。
- Esc：关闭小样。

场景包含 61 格、三档高度、贯通林缘的道路、松树与阔叶树、岩石与地表植物、木栅/石墙/裂墙/瓦顶门楼、一座占两格的小哨所，以及像素版新增的一格木车。人物引用现有 `appearance_empire_infantry.png`，仍为单张正面精灵。哨所两格、大岩石和木车不可通行；门洞留空；树桩和墙体残骸可通行。

新增道具通过 `PixelPropLibrary.gd` 记录名称、尺寸、占格、材质、阴影范围、制作源与可破坏性，并统一实例化。`PixelWell.gd` 提供真实中空石井口、双木柱、摇柄、绳和悬桶，木柱从井沿顶起，不穿过石壁；`PixelRoadsideProps.gd` 提供连续八角外壳、铁箍材质分区的双桶，以及每块箭头一次挤出的双向路牌。`PixelPropFaces.gd` 共用面绕序与轮廓挤出，避免用重叠封闭体堆出细节。三件均为底部 y=0、XZ 居中，复用既有材质与面 UV，不增加色板颜色。哨站位置分别为水井(6,6)、木桶(7,4)、路牌(8,5)，主路保持贯通。

像素版采用自制几何与程序生成的像素图案：`PixelNature.gd` 用少量硬边体块制作植物与岩石；`PixelOutpostKit.gd` 提供简化建筑和木车；`PixelMaterials.gd` 集中维护 15 类材质的色板、图案与缓存。木车复用建筑的木材/金属/木材断面，作为新增物件的一致性样例。地形、碰撞、摆放与交互继续复用两层基础小样，通过视觉构造入口替换模型和材质。

本版制作规格：纹理 16×16、每世界单位 16 个纹素，以人物的素材密度为参照；最近邻采样，图案用 2～4 像素色簇、大面积主色与少量明确分区。15 类材质统一引用 `PixelMaterials.SCENE_PALETTE` 的 32 色场景色板，各类图案仍只用 2～3 色。地面采用较浅的暖灰绿，树冠和灌木采用更深的冷绿；木材、瓦片、石头与道路使用共用色阶。明暗依照面的方向选择色板档位，不增加连续灯光渐变、高光或任意染色；一个多材质物体会使用相应的多组色阶。固定色阶的场景表面不接收实时投影，模型仍能向样板底部背景投影。树冠采用 3～5 个主要体块，建筑细节以贴图和大轮廓为主。

三维场景、人物和 UI 均在原生视口绘制，场景保持窗口分辨率。人物目标高度为 1.2 世界单位，以整数屏幕像素倍率显示原图，默认视角比原尺寸缩小约四分之一；原图中的头盔、武器等像素细节完整保留。移除脚底蓝色底盘，脚点贴近地面。人物与阵营色遮挡轮廓同步尺寸，均以最近邻采样。镜头、拾取、生成、移动与破坏使用基础小样的同一视口和物理空间。

地形使用世界主轴投影。自然物件和建筑使用 `PixelMeshUV.gd` 生成的面局部 UV，一个 UV 单位对应一个模型长度单位；贴图随物件移动和旋转。屋顶部件在倾斜之前建立 UV，合批后保留面内尺寸；自然物件按最终等比缩放补偿 UV 密度。当前工具支持等比实例缩放，非等比缩放需先应用到几何后再生成 UV。三维表面投影到屏幕时会自然倾斜与压缩，不进行全屏粗像素网格处理。

`ModelOutline.gd` 与 `model_outline.gdshader` 给主要模型加共享色板中的近黑描边，宽度以人物显示倍率为参照，默认目标约三个屏幕像素。每个物件合成一个描边壳，跨材质共享位置法线，消除完全相反的重合三角；沿完整法线外扩并同步深度，线宽随表面投影自然变化。壳正常接受遮挡、不写深度、不投影、不改变碰撞，排除接触影，网格按源几何及局部变换缓存。树木、建筑、木车、大石、树桩与墙体残骸启用描边，地面和细小植物不启用；人物仍使用原图自身的像素边缘与独立遮挡轮廓。

物件制作时，材质分区优先共用连续外表面；可见面不与其他部件共面叠放，紧贴部件之间去掉内部封面，孔洞保留真实内壁。自由镜头验收包含默认、低俯角和高俯角的整圈观察，并使用 O 对照裸模型与描边，分别检查几何穿插和轮廓杂线。

`PixelContactShadow.gd` 提供接触阴影：使用场景色板的两档深色与硬边透明像素，贴地小面片，无碰撞、不投影。人物、树根、石头与灌木用小椭圆，墙体、哨所、木车按底面尺寸，门楼仅在两根立柱下落影；阴影挂在物件节点下，随移动、砍伐、破坏与重建同步更新。G 控制独立六边形格线层，线宽与颜色加强，悬停提示保持原有独立顶面叠加。

纯色低模对照版仍使用 Kenney Nature Kit（CC0）自然模型选集，原始模型、许可和来源记录位于 `assets/nature/`；由 `NatureAssets.gd` 加载。该版建筑由 `OutpostKit.gd` 生成。像素版不实例化这批外部模型。

示例环境未连接真实世界地图；移动与破坏仅为小样交互，未接正式战斗、AP、视野或存档。运行不修改地图或战役数据。

轮廓表示镜头遮挡，不负责判断单位是否已被玩家发现；正式接入战斗时需要先遵守战斗视野规则。已在项目的 Compatibility 渲染模式下验证启动与画面、六个方向的拾取和悬停、遮挡轮廓、门洞通行、建筑占格、砍树/裂墙后的通行、移动中重新生成；五个种子的主路与高地台阶均可达。

像素版已验证实际鼠标输入的移动/砍树/破墙、木车与小屋阻挡、G/C/R 操作，以及新旧场景在共用视觉入口后的正常启动。像素自然物件按材质合并网格，草丛由五个体块合为一次绘制。模型描边已通过显隐、重复添加、正常遮挡和 Compatibility 实绘检查。

人物精灵与遮挡轮廓保持相同尺寸；O 开关不影响人物轮廓，重建及破坏后新生成的模型描边遵守开关状态。

原生分辨率、少色像素材质、缩小人物与移除底盘后的默认画面已实绘检查。
