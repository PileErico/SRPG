## ✅ 已实现

### 功能

- **等级零数值 🔒**：等级只推 技能槽/天赋树 解锁节拍（节拍 🔒 §10.1＝**20 级制**：天赋 1(默认)/3/6/9/12/14/18·槽 1/4/8/11/16·属性点 2/5/7/10/13/15/17/19/20）；HP_max/atk/acc/eva/格挡/暴击…＝基础面板 stat、入 `StatMeta` 序列化/编辑器白名单
- **种族底值**：human/lizardmen/harpy（id＝race tag 同词表）；`make_unit`＝底值直落 → proto.stats 差异覆盖；扁平血量（底值不随等级涨）
- **抗性四轨 🔒**：`res_phys`/`res_nature`（全元素含神圣归轨，`damage_kind` 保留细分）＋`will_fort`/`body_fort` 强韧豁免掷（遭受瞬间+每回合各 1 次；效果按 `fort_will`/`fort_body` tag 归轨；`ignore_fort` 穿透两处；防具永不提供强韧）
- **死门检定 🔒（§10.6，2026-07-07 接线）**＝1d20＋运气＋肉体强韧/5 vs DC 逐轮 5/10/15/20/25… 递增（`Sandbox._door_turn_check` 走 `Checks.check_flat`；±3 条/被命中 −1 沿用）
- **四属性全键落地 🔒（§10.6 终表 2026-07-08，每点效果）**：`finesse` 技巧＝1 命中＋0.5% 暴击 / `agility` 灵活＝1 闪避＋0.5 先攻（`initiative()`=speed+floor(灵活/2)；死门 debuff 减半打它）/ `luck` 运气＝−1 被暴击＋**0.5% 爆伤**（另全 d20 检定补正）/ `resolve` 决心＝气势/压力检定修正 +1（🔒 → [模块_战斗_设计.md](模块_战斗_设计.md)「气势系统」）；增量统一 +1/点；全入 StatMeta 三白名单
- **种族重基 🔒（§10.6 终表）**：atk/acc/eva/crit_rate/格挡/speed 人身底值**全部归 0**（武器承载命中、修正落点承载闪避）；**crit_dmg=120** 全招式默认（爆伤=120+运气×0.5）。种族差异（人/鸟/蜥）：HP 40/35/45·移动 4/4(飞6)/3(水4)·视野 5/6/4·技巧 10/12/8·灵活 10/14/6·运气 5/3/3·决心 0/0/4·蜥肉韧底 5＝races.json 真值、设计 §10.6 终表速查
- **条件移动力＋水生 🔒（2026-07-08）**：`Unit.move_allowance(tile_tags)` 读 races.json `move_overrides`——条件命中替换种族基础移动力、修正差量照叠（鸟妖 flying→6 按自身 tag / 蜥蜴人 water→4 按脚下地块 tag，`BattleState._tile_tags_at` 供地块上下文，预览/购点/AI 同口径）；**〈水生动物〉`aquatic`** 蜥蜴人种族常驻——深水可通行、深/浅水/海岸成本恒 1（terrains.json 通行规则＋tags.json 注册）
- **自动轨成长 🔒（节奏数组）**：races.json `growth` 值＝数字（每级）或**数组循环**（按新等级 % 数组长；`Unit._growth_amount`）——人 HP `[1,0]` 逢双升→50·双韧+2/+2→38｜鸟妖 `[1,0,0]` 逢三升→41·意+2·肉+1｜蜥蜴人 `[1,2]` 交替→73·意+1·肉底5+2→43；当前 HP 随上限同补；**20 级封顶**；技艺槽 1/4/8/11/16（`prof_slot_capacity`）；make_unit 追溯成长＝**逐级行走**（节奏数组按级取值）
- **加点数据层＋UI（战后结算 🔒 2026-07-08）**：属性点节点（Lv 2/5/7/10/13/15/17/19/20）每级 `attr_picks` +2，九节点共 **18 点**；增量统一 +1、**可双点同投一属性**；序列化 proto/battle 快照随行；**UI＝三区布局**（🔒 用户定）：**蓝区**＝头像右侧四属性列（序 技巧/灵活/决心/运气，`_attr_col`，有点数行尾出 [+]、战斗锁定、点按面板重建）｜**绿区**＝计量条下 移动力/物理抗性/自然抗性/肉体强韧/意志强韧（百分比键带 %）｜**右列**＝修正属性（`_build_derived_col`：命中率=acc+技巧、闪避率=eva+灵活、暴击率=crit+技巧×0.5、暴击伤害=crit_dmg+运气×0.5、格挡率/性能=装备承载 effective 口径；全部 % 显示）；**战外入口 ✅（2026-07-11）**＝大地图 👥 队伍 → 角色卡（同一份面板，Overworld 无 phase → 加点解锁，见 [模块_大地图.md](模块_大地图.md)）
- **天生武器实装 🔒（§10.4）**：weapons.json `unarmed_fists` 拳脚（innate+natural、atk 2.5/acc 25、tags unarmed/melee/common 无持握）；races.json `natural_weapon` 全族指向；`Unit.ensure_natural_weapon`（生成/卸主手后自动入位）+ `equip_instance` 顶替分档（natural 可顶→`_displace_slot` 销毁实例；锁定 innate 不可顶）+ `unequip(slot, auto_natural)`；`unit_to_proto` 排除 natural；比路兹双爪 acc 各 15（防全局双计）
- **格挡物品化管线 🔒（§10.3）**：`Unit.effective_stat_f` 格挡两键 equip 来源按件聚合取高（`BLOCK_MAX_KEYS`）；**条件 mod 基建** `requires_prof` 字段（`_mod_active`，三循环全接）——武器格挡/`triple_vs` 类条件修正的共用口子；斗盾（15/35 无门槛）现成生效
- **stat 覆盖唯一入口＝`proto.stats`**：`UnitFactory.make_unit` 不读顶层 stat 键、编辑器只写 stats 块；全部原型/嵌入单位纯走种族底值，具名差异化留数值轮重赋
- **`style_block` 格挡域入库**：proficiencies.json 风格页第 11 域（match_tags 空、喂养与档位加成 🟡 数值轮）——`requires_prof:"style_block"` 条件 mod 的真实落点，武器格挡数值自此可写
- 测试：`tools/test_attributes.gd`（种族重基/公式/成长/加点/天生武器/格挡取高/条件 mod/序列化，30 套全绿）
- **技能（熟练度域）子系统**：32 域三页（风格11 含格挡 / 武器9+2异种 / 生活10）；五阶段 生疏→娴熟→老练→专家→大师（阈值 0/100/300/600/1000·大师计量满值 1500，🟡可调参）＝4 次进阶＝4 次专长选择权；`perk_rows` 候选数可变、同层任选一/可空/再点取消，选择存 `prof_perks`，装载总开关控制被动修正与主动能力；前置 `requires{all,any}` 跨页（镰刀=AND、太刀=AND+OR）；派生/异种域阶段浮现（锚＝老练 `REQ_STAGE=3` 🟡）
- **三态**：未学 → 已学（`prof_known`，可装载）→ 装载（`prof_slots`）；熟练度永不丢失（卸下冻结）；一次性学习资格闸门（资格看 xp 不看装载）
- **装载＝总开关**：`prof:<域>` source mods 挂/摘；阶段补正取 `stage_mods` ≤当前阶段的最高一档（不叠加）
- **战斗涨值**：仅装载中可涨；权重 攻击＞格挡＞挨打 🔒、威胁缩放＝等级差线性 🟡、挥空也算练习；行为匹配＝武器/攻击 tags ∩ 域 `match_tags`（一次行为同喂所有匹配域；徒手喂「体术」）
- **BattleIO 回流**：涨值与 perk 选择发生在战斗副本 → `apply_result` 回写 xp/known/slots/perks + 按新阶段重挂 `prof:`/`perk:` 补正（战斗运行态不回流；唯一回流点；无 prof 字段旧结果安全跳过）
- **三层序列化**：proto `profs` 块（烘焙 force 装载，敌方不走槽位校验 🔒）/ campaign / battle 快照（补正随 modifiers 整份）
- **状态页「技艺」tab（视觉稿 v1，真数据已接）**：顶部 5 装备格＝`prof_slots`（竖向计量槽＝档位内进度·档位色；容量外＝未解锁标 Lv）+ 三级 tab（L2 类型页 / L3 具体域，阶段浮现过滤）+ 右侧「已习得」列（熟练度高→低）；档位名/阈值读 ProfDB 单一源、配色 UI 侧；图标管线＝域 `icon` 字段（res:// 路径即显，🟡素材待画）
- **矛·娴熟首行 Perk（2026-07-15）**：`立矛`主动＝2AP、自身至下一 turn_start 的架势、ZOC 2、每 round 每拥有者第一次敌人实际进入时自动引用 BWS（强制位移也触发、生成不触发；双手最终调整×1.2，非反应系数）；`逼退`被动＝`knockback_chance +15` 且 `when.skill_tag=skill_spear`，与主动击退概率合并单掷、逐攻击判定结算。`tools/test_spear_perks.gd` 覆盖选择/总开关/序列化/两项机制。
