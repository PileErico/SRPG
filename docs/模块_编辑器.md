### 功能

**MapIO（地图读/写单一入口；static 伪单例）**
- `read_file(path)`（失败 `{ok:false}`）/ `normalize(dict)`（校验＋钳制＋逐格兜底；文件读与内存试玩共用）/ `to_dict`/`write_map(path,w,h,tiles,opts)`（**opts 字典**，加字段不连坐调用面）/ `grassland(w,h)` / `peek_type`（轻探 map_type 供列表标注，免全量 normalize）。
- MapEditor/Sandbox 共用同一解析——**统一尺寸钳制策略**（同图两侧尺寸必一致）；regions/units 原样透传（各方按内存形再转）。

**六图层（`current_layer`；左侧栏 3 列网格互斥切换，线/地点层仅大地图显示；画布左右键按当前层分派 `primary_paint`/`secondary_paint`）**

- **地形工具四件套（2026-07-07）**：工具行 画笔/填充/矩形/直线 互斥＋画笔半径 SpinBox(0~4)——画笔半径＝六边形距离 ≤N 一片（`_paint_radius`）；油漆桶＝同底地形(terrain/variant)连通块 BFS 整片刷、一次按下只填一回（`_flood_fill`＋`_fill_stroke_done`）；矩形/直线＝两点工具：按下定起点、拖动画布黄描边预览（`EditorCanvas._draw_shape_preview` ← `shape_preview_cells()`）、松开在 `end_stroke` 落形（直线走 `HexGrid.line`）；三者最终都逐格 `paint_cell`（放置物/橡皮/去重/分块重绘单一实现），一段 stroke 一步撤销照旧。⚠️ 选刷注意：工坊化后同名条目可能是放置物刷（写 `object` 子字段不动地形，如森林）。

- 选文件夹作默认路径（目录对话框→`user://map_editor.cfg` 记住；默认 `res://maps`）；`_scan_maps` 用 DirAccess 扫 `*.json` 按名排序；单击切图（经未保存确认；`select()` 静默不回环）、当前行高亮（按文件名）、大地图行标〔大地图〕（`peek_type`）；`＋新建地图…`（文件名输入＋顶栏尺寸→`_create_map` 立即落盘入列表，**撞同名先弹覆盖确认** 2026-07-07）；另存为默认指向该文件夹；当前文件名＋脏标记 `*`。
- **库操作行（2026-07-07）**：重命名/复制/删除 作用于列表选中项（`_on_map_rename/_on_map_duplicate/_on_map_delete`，共用 `_ask_name` 文件名弹窗；删除有确认；当前打开图被改名→`current_path` 跟随、被删→转未保存态）。剩：缩略图预览。

**撤销体系 ＋ Layer 容器（LAYERS 注册表）**
- `_snapshot`/`_apply_snapshot` 全图层深拷贝；上限 50；stroke＝整段拖动一次撤销；区域颜色实时改不入栈；右侧「最近操作」列表（顶部 ↩ 标下一个被撤销项）。
- **`LAYERS` 注册表**＝9 个顶层数据层（regions/units/triggers/terrain_overrides/environment/locations/rivers/roads/bridges）的唯一账本（行＝内存变量名/磁盘字段名/空值形态）：快照、回滚、`new_map` 清空、`_map_opts` 序列化、`load_from_file` 反序列化五处生命周期全部循环本表——**加新数据层＝表加一行**（+专属绘制/工具代码）。tiles 不入表（随尺寸重建、`_copy_tiles` 保 object 子字段）；regions 出入盘经 `_regions_to_json/_regions_from_json`；拷贝分派 `_copy_layer`（regions/units 专用构造、其余 `duplicate(true)`）；缺省值策略统一为空值形态。回归护栏＝test_mapfeatures 第 8 组（全层快照往返/清空/字段齐全/深隔离）。

**编辑器 UI 公共层（与 ItemEditor 共用，DRY 单一出处）**
- `EditorUI.gd`（全 static 控件工厂：label/section_title/field_row/panelize/折叠/菜单/确认框/`select_meta`·`dropdown`·`add_dropdown` 地基件/`add_mod_row` 修正行/`add_when_row`·`collect_when_row` when 条件行〔词表 `WHEN_TYPES`＝技能设计 §4 v1，2026-07-13〕/`item_picker` 物品选择器弹窗〔搜索过滤+行图标+ItemTooltip 悬停富预览；CharacterEditor 在用、DeployPanel 将来可共用，2026-07-13〕；发信号控件经 on_change 回调、不耦合宿主 `_refresh`）＋`EditorTheme.gd`（统一深色主题）。

**通用编辑体验**
- 适配窗口：`HexCanvas.fit_to_view`（留边距、钳 0.2×–4×）；新建/加载后自动 `request_fit`（待布局尺寸就绪在 `_draw` 执行）。
- 未保存提醒：`_dirty`→新建/加载前 `_confirm_discard` 确认框；返回主菜单前另有全局地形数据守卫（见「地形数据」段）。
- `new_map` 清空 units/triggers/terrain_overrides（防带上一张图数据）。
- **地图尺寸可调**（2026-07-13）：顶栏「调整尺寸…」→ 确认对话框（说明裁剪丢出界内容）→ `resize_map`：一次撤销快照（undo 一步全量回退）＋ tiles 扩（新格草原）/裁 ＋ **`_clamp_layers_to_bounds` 按 LAYERS 注册表逐层钳制**（加新数据层须补分支）：单位/地点注记出界删除、区域格与线特征格对丢弃、触发器 when/do 的 col/row 钳入界内、terrain_overrides/environment 无坐标不动；改完 `_refresh_canvas`+`request_fit`，状态栏报出界处理摘要。
