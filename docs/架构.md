# 架构总览（代码结构目录 + 跨模块约定）

> 上半＝**代码结构目录**：全部代码文件 → 一行职责 → 归属模块（细节/关键函数查各 `模块_*.md` 代码架构表）。下半＝**跨模块约定 🔒**（只在本篇维护，别处引用不复述）。运行/测试 → CLAUDE.md。

## 引擎 / 形态
- **Godot 4.6.2 stable（mono 引擎）+ 纯 GDScript**（无 C#）；渲染 `gl_compatibility`；**平顶六边形 flat-top + odd-q 偏移**（奇数列向下错半格）。
- 主场景＝`StartMenu.tscn`；跨场景传参用**静态单例**（`SandboxConfig`），不用 autoload / class_name。

## 场景流
```
StartMenu.tscn（主场景）
 ├─ 战役 新开局/继续 → Overworld.tscn（大地图）        战役层
 ├─ 沙盒模式 → MapSelect.tscn → Sandbox.tscn           自由测试场
 ├─ 编辑器（编辑·试玩）→ Game.tscn（✎编辑/▶试玩 双模式，内存直传）
 ├─ 地图编辑 → MapEditor.tscn　　物品/角色/技能编辑器 → ItemEditor/CharacterEditor/SkillEditor(⇄EffectEditor).tscn
 └─ 外观工坊 → AppearanceWorkshop.tscn　　地块工坊 → TerrainArtWorkshop.tscn
```

## 跨模块约定 🔒

### 三个运行入口职责边界 🔒
| 入口 | 定位 | 产出 |
|---|---|---|
| **MapEditor** | **创作可玩关卡**（authoring） | 持久关卡内容（地图 json） |
| **Sandbox** | **自由测试场**（testing，不挂 WorldState） | 不落盘、临时 |
| **Game** | 编辑↔试玩统一宿主（内存直传） | — |

> **编辑器 ≠ 沙盒**：共用底层（Unit/工厂/DB/画布基类），**不揉成一个**。

### 三套坐标序（最易踩的坑 ⚠️）
| 数据 | 顺序 | 含义 |
|---|---|---|
| `tiles[row][col]` | **行优先** [row][col] | 地形 |
| `regions.cells[[x, y]]` | [x=col, y=row] | 区域格，`x` 是列 |
| `units[].col, .row` | 显式 col/row（odd-q） | 预置单位 |

> 新字段一律显式 `{col,row}` 或 `[col,row]`。像素↔格转换收敛在 `HexCanvas` 与 `Sandbox` 各一份（职责不同不算重复）。

### DB 伪单例范式 🔒
所有 `*DB` + `MapIO`/`SandboxConfig`/`TextureCache`/`WorldState`/`SaveIO`/`ItemInstances` 统一：**`extends RefCounted` + `preload` 常量引用 + `static var` 惰性加载 + 不用 `class_name`**。
- ⚠️ preload 环 → 环上一处改运行时 `load()` 断环（先例 `ItemInstances._ws`）；惰性 load 路径不被导出器扫描——**导出预设必须「导出全部资源」**。
- ⚠️ **刷新函数不得叫 `reload`**（命中原生 `Script.reload()`＝静态全重置）；全 DB 统一 `reload_data()`。

| DB | 数据文件 | 读 | 写回 |
|---|---|---|---|
| `TerrainDB` | `terrains.json` | ✅ | ✅ `save`/reload_data |
| `ItemDB` | `data/{weapons,armor,accessories}.json` | ✅（纯模板；运行时经 `ItemInstances.view`） | ✅ `save_item/delete_item` |
| `ItemInstances` | —（实例态随 campaign 档） | ✅ `view/get_instance` | `create/add_affix/destroy` |
| `TagDB` | `data/tags.json` | ✅ `cn/color/by_cat` | reload_data |
| `RaceDB` | `data/races.json` | ✅ `get_race/apply_to` | 只读 |
| `ProfDB` | `data/proficiencies.json` | ✅ `get_prof/stage_of/matches_tags` | 只读 |
| `EffectDB` | `data/effects.json` | ✅ `get_effect/all` | ✅ `save_effect/delete_effect` |
| `SkillDB` / `TraitDB` / `JobDB` / `LocationDB` / `DialogueDB` / `FactionDB` / `WorldUnitDB` | `data/*.json` 各一 | ✅ | 只读（按需补）；读盘统一走 `JsonRegistry.load_indexed`＋`_path_override` 测试缝 |
| `EnvDB` / `EventDB` | `data/environment.json` / `data/events.json` | ✅ | 只读 |
| `GameSettings` | `user://settings.cfg`（用户态非 res://） | ✅ | ✅（设置面板写） |
| `AppearanceDB` | `data/appearance_parts.json` | ✅ | ✅ `save_part/save_palette` |
| （原型无专用 DB） | `data/unit_prototypes.json` | ✅ `UnitFactory.all_prototypes/get_prototype` | ✅ `UnitFactory.save_prototype/delete_prototype` |

### 战中快照约定 🔒（battle 层＝序列化第四层，与 proto/campaign 并列）
全量运行态原样存（位置/AP/移动点/effects/modifiers/死门条/skills{cd,uses}/ai_aggroed/tags＋熟练度 prof_xp/known/slots）——`UnitFactory.unit_to/from_battle_snapshot`；**复原＝`Unit.new()` 后整份覆写**（绕开 make_unit 的 init_vitals 注满/learn_skill 充能重置/set_trait·equip 重挂陷阱）；**战斗内单位主键＝快照单位池下标**（uid 沙盒/预置单位恒 0 不可作键）；effects↔modifiers **整份原样存取**（source 保真、复原不重挂）；派生态不存（`_vis_visible`/区域派生 restore 重算，`_vis_seen` 唯一必存历史）。**新增运行态字段须同 PR 扩快照白名单**（to_dict/restore＋battle_snapshot 两处）。

### 画布契约护栏
`SandboxCanvas` 直读宿主一批下划线私有（`_deploy_cells`/`_anim_*`/`_flash_units`/`_unit_hidden_by_fog`/`_has_acted`/`_is_active_unit`）——迁移必须在 Sandbox 保留**同名（含下划线）转发**；`hover_extra` 经 `has_method` 探测（MapEditor 故意不实现勿误加）；`faction_color` 在 Sandbox 与 MapEditor 各一份都要留。

### Meta 层架构决策 🔒（2026-07-02）
> Campaign 数据（WorldState）不认识任何场景节点——场景是它的消费者。
1. **uid**＝存档域自增 int（`WorldState.next_uid`），unit/item 共用。
2. **时间＝小时计数器**；战外结算按每小时节拍；职务加成＝改每小时速率；日夜＝小时区间→EnvDB time id。
3. **存档**：campaign 正常档（铁人 flag）；战中存档＝「临时存档 suspend」语义（非 SL、读取即失效、可裁剪）。
4. **战斗不消耗世界时间**：战场日夜冻结、只天气变；退战回读时钟。
5. **sandbox 不挂 WorldState**（临时实例、退出即弃）。

### 地图数据流
`maps/*.json ↔ MapIO`（read_file/normalize/write_map+opts）——schema v4 字段总表/线特征格对/兼容套路 → [模块_编辑器.md](模块_编辑器.md)。编辑器与沙盒**共享同一张 `res://maps/sandbox.json`**。

### 核心理念
① **数据/代码分离**（真值外置 json，代码查表）；② **tag 统一判断**（单位/地块/物品/技能/效果共用 [表单-标签.md](表单-标签.md) 一张词表）；③ **修正是对象**（`Unit.modifiers` 保留载体+buff/debuff 性质；三层 flat/pct/eff → [表单-系统公式.md](表单-系统公式.md)）。
