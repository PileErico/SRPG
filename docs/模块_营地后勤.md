## ✅ 已实现

### 功能

**WorldClock 世界时钟（M2）**
- `advance(ws, hours)`＝唯一推进入口（显式收档、不碰 `current`）；逐小时结算调度表（跨多小时＝多次结算不漏算）。
- 战斗不耗世界时间 🔒（夜进夜出）；推进入口＝大地图移动（格成本×2h 占位）/ 扎营 +8h / 旅店休整 +8h。
- 日夜映射数据外置：`environment.json` times `from_hour`（昼 6 / 夜 18，跨午夜环回）→ `EnvDB.time_for_hour`；Sandbox 日夜优先级＝地图显式 > 战役时钟 > 默认昼。
- 调度表首个入驻＝恢复结算：roster 带伤全员每小时 +1 HP（占位）；HP≤0 不自然恢复；医生在岗 ×2。

**营地职务（M6，框架）**
- `jobs.json` 五职：`medic` 医生（in_use）/ `cook` 厨师 / `smith` 工匠 / `guard` 警卫 / `scout` 情报官（均 ⏳planned）。
- 指派＝`WorldState.camp_jobs` `{job_id: unit_uid}`（随档）；**一人一职**（兼任自动撤原职）；在岗校验＝在册 ∧ 非重伤休整中。
- 加成承载 🔒＝改「每小时速率」；唯一已接消费端＝WorldClock 恢复 ×`MEDIC_REGEN_MULT`(2.0 占位)。
- UI：Overworld 顶栏「🏕 职务」面板（每职一行＋人选下拉、重伤者标注、指派即写档）。

**地点系统（M7）**
- 三层分工（瓦片=地点 🔒 2026-07-13）：类型/服务定义＝`locations.json`；实例（谁在哪）＝**瓦片派生**（terrains.json `location_type`，地图 `locations` 字段＝按格注记 id/label/图/对话——派生单源 `LocationDB.derive_locations` → [模块_大地图.md](模块_大地图.md)）；运行时态＝`WorldState.location_cleared_at`。
- 类型：city（rest/trade/recruit/smith）/ village（rest/trade）/ ruin（site，respawn 0＝一次性）/ lair（site，72h 刷新）。
- 据点刷新 🔒＝惰性判定（`site_ready` 读时算，不占时钟调度）；`site_respawn_in` 倒计时文案。
- 服务 `rest` 已接：−20💰 +8h（占位）→ 推时钟＋全员回满（重伤 `injured_until` 照计，旅店治不了）；trade/recruit/smith ⏳planned 灰显。
- 讨伐闭环：`BattleSetup.context{location_id}` → 战斗透传 → `collect_result` → `apply_result` **战胜才** `mark_location_cleared`（战败/弃战不落账）。
- 金钱：`WorldState.gold`（`START_GOLD=200` 占位，随档）；顶栏 💰。
- Overworld 消费：落格索引 / 名字标签+肃清灰纱（地点长相＝瓦片美术）/ 悬停状态 / 抵达自动进入·原地重进（途经不进）；`dialogue_id` →「💬 交谈」（M8）。
- 编辑器地点层＝注记编辑（第 6 图层，地点增删走地形层画瓦片）→ [模块_编辑器.md](模块_编辑器.md)。

**M5 三处铺垫全部落地**
- ① **击杀统计**：`Unit.last_hit_by`（命中即记）→ `_handle_deaths` 记 `_battle_kills{proto_id, by_uid}` → `apply_result` 累入 `ws.kill_stats`（按 proto_id）——经验归属与情报解锁**共用同一份记录**。
- ② **permanent 透传**：`_add_effect` 的 `permanent` 已透传（死门/重伤在用）；食物「整场 buff」走同一机制＋战斗结束 `_clear_effects_and_buffs` 清场，全部现成。
- ③ **BattleSetup 纯数据可序列化 + `provisions` 挂点**已预留（暂不消费）；预设队伍＝可存的 setup 片段（可序列化白送）。

## 🟡 规划

### 情报/图鉴（信息＝战利品，非默认权利）
- 信息分层：物理可见免费（武器类型/持盾/护甲轻重/体型，初见即显）；隐藏需解锁（精确数值/技能机制/抗性表/隐藏特性）；**抗性表藏最深档**。
- 解锁＝战后按击杀记录（输入源 `ws.kill_stats` 已就绪）；未解锁项在敌方状态页显问号（**含武器装备栏**）。
- 图鉴＝情报官（scout）在职解锁**查阅入口**（解锁引擎独立运作）；非战斗态随时查阅。
- 编号 `codex_id`：unit_prototypes 加 int 编号、图鉴按编号排序；未遇不出现、**总量不可见**；⚠️ 铁律：编号一经玩家可见即冻结（图鉴上线前统一分配一次，此后只追加不重排）。
- 完全解锁（集齐全部层）奖励：形式待定。
- 消费端：`UnitStatusPanel` 按解锁层过滤问号化；分层元数据挂 `StatMeta`（哪 stat 属哪层，单一源）。
- 沙盒保持全知调试＝`WorldState.current == null` 边界 🔒（不挂档即不受影响）。

### 烹饪/食物（猫饭模型：战备增益非维持成本；不吃无惩罚）
- 循环：收集食材 → 营地烹饪（耗时＝`WorldClock.advance`）→ **战前选人阶段**吃 → **整场 buff**（permanent effect＋战斗结束清场，机制现成；挂点＝`BattleSetup.provisions`）。
- 食谱可收集；高级食谱需高级厨子。
- 厨子＝**烹饪熟练度域**（生活页，ProfDB 现成：阶段补正 `prof:` mods）＋ perk 池投资（高级食谱/高品质概率/**分量变大**＝烹饪 perk；perk＝技能编辑器条目、获取＝熟练度阈值）。
- 分量属性：决定惠及人数（大锅乱炖全员 vs 精致烩饭两三人）；分量 vs 强度取舍曲线待定（方向＝广而弱/窄而强真实选择）。
- 营地设施升级：提高每战可用食物数；数据挂载（随行辎重 vs 地点）待定。
- 战前选人界面：右＝花名册（**可保存预设队伍**＝BattleSetup 片段）/ 左＝出战列表 / 食物在此选用。
- 快捷料理兜底：战前用最便宜食材当场做全员简餐，加成极少聊胜于无；厨师能力略微增强。
- 食材获取：EventEngine `give_item` 动作＋宿主原语 `event_give_item` ✅ 已实装（落 `WorldState.inventory`；见 [模块_物品.md](模块_物品.md)「队伍背包」）。
- 库存模型 ✅ 已实装：`WorldState.inventory {tpl_id:count}`（可堆叠、品质＝分档 id、**不进 ItemInstances**、`.get` 零迁移）；食材/食物走同一背包。余项＝品质分档约定 / 容量扩容 / 战斗内使用（→ [模块_物品.md](模块_物品.md) 🟡）。

### 地点服务 / 职务余项
- trade / recruit / smith 服务 ⏳planned（待经济/招募池/词条铁匠轮）；据点专属战斗地图与守军（现指向 sandbox.json 占位）。
- cook/smith/guard/scout 职务效果接入（各随烹饪/耐久/遭遇/图鉴系统）；职务加成 扎营中 vs 行军中 生效差异待定。
- 表演（生活技艺）→ 营地疲劳恢复挂钩（远期；疲劳系统未立项）。
- 占位数值细则待敲定：恢复/重伤（休整时长/死门+3 保底 HP/重伤 debuff）、行程/扎营时长、休整/刷新成本。
