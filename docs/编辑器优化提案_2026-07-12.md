# 编辑器族优化提案（临时·**讨论档**·归宿＝逐条拍板后并入 路线图.md / 各模块下半，本体删除）

> 来源：2026-07-12 用户令「看一看几个编辑器有没有优化空间，功能上的，UI上的，各种方面的」→ 六镜头审查工作流
> （MapEditor / CharacterEditor / ItemEditor / SkillEditor+EffectEditor / 两工坊 / 外壳横切层）+ 主审去重合并排序。
> 与 [技术改进提案_2026-07-11.md](技术改进提案_2026-07-11.md) §3 已核对**不重叠**（重叠项已删、互补项行内注明）。
> 排序原则：**内容录入提速价值**优先（当前瓶颈＝内容量 ~15%，编辑器＝录入管线）；⚠ 标记＝实为 bug 而非改进。
> 用法：逐条拍板 ✅→开工 / ❌→删行。**前五条建议无论如何先做**（都是数据损坏/丢失路径）。

## 高优先

### ⚠ 数据损坏/丢失路径（五条，建议即刻修）

1. **[CharacterEditor] 等级编辑不走成长轨 + 保存把成长烘焙进 stats 覆盖（改级即错档）**
   - 痛点：①打开经 make_unit 走成长轨（CharacterEditor.gd:184→UnitFactory.gd:28-32），保存的 diff 基线却不含成长（UnitFactory.gd:116-124）——任何 level>1 原型（belooz lv5/bandit_boss lv3/bandit_cutthroat lv2）**打开后原样保存＝成长值整块烘焙进 proto.stats**，违背「stats 只写差异、调 races.json 能传导」🔒；②等级 SpinBox 裸设 u.level 不跑成长（UnitStatusPanel.gd:747-750）预览失真；③叠加＝改级即错档。test_chareditor 无 level>1 往返 case。
   - 建议：unit_to_proto 参照基线改「种族底值+成长轨走到 u.level」再 diff（成长步进与 make_unit 共用一份）；改级＝collect→按新级重实例化刷新卡片；补 level>1 打开即存零 diff 回归。〔半天〕
2. **[MapEditor] 跨图撤销可把旧图内容写进新文件**
   - 痛点：load_from_file 换图前压撤销快照（:3288-3289），_apply_snapshot 不回滚 current_path（:3120-3143）。复现：开 A→切 B→Ctrl+Z（画布回 A、标签仍 B）→Ctrl+S→**A 整份覆盖写入 B.json**。唯一能静默毁掉另一张图的路径。
   - 建议：load_from_file/new_map 成功后清空 undo/redo 栈（跨文档不留历史，标准语义），五行内改完。〔小时级〕
3. **[ItemEditor] 「物品大类」下拉切换静默丢弃整张表单**
   - 痛点：_on_kind_changed（:422-433）换 kind 只留 id/名/图标，其余全按骨架重置；无确认、切回不复原——误碰一次下拉丢十几项已填内容，脏守卫管不到。
   - 建议：换 kind 前非骨架内容弹确认；和/或 _kind_cache[kind]=_collect() 缓存离开态、切回恢复。〔小时级〕
4. **[SkillEditor] 公式值 mods 无锁定护栏——打开报转换错、保存把公式扁平化**
   - 痛点：SkillEditor.gd:518 float() 读 mod 值，遇公式对象（引擎 resolve_num 明确支持、:509 绿条还自己宣称可用公式）即无效转换；:755-756 收集落成扁平数**静默毁数据**。hits/riders 有锁定先例（:476-478），公式 mods 没有。apply_effect 的 chance 同型隐患（:539）。
   - 建议：照 hits 先例——检测非数值 value → 整块锁定只读黄条（先堵毁数据路径）；公式三段控件随 conditional_mod 表单一起做。〔半天〕
5. **[外壳] 窗口 X / Alt+F4 关闭绕过脏守卫**
   - 痛点：外壳只给「返回主菜单」挂了脏守卫（ListEditorShell.gd:61-62），点 X 直接退出（auto_accept_quit 默认 true，全仓无 WM_CLOSE_REQUEST 处理）——四个清单编辑器同时中招。
   - 建议：外壳 _ready 设 auto_accept_quit=false + _notification 拦 WM_CLOSE_REQUEST → 走既有 _confirm_discard；_exit_tree 恢复。一处改四editor同愈。〔小时级〕
