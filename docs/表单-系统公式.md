# 表单-系统公式

> 常驻·速查。公式＝当前实现（**引用＝文件+函数名，不带行号**——行号随重构漂移快，函数名稳定；2026-07-09 审查后改制），随平衡调整——改了公式回来同步。键名/术语 → [表单-专用术语.md](表单-专用术语.md)。

修正三层 / 有效值（`Unit.effective_stat_f`）：
```
有效值 = 面板 + Σflat + 面板 × Σpct/100      同source同(stat,op)取高，异source累加
eff_mult(b) = max(0, 面板b/100 或 1) × Π(1+各源%/100)   同源取高，因子≥0   (Unit.eff_mult)
eff_reduce(b) = Π(1−各源%/100)                          同源取高，因子≥0   (Unit.eff_reduce)
```

命中（`BattleState._hit_chance(attacker,target,skill)`，🔒§10.6 2026-07-07；⚠ 决策32 2026-07-13 扩充）：
```
命中率 = clamp( (技能基准命中hit + acc桶 + 技巧 − 闪避−灵活) × eff_mult(hit_eff) × eff_reduce(eva_eff) × 地块因子 , 5, 95 )
技能基准命中 = 武器技能 attack 块 hit 字段（%·flatten 透传顶层·缺省0零回归）——逐技能定基准（横扫低/刺击高）
acc/eva 人身底0：acc桶=角色命中修正（武器/饰品 mods+熟练度 stage_mods+特性——mod 性质装备即生效）、修正落点承载闪避
sure_hit=必中：跳过整个命中对抗（命中/闪避是加减对抗、可破100，必中直接无视）
```

判定序 命中→格挡→暴击：格挡 roll<block_rate→注入 block_power(全域%减伤，招架取高)；
暴击 cr = max(0, crit_rate(招式/武器) + 技巧×0.5 − 受击方运气)
cmult = (crit_dmg + 运气×0.5)/100（🔒 2026-07-08 运气加爆伤；crit_dmg 默认 **120**，未暴=1）。
回合序 = `Unit.initiative()` = speed面板(底0,装备/buff落点) + floor(灵活/2)。（🔒 2026-07-08 减半修订；闪避仍吃满灵活）

输出伤害（`BattleState._resolve_compute`）：
```
输出 = ( effective_stat_f("atk") × coeff × cmult × aeff × ohf + 伤害补正flat(不吃效能) ) × rrate
coeff=技能系数(普攻≈1,AoE<1)   aeff = eff_mult("atk_eff") × 攻方地块攻击效能
ohf = 副手因子(🔒 决策5 阶段3b)：hit weapon_source=="off_hand" 且副手非盾 → offhand_eff/100
      (底50, 单手精通perk≤75) × hit 自带 offhand_factor(偷击0.5, 缺省1)；主手/缺省=1
rrate = 反应系数(🔒 决策31)：hit 带 atk_rate（借机注入 REACTION_RATE=0.75 占位）；普攻缺省=1
```

普攻构成 + 借机反应（🔒 决策31，`BattleState.attack_segments/attack_ap_cost`＋`Sandbox._do_attack/_resolve_aoo`）：
```
段构成 = [主手段] + (dual_strike≥1 ∧ 副手非盾武器 → [副手段 weapon_source=off_hand])   两段独立掷骰
攻击 AP = 连携 DUAL_STRIKE_AP=1(占位) / 单段 skill_ap_cost(主手bws)     _can_attack/_ai_plan 同口
借机 = 普攻构成逐段 ×REACTION_RATE(0.75 占位, atk_rate 键注入)   连携借机=0.75×两段自动成立
```

减伤链 全乘算（`CombatResolver.resolve`）：
```
G = max(0, 1−block_power/100) × def_factor           整击一次
def_factor = max(0, 2−def_eff/100) × 守方地块防御效能
抗因子 = max(0, 1−抗/100)                             抗>100→0免疫；<0→>1放大

非穿甲→先进甲：
  到甲 = max(0, 输出×ratio×G×甲抗因子 − 甲固减)
  ≤池: 池−=到甲   破甲: 溢出=到甲−池;池=0; 到血=max(0, 溢出×人抗因子 − 人固减)
穿甲(p)：人部分=输出×p→到血=max(0,人部分×G×人抗因子−人固减)；甲部分=输出×(1−p)走上
无甲：到血 = max(0, 输出×G×人抗因子 − 人固减)
```

异常施加 + 强韧豁免（`BattleState._try_inflict_state`）：
```
applied = randf×100 < inflict.chance
效果带 fort_will/fort_body → fort=对应强韧值; fort_roll=randf×100; shrugged = fort_roll < fort
净施加 = applied 且 未shrugged        豁免时机：遭受时1次 + 每回合开始1次；ignore_fort 跳过
```

死门（`Sandbox._door_turn_check` / `Checks.check_flat`，🔒§10.6 改版 2026-07-07）：
```
1d20 + luck + floor(body_fort/5) vs DC     DC=5/10/15/20/25…(每回合+5)
过+1/不过−1；被命中−1   门条−3~+3：−3倒下(铁人真死/否则重伤离场)，+3爬回(HP保底1)
```

士气 骨架v1（`BattleState._morale_add` / `_morale_turn_tick` / `Unit.init_vitals`）：
```
初始 = clamp(25 + resolve, 0, 50)（🔒 二次修订 +1/点；Unit.init_vitals）
损失 = −max(1, |Δ| − floor(resolve×0.5))   单次保底1     全程钳 0~50
事件：命中+2(被格挡0)/失手−1（_resolve_compute）；击败者+3、真死同侧全场−5（_handle_deaths_state）
回合开始：邻敌>0 → −clamp(邻敌−邻友,0,6)；无邻敌 → 向25回归±1   （二者取一不叠加）
档位(Unit.morale_band) = morale/10：0~9崩溃 / 10~19动摇 / 20~29稳定 / 30~39高昂 / 40~50狂热
档位判定(✅2026-07-08) = Unit.morale_combat_mod()：−10/−5/0/+5/+10 → 命中平加(_hit_chance+面板命中率行) + 伤害 atk_eff×(1+n/100)
```

技能熟练度（`ProfDB` / `Unit.gain_prof` / `BattleState.grant_combat_prof`）：
```
阶段阈值 = 0/100/300/600/1000（生疏/娴熟/老练/专家/大师）  大师计量满值 MASTER_XP_CAP=1500
战斗涨值 = 基值(攻击10/格挡6/挨打2) × clampf(1.0+0.2×等级差, 0.1, 2.0)   挥空也算练习
资格闸门 REQ_STAGE=3（老练）：资格看 prof_xp 不看装载
```

等级/成长/加点（`Unit.gain_exp/_apply_level_growth/apply_attr_pick`，🔒§10.1/§10.6；战后结算）：
```
LEVEL_CAP=20（🔒 二次修订 2026-07-08）  exp_max×1.2/级(占位)
天赋 1(默认)/3/6/9/12/14/18(满)  技艺槽 1/4/8/11/16(满)  属性点 2/5/7/10/13/15/17/19/20(9节点×2=18点·可同投)
自动轨（growth 数组循环＝按新等级%长度取值）：人 HP[1,0]每2级+1→50·双韧+2/+2→38
  鸟妖 HP[1,0,0]每3级+1→41·意+2→38·肉+1→19 | 蜥蜴人 HP[1,2]交替→73·意+1→19·肉底5+2→43
种族底值：HP 40/35/45  移动 人4/鸟4(飞6)/蜥3(水4)  视野 5/6/4  技巧 10/12/8  灵活 10/14/6  运气 5/3/3  决心 0/0/4

每点效果（增量统一+1）：技巧 1命中+0.5%暴击 | 灵活 1闪避+0.5先攻(floor) | 运气 −1被暴击+0.5%爆伤 | 决心 1初始士气+0.5损失抵抗(floor)

格挡休眠（🔒 决策31）：block 两键 equip 源查物品——盾恒计；手持武器(slot=main/off_hand)须
  weapon_block≥1 才计（Unit._block_source_active）；防具/饰品与非 equip 源恒计
```
