## ✅ 已实现

### 功能
- **Overworld 场景**（M4）：左键=移动指令 → Dijkstra 最小成本路径 → 逐格落位、每格 `advance(成本×HOURS_PER_COST=2h 占位)` → 评估 `enter_tile`（chance/冷却/全局间隔）+`timer` → 行进动画。**移动＝时钟推进 🔒**（时间仅在移动/扎营时流动）。
- **扎营** +8h（占位）；日夜＝时钟推导 → 顶栏「第 X 天 HH:00·昼/夜」+ EnvDB tint 夜幕叠层。
- **自动存档**：移动完成/扎营/返回菜单 → `auto` 槽。**current 生命周期契约 🔒**：返回主菜单＝退出战役清空 `WorldState.current`（防战役档污染沙盒）。
- **战役入口**（StartMenu）：新开局=`WorldState.start_new()`（第 1 天 8 点）→ Overworld；继续=读 `auto` 槽 activate（无档置灰）。
- **schema**：`map_type`(overworld/battle，缺省 battle 旧图兼容) 进 MapIO，编辑器/沙盒透传保真；深水/墙对空 tags 队伍＝天然屏障（`PARTY_TAGS` 预留船/坐骑）；通行成本单一实现 `TerrainDB.move_cost`（与战斗侧共用）；河阻断/桥·路折扣 `_move_cost_between`。
- **编辑器「环境」日夜下拉**：第 0 项「跟随时钟」=不写 `time` 键（运行时按战役时钟推导）；显式昼/夜才落键。
- **WorldSim 动态单位 🟡 v1**：商队/巡逻/兽群/游团，**玩家移动＝世界回合**（budget 累积制，速度=`hours_per_cell`）。四行为 `trade_route`/`patrol`(猎杀 hunts 派系＝d4+power 摩擦战+敌对追击)/`wander`/`hunt`；追上玩家（同/邻格）→`BattleSetup.context{world_unit_uid}`→战胜覆灭/败·弃战=冷静期 12h 占位；一次推进至多一场。`Overworld._advance_world`＝推钟→世界回合→表现 统一入口；画布 token（派系色+字形+敌对红环）。
- 默认大地图 `maps/overworld/world.json` 24×16 + 3 示例触发器；由 `tools/gen_overworld_map.gd` 再生成（**唯一官方再生成路径，勿删**）。

### 代码架构
| 类/文件 | 关键成员 |
|---|---|
| `Overworld.gd` | `_travel`/`_advance_world`(推钟→世界回合→表现)/`_move_cost_between`(河/桥/路)/扎营/声望·职务·地点面板 |
| `OverworldCanvas.gd` (extends HexCanvas) | 队伍金 token+目的地标记+WorldSim token/悬停 |
| `WorldUnitDB.gd` + `data/world_units.json` | 动态单位类型注册表 |
| `WorldSim.gd` | `tick(ws,hours,world)`（宿主鸭子接口，headless 可测） |
| `WorldState` | `party_col/party_row`(-1=首进 BFS 落位)/`world_units`(实例随档) |
| `tools/gen_overworld_map.gd` | world.json 生成器（道路 overlay+边线河+桥） |
| 测试 | `test_overworld.gd`（寻路/耗时/落位，不碰玩家 auto 档 🔒）/`test_worldsim.gd`（生成幂等/budget/商路/追击闭环/冷静期/摩擦战） |
