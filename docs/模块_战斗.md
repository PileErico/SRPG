## ✅ 已实现

### 功能

**回合框架（🔒 单 AP + 移动力）**
- round/turn 双层+速度序：`_sorted_by_speed` 读 `effective_stat("speed")` 大→小、**同速我方/友方优先**；走完一轮 `round_num++` 重排
- turn 始：AP 刷至 `effective_stat("AP_max")`、移动点清零（`Unit.refresh_for_turn`，兼冷却 −1）
- 移动预算：移动点>0 用剩余；=0 且有 AP→**提交时**才 1 AP 转一批移动力（`effective_stat("move")`）；余点可续走、turn 末作废
- 速度中途变化即重排：`notify_speed_changed`→`_resort_pending`（只重排未行动区、保当前行动者）
- 选单驱动：左键任意单位弹 `PopupMenu` **只列可用项**（当前可控单位：攻击/技能/移动/起飞·降落〔harpy 1AP 切地空=换地形+主副手〕/角色状态/回合结束；其它单位只列角色状态）；左键空地=只含结束回合
- 失能跳回合（`has_state("incapacitated")`）→ [模块_技能.md](模块_技能.md)；死门单位检定后跳过行动（见下）
- 胜负：`_handle_deaths` 移除阵亡（保行动者下标、行动者亡 deferred 推进）→ `_check_battle_over`（敌全灭胜/友全灭负；**死门单位算存活** 🔒）→ `_end_battle` 横幅 + **R** `_restart_battle` 重开（从地图 units 重建）

**移动 / 寻路**
- 可达集=Dijkstra（`_dijkstra` 前驱树 `_came_from` 重建路径）；步成本 `_move_cost_at` tag 驱动（`passable_by` 门槛+`cost`+`tag_cost` 取优、−1 不可进、绕占格）；`_effective_move`＝图级 terrain_overrides ?? 全局 TerrainDB
- 提交 `_commit_move`：滑动动画 `_animate_path`（可 await——玩家即发即忘/AI 串行；动画期屏蔽输入）
- 飞行态视觉：悬空因子 `air_t` 0↔1 Tween 起降（`_animate_fly_toggle`，纯 cosmetic）+ 正弦漂浮（错相）+ 固定地面投影 `_draw_ground_shadow`；仅场上有飞行单位才连续重绘

**判定序（🔒 命中→格挡→暴击→输出→减伤；模型 `_resolve_compute`/宿主 `_resolve_one` 掷骰+日志）**
- 全程 `effective_stat(_f)`（1 位小数；整数版供出手/AP/可达）；命中率=clamp((武器命中+技巧−闪避−灵活)×hit_eff×eva_eff×地块因子, 5, 95)（🔒 §10.6）；暴击=max(0, 招式crit_rate+技巧×0.5−对方运气)、爆伤=(crit_dmg120+运气×0.5)%（🔒 二次修订）；回合序=`Unit.initiative()`（speed＋floor(灵活/2)，🔒 减半修订）
- **eff 效能桶**：`eff_mult`（增益 Π(1+%/100)）/`eff_reduce`（减免 Π(1−%/100)）——乘算、异源互乘、同源去重取高、每因子 ≥0
- 输出=atk×coeff×暴击×atk_eff（+补正 flat 不吃效能）；全域 G=max(0,1−block_power/100)×def_factor（=max(0,2−def_eff/100)×守方地块因子，100 中性/≥200 免疫）
- **CombatResolver 分量化减伤链**（纯数学/无 RNG/不 mutate）：`components=[{lane,damage_kind,ratio}]`——普攻单分量先进甲；穿甲 `armor_pen` p 拆人(p)/甲(1−p)；逐分量过甲抗 `armor_res_*`/人抗 `res_*`+固减 `dr_flat_armor/human`；破甲溢出**保留原 damage_kind** 再过人层；抗性因子=max(0,1−抗/100)（>100 免疫/负抗放大）；damage_kind 白名单 `RES_SUFFIX`（physical→phys、元素含 holy→nature、未知告警回退物理）
- **地块 effect 惰性接入**：`TerrainDB.active_grants`（按占据者 tag 过滤 `when`）→`_terrain_eff_factor` 映射四效能桶（evasion→eva/accuracy→hit/attack→atk/defense→def）对称接全，飞行态经 `when` 免疫；当前内容仅森林掩蔽（闪避效能+15%）
- 施加异常 `_try_inflict_state`（概率×强韧豁免；DoT turn 末 `_apply_turn_end_effects`）与 buff↔modifier 桥 → [模块_技能.md](模块_技能.md)

**攻击指令**
- BAS=主手武器 `attack`（恒读主手 🔒；无武器徒手默认）→ [模块_技能.md](模块_技能.md)；距离/AP 消耗由 skill 给
- 攻击模式：单体标 range 圈、直线 AoE 标 6 方向 spoke（`_enter_attack_mode`）；`_attack_targets` 直线取线上单位、`friendly_fire` 连友军；`_is_hostile`＝我方/友方 vs 敌方/中立，跨侧敌对
- 攻击动画+音效 `_play_attack_anim`（玩家/AI 共用）：lunge 冲撞退回 + 受击整棋闪红 `_flash_units` + `_sfx`（cosmetic，判定先算）

**ZOC + 借机**
- ZOC=单位周围一圈，作用敌对移动者（`_in_hostile_zoc`/`_first_zoc_owner`）；**进入即停**（Dijkstra「ZOC 终点」不外扩、起点豁免）——玩家/AI/范围预览同一套
- 离开起点判借机 `_zoc_on_leave`（玩家 `_commit_move`+AI `_ai_step_toward` 共用）→ `_resolve_aoo` 复用判定序（不耗拥有者 AP）：命中=本次移动作废、被闪/被格=放行；每 round 每「拥有者→移动者」一次（`zoc_triggered`）；借机可致死；失能单位不行使 ZOC/借机

**敌方 AI（基础版 + 三警觉）**
- 行动循环 `_run_enemy_ai`（await 串行，`AI_THINK_DELAY`/`AI_ACT_GAP` 便于观看）：未激活=休眠结束回合；激活后 `_ai_one_action`——够攻击距离有 AP→打最近敌对（复用 `_do_attack`），否则 `_ai_step_toward` 朝最近敌对走一步（挑可达格最靠近、不能更近收手）
- 三仇恨触发 `_ai_update_aggro`（数据驱动字段 `ai_threat`/`ai_region`/`ai_group`+`ai_aggroed`，可组合）：① 视野感知（进 `sight`+LOS 即警觉，受环境修正）② 区域触发（玩家踏进 `aggro_regions[id]`，地图 regions 闭环）③ 连锁（`_ai_set_aggro` 组内递归）；激活持续不回眠、首激活记日志

**感知 P1：视野 / LOS / 三态迷雾 🔒**
- `sight` stat 走 `effective_stat`；LOS：`_hex_line`（cube 插值+微 epsilon）+`_has_los`＝中间格 `blocks_sight` tag 即挡（**只地形挡、单位不挡、终点格不挡**）
- 团队视野：`_vis_visible`（我方/友方可见格并集）+`_vis_seen`（曾见只增·唯一必存历史）；`cell_fog`→0 黑/1 灰/2 常态；重算挂开战/落位/阵亡三处；`_unit_hidden_by_fog` 藏敌
- 重塑战术：AI 警觉①视野驱动；攻击 targeting 须可见+LOS（只能打看得到的）；悬停/最近敌预览跳过迷雾单位；按 **V** 切全知 `omniscient`（默认关=真实体验 🔒）

**感知 P2：环境（日夜 + 天气）🔒**
- `EnvDB`+`data/environment.json`：天气 `{id,label,sight(flat),tint?,fx?}`（晴/雨/雾/雪/沙暴/雷暴）、日夜 `{id,label,sight_mult,tint}`（昼×1.0/夜×0.5）
- 天气机：地图 `environment:{time,weather_table}`——`_setup_environment` 开战摇/`_tick_weather` 每 round −1 到期重摇/`set_weather` 触发器定点变天（duration 后回表）
- 挂载 `_apply_env_modifiers`：天气=flat 修正挂全体 `source=env:weather`（AI 警觉+玩家迷雾一并生效）；日夜=最终乘子——`_effective_sight(u)=Unit.effective_sight(_time_sight_mult)`＝**所有加减在前、夜×0.5 最后** 🔒；视觉状态：`blind`→视野 0、`nightvision`→夜间乘子提回 ≥1（`has_vision_state`，装备/特性/buff 任意来源）
- 夜晚 tint 全屏滤镜 `_night_overlay`；HUD 非「昼·晴」显「环境：夜·雨（余N）」；调试键 **V** 迷雾/**N** 昼夜/**C** 天气（右下角常驻提示）；战斗不耗世界时间·战中日夜冻结 🔒 → [架构.md](架构.md) Meta 决策 4；天气 VFX 叠层 → [模块_地图美术.md](模块_地图美术.md)
