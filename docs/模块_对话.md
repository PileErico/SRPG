## ✅ 已实现

### 功能

**数据（`data/dialogues.json`＝对话单一源；schema 同步维护于其 `_note`）**

| 结构 | 字段 | 语义 |
|---|---|---|
| dialogue | `id,label,nodes[]` | 首节点＝`nodes[0]`（入口约定）；坏 id/空对话＝警告＋直接 finished |
| node | `id,speaker,side,portrait?,text` ＋ `next` 或 `choices` | 无 choices＝纯演出，点击任意处推进 `next`；有 choices＝分支（点击不推进、必须选） |
| choice | `text,next,set_flags?,rep?` | 选中先落效果再跳转：`set_flags` 写 `ws.flags`；`rep`＝`{faction:delta}` 经 `FactionDB.add_rep` 累加（钳 [-100,100]） |

- 示例数据：`dlg_merchant`（纯演出，大地图游商触发器）/ `dlg_elder_astra`（分支 set_flags＋rep empire±，挂阿斯特拉城「交谈」）。

**DialogueUI（通用对话控件，一份三场景共用）**
- **播放核心 ⟂ UI**：`start/advance/choose` 纯逻辑（headless `new()` 即测、不进树 `_ready` 不跑，UI 刷新全 null 守卫）；UI 进树 `_ready` 才建。
- UI＝全屏模态吞输入：压暗层＋底部对话条＝左右立绘（说话方点亮、另一侧记忆上次立绘变暗〔VN 惯例〕、右侧镜像）＋说话人＋正文＋选项按钮/「▼ 点击继续」。
- 效果落点 `ws`＝WorldState；**无档（纯沙盒）＝效果跳过仅警告**；结束发 `finished` 信号自毁。

**三触发场景（唯一接口＝EventEngine `dialogue` 动作 → 宿主原语 `event_dialogue(id)` 单一缝）**

| 场景 | 接线 |
|---|---|
| 大地图事件 | `Overworld.event_dialogue`；行进中触发＝`_travel` 暂停 `await finished` 播完再走 |
| 地点交谈（据点 NPC） | 地点面板「交谈」直调（`locations.dialogue_id`）→ [模块_营地后勤.md](模块_营地后勤.md) M7 |
| 战场内（火纹式） | `Sandbox.event_dialogue`（需求预判「唯一有额外接口成本」的场景，实际＝一个原语十行） |

- EventEngine 注册表加 `dialogue` 动作 → 编辑器触发器表单自动跟上（注册表数据驱动，零编辑器改动）。

**坑记录 ⚠️**：DialogueUI `_ready` 用 `set_anchors_preset` 只改锚点不动 offsets → 已进树时保住 0×0 假死；须用 `set_anchors_and_offsets_preset`。

### 代码架构

| 类/文件 | 职责 | 关键成员 |
|---|---|---|
| `DialogueDB.gd` | 对话注册表（DB 范式 preload＋static） | `all_dialogues`/`dialogue(id)`/`node(dlg,node_id)`（节点线性扫，量级小不建全局索引）/`first_node` |
| `DialogueUI.gd` | 播放核心＋全屏模态 UI＋选项效果 | `start(id,ws)`/`advance`/`choose(i)`/`is_active`/`current_node`·信号 `finished`（自毁） |
| `data/dialogues.json` | 对话单一源 | schema＝`_note` |
| `EventEngine.gd` | `dialogue` 动作注册（表单数据驱动） | `execute_action`→宿主转发 |
| `Overworld.gd` / `Sandbox.gd` | 宿主原语（new＋add_child＋start） | `event_dialogue(id)`（大地图行进 await / 战场内） |
| `FactionDB.gd` | 选项 rep 唯一写口 | `add_rep`（钳制/默认值在它那）→ [实现现状.md](实现现状.md) M9 |
