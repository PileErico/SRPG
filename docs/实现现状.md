# 实现现状（地图编辑器）

> 本文档只记录“目前已经实现的东西”，随实现更新。旧的 `地图编辑器规划.md` 已过时，不再维护。

## 概述
- 引擎：**Godot 4.6.2 stable（mono 版）**，但本工程是**纯 GDScript**（不含 C# 代码）。
- 形态：`D:\1战棋` 下的**独立工程**，**主场景＝开始菜单 `StartMenu.tscn`**（见「启动流程」）；地图编辑器 `MapEditor.tscn` 为另一独立入口场景（`.bat`/VSCode 任务单独启动）。
- 网格：**flat-top（平顶）六边形**，**odd-q 偏移**（奇数列向下错半格）。
- 渲染：`gl_compatibility`（兼容性渲染器）。

## 地图文件格式（JSON）
```json
{
  "format_version": 2,
  "grid": "hex_flat_oddq",
  "width": 15,
  "height": 15,
  "tiles": [
    [ {"terrain": "plain", "variant": "grassland"}, {"terrain": "forest", "variant": "forest"} ]
  ],
  "regions": [
    { "id": "guard_room", "label": "守军房", "color": "#A24BD5", "cells": [[3,4],[4,4]] }
  ]
}
```
- `tiles[y][x]`：共 `height` 行、每行 `width` 个。
- 每格只存 `terrain`（战斗属性类型）+ `variant`（外观）。**tags 不入每格**，按地形定义查表得到。
- `grid` 标明坐标系（平顶 odd-q）。
- `regions`（`format_version` 2 起，**可选/向后兼容**）：命名区域列表，每个 = `{id, label, color, cells:[[x,y]…], kind?, faction?}`。**`kind` 区分区域类型**（缺省＝`aggro`，向后兼容）：`aggro`＝AI 仇恨触发区（沙盒读它填 `aggro_regions`，敌人 `ai_region` 引用）；`deploy`＝玩家**部署区**（沙盒读它填 `_deploy_cells`，限制玩家单位只能放区内）。将来可加 `objective`/`hazard` 等类型，框架不变。无 `regions` 字段 = 空。
- 加载时做了容错：缺格/坏格回退为默认地形（草原），未知地形在画布上渲染为**品红**以便发现；区域 `cells` 加载时**过滤越界格**；尺寸超上限（50）先钳再建 `tiles`（不再出现 tiles 比 width/height 大的不一致）。

## 地形定义（外置于 `terrains.json`）
> 这是编辑器与战斗的“地形真值”。编辑器启动时从 `res://terrains.json` 读取；
> 文件缺失/损坏会回退到内置兜底并告警。编辑器只用 `label/color/accent/decor/tags`，
> `move` / `effects` 字段留给战斗（sandbox 已在用）。
> **理念**：配置服务于需求——不是按配置反推系统，而是按战斗需求调配置。通行/成本/效果一律 **tag 驱动**（与「tag 统一判断」一致）。

**绘制规则：每格只有两色 —— 底色 `color` + 纹理线条色 `accent`。纹理一律为单色线稿（描边、不填充）。**

|---|---|---|---|---|---|---|

### 战斗属性（`move` 通行性+成本 / `effects` 地块效果）🔒

**`move` 块（tag 驱动的通行性与成本）**
- `passable_by`：`"all"`=任何单位可进 / `"none"`=不可通行（如「墙」地块） / `[tag,…]`=仅含其中之一可进。
- `cost`：基础通行成本。
- `tag_cost`：`{tag: 成本}`，单位带该 tag 时**取更优（最小）**。
- 单位的「移动型 tag」（地面/飞行/灵体）写在 `Unit.tags`；基础兵种 = `["ground"]`。

**`effects` 块（站在该格的单位获得的效果）**
- 每条 = `条件 when → 改动 grant`，**伤害结算时惰性读取**（不材质化成持久 buff 对象，最简）。
- `when.occupant_lacks_tags`：占据者缺这些 tag 才生效（如森林对飞行态不生效）。
- `grant`：`{stat, layer(效能/补正…), percent, nature(buff/debuff)}`——以「修正对象」语义进入攻防管线（载体=占据者、来源=地块）。

| 地块 | passable_by | cost | tag_cost | effects |
|---|---|---|---|---|
| 草原/荒原 | all | 1 | — | — |
| 森林 | all | 2 | flying→1 | 森林掩蔽：闪避效能 +15%（飞行态不享受 = 敌命中最终 ×0.85） |
| 山地 | all | 3 | flying→1 | — |
| 浅水 | all | 2 | flying→1 | — |
| 深水 | 仅 flying | 1 | — | — |
| 道路 | all | 1 | — | — |
| 灌木 | all | 1 | — | — |
| 丘陵 | all | 2 | flying→1 | — |
| 沙地 | all | 2 | flying→1 | — |
| 雪地 | all | 2 | flying→1 | — |
| 废墟 | all | 2 | flying→1 | — |
| 墙 | **none（不可通行）** | — | — | — |

> 注：旧的 `solid` / `move_cost_ground/air` / `hit_factor` 标量已被本结构取代（森林的 `hit_factor 0.85` 现由「森林掩蔽」效果在伤害时算出）。

**✅ 编辑器可改地形 move 数据（全局，2026-06-30）**：地图编辑器地形层→选笔刷→「地形数据」区编辑该地形（全局，写回 `terrains.json`）：① 移动成本 SpinBox；② 通行（任何 `all` / 不可 `none` / **限定tag** 复选地面·飞行·灵体→ `passable_by:[tag…]`）；③ **`tag_cost`**（地面/飞行/灵体各一行：启用 CheckBox + 成本 SpinBox，如森林 flying→1，不勾＝无该键）。`TerrainDB.save()`（`_root` 保留顶层 `format_version`/`_note`）/`reload()`；`palette()` 是 live 引用 → 编辑器改完沙盒同进程即生效。`effects`（地块特殊效果）的编辑器编辑＝**用户暂缓、先不做**。

| `Ctrl+S` | 保存（有文件覆盖，无文件弹另存为） |

> **适配窗口**：「适配窗口」按钮把整张地图缩放居中铺满画布（`HexCanvas.fit_to_view`，留边距、钳进 0.2×–4×）；新建/加载后自动适配一次（`request_fit`，待布局尺寸就绪在 `_draw` 里执行）。

## 编辑器 ↔ 战斗：共享同一张地图 🔒

- **唯一战斗地图 = `res://maps/sandbox.json`**（常量 `MAP_PATH`，编辑器与 Sandbox 各持一份同名常量）。闭环：**编辑器启动即载入它 → 编辑 → `Ctrl+S` 写回 → 打开 Sandbox → 立即看到改动**（已 headless 验证：改图后沙盒 `tiles` 读到对应地形）。
- 编辑器仍是通用编辑器：`新建`/`另存为`/`加载` 照常处理任意文件；只是默认打开 / 保存目标是这张战斗地图。
- Sandbox `_load_map()` 读 `MAP_PATH`（缺失/损坏 → 回退全草原，永远能跑）；**出生点越界保护**：地图被改得比出生坐标小时把单位钳进界内（`push_warning` + clamp，不崩）。

## MapIO + 单位进地图（schema v3）🔒
> 「编辑器/沙盒合并」阶段 0+1 的产物（规划见 [编辑器合并规划.md](编辑器合并规划.md)）。把地图读写收成单一入口、并让单位成为地图数据。

**`MapIO.gd`（地图读 / 写单一入口）**：static 单例（仿 DB，`preload` + 静态函数，不用 class_name）。`read_file(path)→{ok,format_version,width,height,tiles,regions,units}`（失败 `{ok:false}`）、`to_dict(...)`、`write_map(...)`、`grassland(w,h)` + schema 常量（`FORMAT_VERSION=3`/`GRID`/`MAX_W/H=50`/默认草原）。**取代** `MapEditor.load_from_file`/`save_to_file`/`to_json_dict` 与 `Sandbox._load_map` 各自分叉的解析——**统一尺寸钳制策略**（旧坑：编辑器钳到 50、沙盒只 `max(1,…)` 不钳上限，同一大图两边读出不一致）。`tiles` 逐格兜底、`regions`/`units` 原样透传（各方按自己内存形再转）。已 headless 验证 v1/v2 旧图读写往返 + 全格地形不回归。

**地图 JSON 升 `format_version` 3**：新增可选字段 **`units:[{proto, col, row, faction}]`**（`proto` = `Sandbox._unit_to_proto` 输出 + AI 字段；`faction` 覆盖 `proto.default_faction`）。**向后兼容**：旧 v1/v2 图无此键 = 空，读端 `.get` 兜底。`regions` 字段不变。

**单位进地图（沙盒侧）**：

## Game 统一宿主：一个场景双模式 + 内存试玩 🔒
> 「编辑器/沙盒合并」阶段 2 的产物。决策 A1（一个场景 + `mode` 切换）+ B1（内存直传试玩），见 [编辑器合并规划.md](编辑器合并规划.md)。

**`Game.gd` / `Game.tscn`（新入口，`StartMenu`「编辑器（编辑 · 试玩）」→ 它）**：顶部模式条（主菜单 + ✎编辑 / ▶试玩 互斥 tab），把 `MapEditor` 与 `Sandbox` **作为子场景同时实例化、叠放在同一容器**，按 `mode` 切 `visible` + `process_mode`（隐藏方 `PROCESS_MODE_DISABLED`，停其 `_process`/`_input`，避免快捷键/动画串台）。**子场景间零回调耦合**——Game 单向调 `_editor.to_json_dict()`（取编辑器内存地图）/ `_battle.load_from_memory()`（喂战斗）。

**内存直传试玩（免存盘）**：
- `MapIO.normalize(dict)`：从 `read_file` 抽出的「校验 + 钳制 + 逐格兜底」，供文件读与内存装载共用。
- `Sandbox.load_from_memory(map_dict)`：按内存地图字典重置到布置阶段——设 width/height/tiles/regions/units、`_setup_regions`、清场上 units、**roster 收回待命（跨试玩保留玩家自带军）**、`_spawn_map_units` 重落预置单位、回合状态归零、`_enter_deploy`。

- **② 伤害分量化**：抽 **`CombatResolver.gd`**（纯数学）——输出 → `[{lane:armor_first/human, element, ratio}]` 分量 → 逐分量减伤链（甲抗 `armor_res_*` / 人抗 `res_*` 按元素、甲/人固减 `dr_flat_armor/human`、破甲溢出**保留原元素**再过人层）→ 汇总落血。`_resolve_one` 按 `armor_pen` 拆人/甲分量（普攻单分量）。**验证**：对上 spec 验算（输出50/甲抗50%/池20/人抗20% → HP−4·护甲−20）；无甲无抗时与旧逐位一致；删旧 `_apply_damage`。
- **③ buff↔modifier 桥**：`_add_effect` 挂效果时若带 `mods` 就同挂进 `modifiers`（`source="buff:名"`），到期(`_tick`)/清除(`_cleanse`)/重开(`_clear_effects_and_buffs`)按 source 摘，改四维自动 `recompute_derived`——冰减速/雷麻痹类**改属性的异常**可落地。
- **键约定 🔒**：人抗 `res_*`（挂人）/ 甲抗 `armor_res_*`（挂防具、默认0）/ 固减 `dr_flat_human`·`dr_flat_armor`（默认0），抗性均为**百分比**（value 50 = 减 50%，用 `op:flat` 加百分点；`op:pct` 对 base=0 的抗性无效）。**`def_eff` 已接进 G**：`def_factor = max(0, 2 − def_eff/100)`（100 中性 / 120→×0.8 / ≥200 免疫，下限0安全）——default 100 故对现有内容无变化。**接口就绪、待元素轮铺内容**：具体元素技能·附魔武器·`triple_vs`·地块effect→eva_eff 未铺（见 [路线图.md](路线图.md)「技术债」）。当前单位默认无甲无甲抗、def_eff=100，故新链对现有内容无行为变化。
- **防御类 stat 可被技能增幅 🔒**：甲抗 `armor_res_*` / 格挡率 `block_rate` / 格挡性能 / `def_eff` 等都是走 `effective_stat` 的普通 stat，技能挂 buff（经 buff↔modifier 桥）即可临时增幅、战斗即时生效。已 headless 验证：一条 buff 给 +50 def_eff/+30 甲抗/+20 格挡率 → 减伤 factor 1.0→0.5、buff 甲抗真进减伤链（护甲承伤 40→28）。

**回合框架（简陋版，已实现 `Sandbox.gd`）**
- round/turn 双层 + **速度出手序列**：`turn_order` 由 `_sorted_by_speed`（读 `effective_stat("speed")`，含修正，大→小；**同速我方/友方优先**）排出；`active_index` 指向当前行动单位；走完一轮 → `round_num++` 并重排序列。
- **行动经济**（按 [单位系统设计.md](单位系统设计.md) 已锁定的「单 AP + 移动力」）：turn 开始 AP 刷新到 `AP_max`、移动点清零。
- **顶部行动顺序槽**（`TurnOrderBar`，宽=屏幕一半·居中）：显示「**当前回合剩余 + 下一回合全员**」的条目序列（回合标记 + 单位头像/名字/速度），由 `_turn_sequence()` 算好后 `_refresh_turn_bar()` 推给 bar。当前行动者永远排在最左（紧跟当前回合标记）、金框高亮；**结束回合** → 该槽向下渐变移除、其余左滑补位、下一位成为最左金框。
- **速度中途变化即重排**：`notify_speed_changed()` → `_resort_pending()`（保留已行动者与当前行动者，仅对「之后未行动」按新速度重排）→ 立即刷新出手序列与行动顺序槽（槽内滑动到新位）。目前尚无改 speed 的来源，接口已就位（加 speed 修正后调它即可）。
- **地图棋子·行动顺序三态（火纹式，`_has_acted`/`_is_active_unit`）**：本 round 内 **已行动**（turn 已结束）→ 棋子整体**变灰**（`ACTED_FILL` + 图标 `ACTED_ICON`）；**当前可行动**（active_unit）→ 圆外**绿描边** `CAN_ACT_RING`；**尚未行动** → 无装饰。一眼区分谁动过、谁在动、谁还没动（与顶部顺序槽互补）。
- **飞行态视觉（`_draw_unit` + `_draw_ground_shadow`）**：棋子**抬离地面**（上移 ≈0.72·HEX_SIZE——必须 > 棋子半径，否则浮起的圆会盖住自己的影子）、原格落一枚**扁椭圆地面投影**（**固定贴地、不随漂浮上下动**；抬得越高影子越小越淡、给透视感，但有下限保证看得见），并做**轻微上下漂浮**（`_fly_phase` 正弦、每单位按格号错相，不齐步——漂浮使 token 与固定影子的间距来回变化，强化悬空感）。漂浮由 `_process` 驱动，但**仅在场上存在飞行单位时才连续重绘**（否则保持事件驱动、不空转）。
- **起飞/降落过渡（非瞬切）**：抬升量由**悬空因子 `air_t`(0贴地↔1全悬空)** 缩放——起飞/降落时 `_do_toggle_fly` 即时切游戏状态（地形/主副手），视觉上 `_animate_fly_toggle` 用 Tween 把 `air_t` 在 0↔1 间缓动 `FLY_ANIM_TIME`(0.28s，SINE 缓出/缓入)，`SandboxCanvas._draw_unit` 读 `editor.fly_factor(u)` → token、影子、漂浮幅度都按 `air_t` 插值升起/落下。纯 cosmetic、不占用移动/攻击的 `_animating` 串行通道；再次切换会 kill 旧 tween 从当前高度续接。地/空一眼可辨，配合主副手切换（地撕裂/空抓取）。
- **选单驱动操作**：左键点中**任意单位** → 鼠标处弹 `PopupMenu`，**只列当前可用项、隐藏不可用项**（`open_context_menu` 动态构建）：仅「**当前行动的可控单位（我方/友方）**」才有【攻击（有 AP 才列）/ **技能**（有已学主动技能且 AP>0 才列）/ 移动（有预算才列）/ **起飞·降落**（`can_fly()`＝harpy 且 AP>0 才列，`_do_toggle_fly` 耗 1 AP 切 ground/flying＝换地形+换主副手攻击）/ 角色状态 / 回合结束】；**其它单位（非当前回合 / 敌方 / 中立）只列【角色状态】**——角色状态页**只经该菜单项打开**（不再一点单位就弹窗）。回合结束 → 推进到下一单位 / 新 round。
- **主动技能使用（首条已实现 🟡）**：选单「攻击」后、「移动」前的**「技能」子菜单**（`_skill_submenu`）列该单位**已学主动技能**；**冷却中/用尽 → 灰显 + 名后用阿拉伯数字标剩余冷却**。选中某技能 → `skill_mode`：棋子周围 `range` 圈**绿色**高亮（`RANGE_SKILL`）→ 点范围内**非敌方（含自己）** → `_do_skill` **扣 1 AP** + 进冷却 + 扣本战次数，按等级档治疗 + 清流血。**首条＝战场救治**（通用序列#1，主动、距离 1、治疗最大生命 10/20/30%、清「bleeding」、冷却 `7−智力×0.1`、每战 `1+智力×0.2` 次，均 floor·次数≥1）。技能数据 `data/skills.json`（`SkillDB`，仿 ItemDB）；已学态/冷却/次数存 `Unit.skills`；详见 [单位系统设计.md](单位系统设计.md)「主动技能系统」。**翼爪「撕裂」的流血改名「流血·翼爪」并带 `bleeding` 标签**（可被战场救治清除）。**当前占位演示**：比路兹开局设等级 5 + 预学战场救治 I（`_spawn_units`，正式数据接入后撤）。
- 行动顺序槽里**点头像** = 镜头切到该单位所在格；**鼠标扫过头像** = 在地图上高亮其所在格（青白色，区别于黄色地形悬停）——想看后续出手顺序就扫一遍，想知道具体位置就点。底部横向滑条做**细**（薄 stylebox）。
- **友方可控 / 敌方 AI**：**我方+友方单位由玩家操控**（`_is_friendly`，维肯也能走能打）；敌对方（敌方/中立）由 **AI** 操控（`_run_enemy_ai`，见下「敌方 AI」）。

**敌方 AI（基础版 + 警觉/仇恨，已实现）**
- **行动循环** `_run_enemy_ai`（`await` 串行：回合起 `AI_THINK_DELAY` 思考、**每个动作之间停 `AI_ACT_GAP`=1 秒**——移动→停 1 秒→攻击，便于观看）：先评估仇恨，**未激活=休眠按兵不动直接结束回合**；激活后循环 `_ai_one_action`——**进攻击距离且有 AP→攻击最近敌对**（复用 `_do_attack`），否则 `_ai_step_toward` 朝最近敌对走一步（复用 `_dijkstra`+`_path_via`+`_animate_path`，挑可达格里最靠近目标的、不能更近就收手），AP/移动力耗尽即收手 → `end_turn`。
- **三种仇恨触发（数据驱动，字段在 `Unit`：`ai_threat`/`ai_region`/`ai_group`/`ai_aggroed`；任一满足即激活、可组合，`_ai_update_aggro`）**：
  - **① 视野感知 `ai_threat`**（默认开，2026-07-01 改为视野驱动，见「感知系统」）：敌人进入其**视野 `effective_stat("sight")` 且视线 LOS 不被地形挡**就激活（原为「移动力+攻击距离」的威胁圈）；逐单位自动算，`sight` 可被夜/天气等环境修正。
  - **② 区域触发 `ai_region`**：敌人挂一个区域 id；**玩家踏进 `aggro_regions[id]`** 即激活（与本单位移动/攻击无关，"进房间惊动守军"）。**区域由地图文件 `regions` 字段读入**（`_load_map`→`_map_regions`，`_setup_regions` 转 `aggro_regions`、过滤越界格）——地图编辑器「区域层」画、沙盒据此触发，闭环已合。
  - **③ 连锁 `ai_group`**：组内任一被激活 → 全组连锁（`_ai_set_aggro` 递归）；与 ①② 任意组合。
  - 激活持续（不回休眠），首次激活记日志「X 进入战斗！」。每个敌方 turn 开始评估。
- **六边形距离** `_hex_dist`（odd-q offset→cube）供视野/寻路判距。当前花名册：**帝国步兵 + 帝国轻步兵都用视野感知**（默认 `sight`=5，进视野+LOS 即警觉）。区域触发(`ai_region`)、连锁(`ai_group`)机制均已实现、当前阵容未用（给字段赋值即开；区域在 `_setup_regions` 定义）。

**范围显示（移动/攻击范围，统一「范围层」`range_overlays`）**
- 画布按 `editor.range_overlays`（`[{reach,attack,move_color,atk_color}]`）逐层画：先攻击(浅红)再移动，移动盖在攻击上（`SandboxCanvas._draw_cells`）。`_update_overlays()` 按当前模式/悬停/Tab 重建该列表。
- **移动范围色按阵营**：**我方=浅蓝 `RANGE_MOVE_FRIENDLY`**、**敌方=浅黄 `RANGE_MOVE_ENEMY`**；**攻击范围统一浅红 `RANGE_ATTACK`**。
- **攻击范围 = 理论最远威胁圈**：`_compute_ranges` 以**一次移动动作(1 AP→一批移动力 `effective_stat("move")`)** 的可达格为移动范围，攻击范围 = (可达 ∪ 起点) 外扩武器攻击距离、去掉可站立格 = **「移动 1 AP 后再攻击 1 AP」能触及处**。
- **ZOC（控制区）可视化**：范围层里**敌方单位**带 `zoc`（自身周围一圈在界格），画布把这圈地块**填深红**（`_draw_zoc`，比浅红攻击范围更深、叠最上层）——预览敌方移动/攻击范围时，它身边一圈深红即其 ZOC。（友方暂不画。）
- **悬停预览（地图，敌我皆可）**：鼠标移到任一单位棋子上 → 显示**它**的移动范围+攻击范围（`update_unit_hover`→`_compute_ranges`，颜色按其阵营，敌方附 ZOC 红框）；移开/移动模式中让位。
- **移动模式（点「移动」后）**：默认显示**己方**(active 单位) 的范围（移动浅蓝 + 攻击浅红，用实际剩余 AP/移动点的可达 `_recompute_reachable`）+ **移动范围内的敌方 ZOC 自动标深红**（`_enemy_zoc_in_range`，无需按键，提示"踏进会被控制/离开要吃借机"）；按 **Tab** 再**叠加显示「距离最近的敌方单位」的移动+攻击范围**（浅黄，`show_enemy_preview`，`_input` 拦 Tab）。
- 选「移动」→ 进入**移动模式**；鼠标悬停可达格时即时画**带宽度的箭头丝带**（`_path_ribbon`：中心线先经 `_smooth` 做 Chaikin 切角柔化拐角，再左右偏移成丝带轮廓 + miter 斜接：深蓝描边（抗锯齿）+ 更浅半透明蓝填充、终点箭头用原方向；带宽用世界坐标≈半条六边形边、随缩放同比例；随鼠标换格实时更新）。
- **本次移动的预算规则**：移动点 `>0` → 用**剩余移动点**；移动点 `=0` 且有 AP → 用**一批移动力**（点「移动」只显示范围，**不立即转化**）。
- **可达集** = Dijkstra（`_recompute_reachable`，存前驱树 `_came_from` 供路径重建），步成本 `_move_cost_at(col,row,unit)` 按单位 tag 算：读地块 `move`（`passable_by` 门槛 + `cost` + `tag_cost` 取最优），`-1`=不可进入；绕过被占格。
  - 基础兵种（`tags=["ground"]`）：草原1 / 森林2 / 浅水2 / 山地3 / 深水不可进；飞行单位森林/浅水/山地→1、可进深水。
- **提交移动**（点**浅蓝**范围内目标格）：移动点 `=0` 时**此刻**把 1 点通用 AP 转成一批移动点（`+move`），再扣路径消耗落位；移动点有余可**反复选中→移动**续走，零头到 turn 末作废。
- **滑动动画**：提交后 token 沿路径逐格平移（`_animate_path`，可 `await`——玩家即发即忘、敌方 AI 串行等待；`create_tween` 每格 `MOVE_ANIM_STEP` 秒；动画期间 `_draw_unit` 用 `_anim_pos`、屏蔽输入），非瞬移。
- **选单定位**：弹窗用视口内坐标紧贴光标（`open_context_menu` 读 `get_viewport().get_mouse_position()`，按是否内嵌兼容桌面坐标）。
- 点范围外 / 右键 = 取消。平顶 odd-q 邻居：`NB_EVEN / NB_ODD`。

**ZOC 控制区 + 借机（已实现，设计 🔒 见 [单位系统设计.md](单位系统设计.md)「ZOC」）**
- **ZOC** = 每个单位周围一圈，作用于敌对移动者（`_in_hostile_zoc` / `_first_zoc_owner`，敌友按 `_is_hostile`）。
- **进入即停**：`_dijkstra` 加「ZOC 终点」——踏入敌对 ZOC 的格可达但不能从它继续外扩（**起点格豁免**）。玩家移动范围、敌方 AI 走位、范围预览都走这套，故都自动遵守 ZOC。
- **离开/区内移动触发借机**（`_zoc_on_leave`，玩家 `_commit_move` + 敌方 `_ai_step_toward` 共用）：因「进 ZOC 即终点」，一次移动里只有起点可能在 ZOC 内 → **只在离开起点时判一次**。取第一个本 round 未对该移动者触发过的拥有者打一次借机（`_resolve_aoo` 复用判定序 `_resolve_one`，不耗拥有者 AP）：
  - **命中（未闪未格）→ 本次移动作废**：移动力清空、留在原地。
  - **被闪 / 被格 → 放行**。
  - **每 round 每「拥有者→移动者」只一次**（`zoc_triggered`，每 round 清）：被一个敌人拦下后再花 1 AP 即可走（但会被同格的另一敌人拦）。一次尝试只触发一个拥有者。
- **借机可致死**：`_resolve_one` 返回 `{hit,blocked}` 供判定；移动者被借机打死则停下。若**当前行动者**因借机阵亡，`_handle_deaths` 走「行动者阵亡」分支（按需进新 round）并 `call_deferred("_begin_active_turn")` 推进。

**攻击指令（已实现：武器 attack skill + 判定序 + 战斗记录，全程读 `effective_stat`）**
- **基础攻击 = 武器 skill**：`Unit.basic_attack()` 返回主手武器的 `attack`（`coeff/range/ap_cost/aoe`…），无武器走徒手默认（range1/coeff1/ap1）。攻击距离、AP 消耗都由 skill 给（不再用固定 `ATTACK_RANGE/ATTACK_AP_COST`）。
- 选「攻击」→ **攻击模式**：单体 skill 标 range 圈；**直线 AoE** skill 标 6 方向的直线 spoke（`_enter_attack_mode`，平顶 odd-q 用 `_neighbor_in_dir` 逐格走）。
- 点攻击格 → `_do_attack(attacker, cell)`：`_attack_targets` 算命中单位 —— 直线 AoE 取该方向直线上的单位（`_line_cells`），`friendly_fire` 为真则**连友军一起打**；否则取该格敌对单位。扣 skill AP，逐目标判定，处理死亡，退出。
- **敌友判定** `_is_hostile`：我方/友方一侧、敌方/中立一侧，跨侧=敌对。
- **判定序**（`_resolve_attack` → 逐目标 `_resolve_one`，🔒 命中→格挡→暴击→输出→减伤）：
  - 全程读 `effective_stat`（装备/buff 加成进战斗）；命中率 `_hit_chance` = clamp(命中−闪避,5,95)%。
  - **输出 = 攻击面板 × 技能伤害系数 × 暴击倍率 × 攻击效能**（系数=skill `coeff`，如突刺·龙枪 0.85）。
  - **伤害补正**（`skill.bonus`，`_skill_bonus`）：flat 加在乘算链之后、**不吃效能**（如爪的 (力量+灵巧)×0.5）。
  - **属性吃 1 位小数**（`effective_stat_f`）；战斗记录用 `_numf`。
  - 减伤（✅ 2026-07-01 起走 `CombatResolver` 分量化链）= 全域 G（`max(0,1−格挡性能/100) × def_factor`，防御效能因子 `def_factor=max(0,2−def_eff/100)`，100 中性/≥200 免疫）后 `CombatResolver.resolve` 逐分量结算：普攻单分量先进甲；**穿甲 `armor_pen` 拆 人(pen)/甲(1−pen) 两分量**；逐分量按元素过 **甲抗 `armor_res_*` / 人抗 `res_*` + 固减 `dr_flat_armor/human`**，破甲溢出**保留原元素**再过人抗（抗性因子=max(0,1−抗/100)，>100 免疫、负抗放大）。
  - **施加异常**（`skill.inflict`，`_try_inflict`）：命中后按 概率×(1−异常抵抗) 掷骰，成功 `_add_effect` 挂 `Unit.effects`（同名刷新、不叠层）。**个人 DoT** 在该单位 turn 末 `_tick_turn_end_effects`（挂 `end_turn`）结算：流血=最大生命×5%/回合、持续 2 round、无视护甲、致死复用 `_handle_deaths`。
  - ⚠️ **剩**：转换分流 `convert`（分量格式已支持多元素、缺 skill schema 与 `_resolve_one` 侧构造入口）+ 元素技能/附魔/防具甲抗**数据内容**（管线就绪待填）——详见 [路线图.md](路线图.md)「技术债·战斗数值地基」剩内容清单。
- **攻击动画 + 音效**（`_play_attack_anim`，玩家/AI 共用）：攻方棋子朝目标方向**冲撞一下再退回**（复用 `_anim_pos`/`_animating`，`create_tween` lunge 0.09s + 退回 0.13s）；**撞击瞬间**受击方**整颗棋子（圆+图标）闪红** `FLASH_TIME` 秒（`_flash_units`：`_draw_unit` 红底 + 图标红 modulate + 顶上再盖一层半透明红，确保整体都红而非只露出的圆边）+ 播放音效（`_sfx` 播 `res://audio/attack.mp3`，`_load_audio` 优先已导入资源、否则直读 mp3 字节兜底）。判定/伤害仍同步先算，动画为 cosmetic。

## Meta 层 M1：持久化根基 + 物品实例化（2026-07-02 ✅）
> 需求依据 [meta层需求提炼_1.md](meta层需求提炼_1.md) §3.0（并列根依赖）；架构设计 [meta架构规划.md](meta架构规划.md)。决策 🔒：uid=存档域自增 int（unit/item 共用计数器）、时间=小时计数、沙盒不建档。

**M1a · uid / WorldState / SaveIO**
- `Unit.uid`（0=未分配临时）；`WorldState.gd`＝campaign 聚合根（静态 `current` 跨场景，仿 SandboxConfig；`mint_uid()` 共享计数器、无战役给临时 id；roster=活 Unit；clock_hours/ironman/flags/reputation；to_dict/from_dict）。
- `SaveIO.gd`（仿 MapIO）：`user://saves/<slot>.json`，save/load/list/delete，版本 `.get` 兜底。
- `UnitFactory.unit_to_campaign/unit_from_campaign`：proto ⊕ uid/HP/armor/equip_uids；**复原在 `make_unit` 之后覆写 vitals（绕开 `init_vitals` 注满）**——战损跨存档保留。顺手修 `exp_max` 不入 proto 往返的旧缺口。

**M1b · 物品实例化**
- `ItemInstances.gd`：uid→`{tpl_id, affixes[], durability(-1=未启用), condition, enhance_count}`；**合成视图 `view(uid)`＝模板深拷 ⊕ 词条并入 mods**。`ItemDB` 降为纯模板源（物品编辑器不变）。
