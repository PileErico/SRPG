## ✅ 已实现

### 功能

- **能力管线（SkillDB）**：`Unit.skills` 已学态 `{level,cd,uses}`；`learn_skill`（max_level 封顶）/ `skill_ready`（冷却+次数）/ `consume_skill`（进冷却+扣次数）/ `reset_skill_charges`（战斗开始重置）；冷却按本单位 turn −1（`refresh_for_turn`）
- **战斗施放**：选单「技能」子菜单（列已学主动能力；冷却/用尽/沉默灰显+数字标剩余冷却）→ `skill_mode` range 圈绿高亮选目标 → `_do_skill`（薄渲染壳）→ **`BattleState.apply_skill` 模型层结算**（阶段2 下沉 ✅ 2026-07-09：AP/冷却/次数消耗+效果块分派全在模型、结构化事件出、宿主只渲染——修「heal 违例在宿主」）
- **阶段2 引擎侧 ✅（2026-07-09）**：统一 schema 落地（`costs`/`cooldown{base}`/`uses_per_battle`/`max_level`/`target` 三旗/`requires_hands`/`effects[]` 块）；**双读取器**＝`SkillDB.skill_ap_cost`（costs.ap↔ap_cost 双键桥，7 个读点全切）+ `SkillDB.resolve_num`（标量/公式 `{base,per_stat,per_level}` 两吃，🔒 §2.4 数值边界：越界取末档/level0 取首档/空对象回 default）；`_valid_skill_target` **三旗 {enemy,ally,self} 分派**（旧 self_target 废弃，缺省={ally,self}）；SkillDB **写盘口** `save_skill/delete_skill`（replace_id 改名语义，仿 EffectDB）；v1 可跑块＝`heal`（%最大生命+cleanse_tags）/`apply_effect`（{effect,chance} 对象形，复用 `_try_inflict_state` 强韧豁免单一路径）；未知 kind 警告跳过（可编≠可跑护栏）；uses 无限哨兵 −1（决策18，波0 先行）
- **阶段3a BWS/EWS 引用制 ✅（2026-07-11，🔒 决策25/26）**：**BAS 并入技能库**——8 武器内联 attack 迁 skills.json BWS 条目（`tools/migrate_weapons_bas.gd` 幂等+自校验零漂移；通用招式按种类共用 bws_slash/stab/bash/unarmed、专属独立），武器 **`bws` 引用**（旧键 `bas` 双键桥）、`prefer` 上提武器级；`basic_attack()` 经 `Unit._main_weapon_attack` 单一取处（bws→`SkillDB.flatten_bws` 扁平 legacy dict、双读窗口回退内联、golden 伤害不回归）。**EWS 装备授予**：`ews: [{skill, requires:[{prof,value}…]}]` 每条复数 AND 解锁条件（技艺域+熟练度裸数值，跨页；空=装备即用）；运行态 `ews_state`（非已学不入 skills，战斗开始重置/turn 递减/**战斗快照白名单往返**·护栏#3）；战斗能力菜单 **EWS 置顶**（未解锁灰显+条件人话）；ItemEditor「武器技能」段（BWS 下拉 usable_as_bas 过滤/EWS 条件行+档位提示）；ItemTooltip 双读+EWS 陈列（顺手修 inflict 引用形显示空名）；lint 规则8 扩展（bws/ews/prof 引用完整性+内联残留窗口期提示）。**剩 3b**＝offhand_eff 副手惩罚+weapon_source 结算。**对抗审查修复 ✅（2026-07-11，5 根因）**：`apply_skill` 可跑块前置守卫（effects 无 `SkillDB.RUNNABLE_KINDS`〔heal/apply_effect〕块→拒发**零消耗**——堵「纯 attack 技能经能力路径白烧 AP」）；`flatten_bws` 无 attack 块→`{}`（堵幻影全额物理普攻，`basic_attack` 兜 UNARMED、tooltip/悬停同链回退内联）；能力菜单滤 usable_as_bas/纯 attack；`ews_entries` 同 id 去重改**已解锁优先**（跨源 OR vs 手位语义＝3b 待问）；ItemEditor 悬空 bws/ews/prof 引用「⚠ 悬空引用」保值项（勿静默剥）+EWS 下拉可跑块过滤+prefer 初值双读 attack.prefer；lint 新规＝usable_as_bas⇒含 attack 块（规则7）、EWS⇒含≥1 可跑块（规则8）
- **SkillEditor + EffectEditor ✅（2026-07-11，阶段2 收官）**：两编辑器均继承 `ListEditorShell` CRUD 外壳、标题栏分段互切（⚔能力库⇄✨效果库，脏守卫接管）、StartMenu「技能编辑器」入口。**SkillEditor** v1 可编块＝attack(单 hit+公式)/heal/passive_stat_mods/apply_effect/scripted；公式三段控件（基础值+缩放属性×系数+逐级数组，🔒 §2.4 无表达式解析器）；**存盘校验与 lint 规则7 对齐**（BAS 约束/三旗全 false/seq 撞格/per_level 长度/costs.ap 双键剥离）；**可编不可跑护栏**＝多 hits/riders 块锁定只读（红）、weapon_source/被动阶段4/scripted 未注册/round_end tick 未实现（黄条警示）；未编辑高级字段（aoe/bonus/ignore_*）保存原样保留。**EffectEditor** 全字段表单（duration_model 两模型/expire_timing/叠层/DoT·HoT/mods/on_expire_apply 连锁下拉·排自身防死循环）。**canonical 字节级往返**＝「duplicate 原条目+按键更新」保键序+未编辑字段；data/skills.json 已随手规范化成写盘口排版
- **首条能力内容**：`first_aid` 救护（3 级 15/25/35% 治疗+清流血；{ally,self}/range1/costs.ap1/cd2）——schema/三旗/resolve_num 验收条目
- **battlefield_heal 战场救治已删 🔒**（2026-07-06 属性重做 §7）；heal 语义已由 first_aid 经新 schema 重建
- **效果注册表（§10 阶段1A ✅）**：效果＝有 id 的 buff/debuff（`effects.json`）；`_add_effect_by_id` 同 id 刷新时长 / `stackable` 叠层≤`max_stacks`；无 id 匿名内联旧路径向后兼容（死门/重伤）；`hot_flat` HoT 回合末回血；`on_expire_apply` 两段式到期连锁（决策20）；`duration` 双形（裸标量 / `{base,per_stat}` 现只读 base，公式待阶段2 `resolve_num`）
- **失能状态机（§10 阶段1B ✅）**：`Unit.has_state(tag)` 扫活跃 effects tags（不污染 permanent tags）；`incapacitated` 回合跳过（不行使 ZOC/借机）；`fort_will`/`fort_body` tag→强韧豁免掷（遭受时+每回合；`duration_model:"resist"` 已可跑）、`ignore_fort` 穿透
- **buff↔modifier 桥**：效果带 `mods` 同挂 `modifiers`（source=`buff:<id>`），到期/清除/重开按 source 摘；防御类 stat（甲抗/格挡/def_eff）可被能力增幅 🔒
- **地基对齐（§10 阶段0 ✅）**：`damage_kind` 正字（element 废弃；`CombatResolver.RES_SUFFIX` 白名单+未知回退物理）；`refresh_for_turn` 改读 `effective_stat("AP_max")`；比路兹恒读主手+`set_airborne` 主副手 uid 对调；golden 伤害基线落地
- **能力三分类 tab 框架**（UnitStatusPanel）：通用（13 通用序列数据驱动）/ 第三页二选一＝具名 `char_*`→专属（占位）· 杂兵→职业＝天赋树（占位）
- **首条效果内容**：bleeding 流血（`fort_body` 归轨 / `dot_pct_max_hp` 5 / 2 回合 / 无视护甲）
