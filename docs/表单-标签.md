## 武器 — 持握 / 射程
> **🔒 校正（2026-06-30）：`main_hand`/`off_hand` 是【槽位】、不是【物品 tag】。** 单手武器可装任一手、双手武器占两手，故「在哪只手」不是物品的内在属性。槽位由 `EquipSlots.gd` 管；「强化副手武器 / 单手在副手削弱」等按【槽位占用】判（读 `equipment["off_hand"]`），**不靠物品 tag**。物品的**持握 tag = `one_handed` / `two_handed`**（天生武器 `innate` 无持握词条）。

| ~~`main_hand` / `off_hand`~~ | **是槽位、非物品 tag**（见上框，归 `EquipSlots`） | — |

## 效果 / 异常（写在 effect 对象 `tags`，供「按 tag 驱散/清除」）
| tag | 含义 | 状态 |
|---|---|---|
| `bleeding` | 流血类（回合末按最大生命%掉血）。带此 tag 的效果可被「清流血」类技能整批移除 | ✅ 已接入（流血·翼爪）|
| `incapacitated` | **失能**（眩晕/麻痹等）：该单位回合直接跳过——不行动即不行使 ZOC/借机（`Unit.has_state` 消费，Sandbox 跳回合）| ✅ 已接入 |
| `silenced` | **失语**：禁用带 `verbal` tag 的能力（`Unit.has_state` 消费）| ✅ 机制已接入 |
| `fort_will` | **意志系**（异常维度 🔒 [模块_属性成长_设计.md](模块_属性成长_设计.md) §5）：非物质异常——眩晕/恐惧/混乱…由**意志强韧** `will_fort` 豁免 | ✅ 豁免机制已接入 |
| `fort_body` | **肉体系**（异常维度 🔒）：物质异常——寒冷/麻痹/流血…由**肉体强韧** `body_fort` 豁免 | ✅ 已接入（流血）|

> 效果对象（`Unit.effects` 的条目）形如 `{name,kind,permanent,duration,dot_pct_max_hp,tags}`。`_add_effect` 从技能 `inflict.tags` 写入；`_cleanse_effects_with_tag(u,tag)` 按 tag 整批移除。**tag 统一判断**：将来任何流血变体只要带 `bleeding` 就被一并清除。
> **强韧豁免 🔒**：带维度 tag 的异常在「遭受第一时间」与「每回合开始」各掷一次豁免（成功率＝对应强韧值%；成功＝完全不受影响/立即挣脱）；效果引用可带 `ignore_fort:true` 无视强韧（两处豁免一并跳过）。不带维度 tag（一切 buff、死门/重伤等纯机制效果）不参与豁免。

## 角色身份 / 装备需求（✅ 已接入）

|---|---|

## 派系归属 camp（✅ 2026-07-03；派系＝tag）
> **派系归属做成 tag**（用户决议「阵营也作 tag 用」，符合 tag 统一判断）：`camp_<id>`，`<id>` ＝ `data/factions.json` 的派系 id。声望/敌对配置在 `factions.json`（FactionDB）、成员 tag+cn 在此。**区别于阵营立场**（player/ally/enemy/neutral，本关站哪边、关卡决定）——camp 是单位**内在**派系（帝国/流寇…），影响声望/敌对。角色编辑器「派系」下拉。
