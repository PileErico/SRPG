# 属性与成长系统 🔒

> 2026-07-06 设计定稿（逐条问答裁定）。定调句 🔒：
> **「必须经过努力锻炼和学习，才能步入正轨、成为独当一面的战士——而非超人。」**
> 成长＝横向（技艺/perk/装备选项）而非纵向数值膨胀；**敌我同规则、双方都不膨胀**，数值恒定可读（战棋质感）。
> 配套：[模块_技能_设计.md](模块_技能_设计.md)（perk＝技能条目）、[技能树_帝国士兵.md](技能树_帝国士兵.md)（职业树内容）、[模块_词条.md](模块_词条.md)（装备数值主载体）、[表单-标签.md](表单-标签.md)。

## 0. 一句话总纲 🔒

**不设维度主属性与派生公式层**。角色能力 ＝ **种族底值 + 四加点属性（§10.6）+ 装备 + 技艺熟练度 + perk**。等级＝解锁节拍器（20 级制三轨轮转，§10.1）——其中属性提升为受控小幅节拍、敌我同规则。

## 1. 等级 🔒

- 等级与 XP 照旧保留；**20 级制·三轨轮转**（天赋层/技能槽/属性提升，每级必得一物）——等级表与轨道汇总见 §10.1。
- 职业树到层解锁：到层即可选学 1 个（同层互斥、可跳层、同名覆盖）。
- 个人树（专属角色成长，有被动有主动，≠技艺）另列，不在本文展开。

## 2. 技艺（熟练度域）

**术语切割 🔒**：**技艺**＝本文的熟练度域（剑术/盾/烹饪…）；**技能**＝技能编辑器条目（skills.json）；**成长**＝个人树节点。三词严禁混用，UI/文档/schema 同此。

### 2.1 三页 33 域（30 基础＋3 风格派生）v1 🔒

| 页 | 域 | 备注 |
|---|---|---|
| **风格**（8） | 单手 → 双武器、双手 → 长柄、远程 → 火药武器、投掷、体术、格挡、盾、防具 | 火药武器含火枪（武器页不单列枪）；箭头＝派生域；格挡＝`style_block`（§10.3）；体术＝身体能力（§10.5） |
| **武器·基础**（10） | 剑、匕首、斧、锤、连枷、矛、弓、弩、戟、格斗 | 按武器 tag 聚合：含「剑」tag 的武器都涨剑熟练度；格斗＝徒手技术域（拟 `wp_brawling`，§10.5） |
| **武器·异种**（2） | 镰刀、太刀 | 镰刀前置＝双手+长柄；太刀前置＝剑+（单手 或 双手） |
| **生活**（10） | 追踪、谈判、冥想、采伐、烹饪、学识、医疗、加工、表演、潜行 | 加工囊括锻造/裁缝/修补；骑术不设；驯兽暂缓 |

- **前置文法**：`requires: {all:[...], any:[...]}`，可跨页引用（镰刀=AND、太刀=AND+OR 即首例）。
- **派生域＝阶段浮现**：默认不显示，前置技艺「过半」（锚定＝达到老练阶，🟡数值可调）后浮现、**自悟可学**（无需导师）；基础域＝师承（§2.5）。
- **前置＝一次性学习资格闸门** 🔒：学会后即独立技艺，可卸下前置域不受影响（D&D 转职式接力，而非叠加依赖）。

### 2.2 槽位与装载 🔒

- **统一槽池**（不分战斗格/生活格），5 槽；非战斗状态随时切换。
- **装载＝总开关**：装载中＝阶段补正+perk 全生效+熟练度可涨；卸下＝相关一切收益失效、熟练度冻结但**永不丢失**。
- 叠加装载＝可选深度（如 双手+太刀 同时生效、加成各异），深度换广度是真实构筑决策。

### 2.3 阶段与 perk 🔒

> 到阶双轨＝固定阶段奖励＋perk 行；perk 行规则（任选一/可空/非战斗自由切换）与「装载即基础效果」见 §10.2。

- 五阶段：**生疏 → 娴熟 → 老练 → 专家 → 大师**；恰好 4 次进阶＝每技艺 **4 次 perk 选择权**（每次进阶解锁一次）。
- 每技艺 perk 池 **> 4**（保证同域两个大师构筑不同）。三页所有域统一此规则。
- **perk＝技能编辑器条目**（passive_stat_mods / conditional_mod / reaction…全套块可用），获取渠道＝熟练度阈值——定义⟂获取分离的直接兑现，编辑器即 perk 量产工具。perk 池内容渐进入库（骨架先行）。

### 2.4 熟练度获取 🔒

- **一次行为同时喂养所有匹配 tag 的已装载技艺**（单手持剑挥砍＝单手+剑同涨；双持再+双武器）。
- 战斗行为权重：**攻击 ＞ 招架/格挡/反击 ＞ 挨打**。
- **威胁缩放（反刷屏）**：面对强敌快涨、面对弱敌趋于停滞；生产同构——高级素材/作业＝更多熟练度+更多疲劳+更高失败率（靠熟练度与 perk 克服）。
- 换装训练自带风险定价：用生疏技艺打强敌本身就是代价，无需额外惩罚规则。

### 2.5 学习渠道 🔒

三态：**未学**（槽里放不进）→ **已学**（可装载，生疏起步）→ **阶段成长**。

- **基础技艺＝师承**：向导师/组织（公会、M7 地点服务、M6「教官」营地职务）学习。
  - 导师门槛＝自身该技艺阶段达标（拟≥专家，🟡）且只教自己精通的技艺；NPC 导师与队内教官同规则。
  - **传授的是「已学」状态，熟练度永不可传授**——师父领进门，修行在个人。
  - 价格＝技艺基础价 × 系数（声望/派系/地区）；数值后置。
  - **内容护栏**：初始特殊角色出身自带基本盘技艺（公会补课＝另外的价钱）；招募单位差异＝已学清单+各自阶段（招募从刷数值变成猎取知识）。
- **派生技艺＝自悟**（§2.1）。
- 声望门槛＝高阶传授的天然闸（帝国声望不够，帝国军旗术没人教你）——挂 M9。

## 3. 基础值与种族 🔒

- 真值文件 **`races.json`**：`HP_max`、`move`、`speed`、`sight`、`acc` 底值、疲劳上限等基础面板值按种族给定，同种族底色趋同。
- **低斜率血量**：HP_max＝种族底值＋种族成长曲线（随级自动、幅度很低，§10.6 自动轨终表；写实系）。`per_char_level` 类被动（如帝国树·新兵操练）＝**刻意设计的例外、稀有品类**，内容侧严禁随手滥发。
- 生存成长的来源＝防具、词条、盾/防具技艺 perk、走位——学来的、买来的，不是升级送的；致命性全程恒定，死门全程有牙。
- **疲劳**：上限＝种族底值+perk；恢复＝perk+营地设施（表演/吟游类职务）。营地主动工作耗疲劳（被动生效不耗）。

## 4. 战斗数值取源（stat 键映射）🔒

管线：修正管线 stat 键/op/source 全开放字符串，**熟练度补正＝`prof:<域>` 来源前缀的 mods**，装载/卸载＝按前缀挂/摘；perk 走技能→被动 mod 桥。效能桶、减伤链、UI 骨架共用此管线。无 `STR`/`DEX`/`INT`/`STA`/`mag` 类维度键。

| 键 | 来源 |
|---|---|
| `HP_max` | 种族底值＋种族成长曲线（§10.6 自动轨） |
| `atk` | 底值 0；武器 flat mod + 熟练度 + perk |
| `acc` | 人身底 0；武器 mods 承载命中 + 技巧 + 熟练度 + perk |
| `eva` | 人身底 0；灵活 + perk + 词条 |
| `block_rate` / `block_power` | 底值 0；盾/武器提供 + 盾技艺 + perk（武器格挡须装载「格挡」域激活、装备来源取高，§10.3） |
| `crit_rate` | 无人身底率；招式/武器字段 + 技巧添头 + perk（§10.6） |
| `crit_dmg` | 全招式默认值 120 + 运气添头 + perk（§10.6） |
| `HP` `armor` `armor_max` `AP_max` `move` `speed` `sight`、四效能桶、`res_phys` `armor_res_phys`、`dr_flat_*`、`vision_state`、死门 | 非派生面板值；底值由 races.json 喂 |
| 熟练度表（域→数值+阶段） | 独立结构（不进 stats 字典）+ 存档（M1） |
| §5 四轨键 | 见 §5 |

- 公式形态：**攻击＝武器面板 ×招数系数(coeff)× 暴击 × 效能桶 + 补正 mods；防御＝防具 + 补正**。命中判定/减伤链走 `_hit_chance`/`CombatResolver` 骨架。数值细部 🟡 实现时调。
- 已知技术债：def_eff 与其余效能桶通道不对称。

## 5. 抗性与强韧 🔒

四轨，**人/甲分开计算**；**防具可拥有两种抗性、永不拥有强韧**（强韧来源＝种族+等级曲线+perk）。

| 键 | 名 | 管什么 | 机制 |
|---|---|---|---|
| `res_phys` / `armor_res_phys` | 物理抗性（人/甲） | 全部物理伤害 | 百分比减伤 |
| `res_nature` / `armor_res_nature` | 自然抗性（人/甲） | 全部元素伤害（**含神圣**） | 百分比减伤 |
| `will_fort` | 意志强韧 | 非物质异常：眩晕、恐惧、混乱… | 豁免掷 |
| `body_fort` | 肉体强韧 | 物质异常：寒冷、麻痹、流血… | 豁免掷 |

- **强韧豁免**：遭受效果**第一时间**掷一次（成功＝完全不受影响）；此后**每回合**掷一次（成功＝立即移除）。数值即豁免率。＝效果系统 `duration_model: resist` 的具体化。
- **弱抵抗哲学**：默认强韧≈0（难抵抗），来源＝种族 tag（免疫走 tag 不走数值）+ **等级自动曲线**（全种族固定随级提升，纯等级奖励不可加点，§10.6）+ 特定 perk + 装备词条（词条仅提供抗性，物品永不提供强韧）。
- 效果侧配套（tag-first，进标签词典）：异常效果打 **`意志系` / `肉体系`** tag 声明归属；不带维度 tag（一切 buff、纯机制效果）不参与豁免；**「无视强韧」＝效果引用字段 `ignore_fort`**（与 `chance` 并列）。
- 元素特异性弱点（狼人怕火）：**不走抗性轨**——走 (a) 异常侧（火攻施加「燃烧」肉体系异常）或单位专属逻辑（受 `element_fire` tag 攻击时豁免/抗性削弱），专项调整、现在不做。
- `dr_flat_*` 固减机制保留（词条系统未来大概率复用）。

## 10. 增补决议（2026-07-07）🔒

### 10.1 20 级制·三轨轮转 🔒（2026-07-08，已实装）

每级必得一物，三轨轮转：**a＝天赋层 / b＝技能槽 / c＝属性提升**（Lv1 起点自带 a1+b1）。

| Lv | 解锁 | Lv | 解锁 |
|---|---|---|---|
| 1 | 天赋1＋槽位1（默认） | 11 | 槽位4 |
| 2 | 属性点 | 12 | 天赋5 |
| 3 | 天赋2 | 13 | 属性点 |
| 4 | 槽位2 | 14 | 天赋6 |
| 5 | 属性点 | 15 | 属性点 |
| 6 | 天赋3 | 16 | 槽位5 ←槽位满 |
| 7 | 属性点 | 17 | 属性点 |
| 8 | 槽位3 | 18 | 天赋7 ←天赋满 |
| 9 | 天赋4 | 19 | 属性点 |
| 10 | 属性点 | 20 | 属性点 |

汇总：**天赋 7 个** Lv 1(默认)/3/6/9/12/14/18 · **技能槽 5 格** Lv 1/4/8/11/16（不膨胀）· **属性点 9 节点 ×2＝18 点** Lv 2/5/7/10/13/15/17/19/20，**允许双点同投一属性**；增量统一 +1/点（强弱在每点效果 §10.6 终表，不在增量）；**20 级毕业**。

- c＝**四属性加点**（技巧/灵活/运气/决心，§10.6）——固定幅度＋自由选择＝零随机零 SL 🔒。
- c 是受控小幅数值节拍；「敌我同规则、双方不膨胀」不变（敌人烘焙侧同节拍走原型×等级纯函数 §6）。
- 实现落点（已实装）：`Unit.LEVEL_CAP`＝20、`ATTR_PICK_LEVELS`＝[2,5,7,10,13,15,17,19,20]、`Unit.prof_slot_capacity`/`UnitStatusPanel.PROF_SLOT_LV`＝[1,4,8,11,16]；天赋树层表＝[1,3,6,9,12,14,18]（随天赋树实装）；经验曲线＋熟练度涨值的等级差系数（±0.2/级）——可用，数值轮再校。

### 10.2 到阶双轨＋perk 行规则（增补 §2.3）

- **到阶＝两份收益**：①**阶段奖励**＝固定 mods（现 `stage_mods`，装载中自动生效）；②**perk 行解锁**。
- **perk 行规则**：每到一阶开**一整行**候选；行内**任选其一**、允许空着不选；点选即生效、再点取消；**非战斗随时切换/取消**（与装载同律）；行内候选数不固定（随各域 perk 设计）。
- 装载仍是总开关：卸下域＝阶段奖励+已选 perk 全失效（选择保留，重装载恢复）。
- **装载即基础效果**：装载本身可解锁基础效果（首例＝格挡域激活武器格挡 §10.3）——技能三层价值：装载=解锁基础 → 到阶=固定奖励 → perk=自选特化；生疏阶段装载自此有价值。
- UI 落点：技艺页 L3 详情区双栏——一侧 perk 行格、一侧当前阶段奖励。
- **矛·娴熟首行 🔒（2026-07-15）**：`立矛`＝2AP 架势至自身下一 round 的 turn 开始，ZOC 扩至2；立矛＝**架势类（stance tag）**技能（🔒 2026-07-17 决策37）——命名层是矛、本质是架势，架势类基础律＝**位移即解除**（主动/被推同律），将来体术类 perk（架势 AP 减免/移动不破架势）挂此类别。每 round 每拥有者第一次有敌方以实际移动进入其 ZOC 时自动引用当前矛 BWS（主动/强制进入同律，生成不触发；普通借机照常；双手持矛该次最终伤害调整×1.2〔`final_damage_factor`，非反应系数〕）；迎击按**反应段**结算——`is_reaction:true` 不写 atk_rate〔伤害零衰减〕、照常判定击退（借机同律，🔒 2026-07-17 涌现口径），位移请求在反应动作末就地 flush（不泄漏进后续攻击动作）、反应链由 limit 有界；立矛走**通用 Reaction 系统**〔决策36 v1，真值→[模块_技能_设计.md](模块_技能_设计.md)〕——effects.json `reactions[]` 纯数据驱动，引擎无立矛专名。`逼退`＝所有动态 `skill_spear` 攻击判定获得15%被动击退概率；命中且未格挡后，与招式主动击退概率相加合并单掷，再直减目标肉体强韧。

### 10.3 格挡物品化（细化 §4）

- `block_rate`/`block_power` **人身底值归零**（races.json / Unit 默认字典）＝纯物品承载。
- **盾＝天生激活**：格挡 mods 无门槛（举盾即挡，新手保底防御）。
- **武器＝数据在武器、技能只是开关**：格挡数据写在武器条目 mods 上，须装载**「格挡」域**（`style_block`，风格域）才激活。机制＝mod 条件字段（拟 `requires_prof`），与「triple_vs 条件修正」同一套条件 mod 基建。
- **聚合＝装备来源按键取高**（`block_rate`/`block_power` 各自取最大）：语义＝"只用一件器械格挡"——单手不高于盾、双手剑可率高而减伤低、双持不翻倍。buff/阶段奖励/perk 来源照常叠加其上（器械定底子、训练叠上去）。
- 数值护栏：双手武器占双手装不了盾，武器+盾并存只有「单手+盾」与「双持」两形——取高规则天然覆盖。

### 10.4 徒手＝天生武器（实装·可替换，2026-07-07 定形）

- **`weapons.json`「拳脚」条目**（人类天生武器）：attack 行为＝数据承载（数据/代码分离）；mods 携带徒手攻击性（flat atk）；**tags 定案＝`unarmed`＋`melee`＋稀有度（拟 `common`）＋innate 标记，刻意无持握 tag**（「天生武器无持握词条」既有规则）→ 双持判定（两手皆持 `one_handed` 武器）**天然排除拳**，零特判。图标已有（拳套绑绷带自绘，与武器图标同风格）。
- **人身 `atk` 底值＝0**——徒手攻击性由拳脚条目 mods 承载（§4）。
- **实装形态 🔒**：拳＝**真实例、真占主手槽**（`races.json` 拟加 `natural_weapon` 字段：human→拳脚，其余种族各指其条目；单位生成时自动装备）。装武器＝拳被顶替下槽；卸下武器/主手空位＝拳**自动回位**。
- **天生武器两档**：**锁定型**＝innate 现行为（比路兹双爪：永不卸下**也不可被顶**）／**默认型**＝人类拳（不可手动卸下、**可被武器顶替**）。`equip_instance` 的 innate 挡顶逻辑需按档分流。
- 天生武器**不可缴械**；被缴械者主手空位 → 拳自动回位（风格化玩法保底）。
- **徒手向奖励的判定**＝当前攻击来源（主手武器或天生武器）带 `unarmed` tag——拳套/爪套＝带 `unarmed` tag 的常规武器，即体术/格斗流的"换武器"成长轴（徒手→拳套→魔改爪套）。
- 体术格挡＝拳脚/拳套条目的格挡 mods＋域激活，与 §10.3 同构。
- **出拳规则（2026-07-07）**：普攻恒读主手 🔒——主手永远非空（武器或天生武器二选一）；**副手持盾/武器默认不影响出拳**，若有影响写在对应 weapon skill 条目里（例外数据驱动，不立全局规则）；脚/膝/摔＝格斗域 EWS 解锁的攻击方式（行为层），不建模为副手槽位。
- 🟡 待定（双持/副手规则轮再裁）：副手武器 mods 现行全局生效（主手空拳也吃副手武器的 atk 加成）——「攻击数值是否跟随攻击来源」暂不收紧、先留痕。

### 10.6 人身成长定形：双轨＋四加点属性（2026-07-07 🔒，落实 §10.1 的 c）

**归属判定表 🔒**（任何新词段先问归属、再定成长轨——归属决定一切）：

| 所有者 | 词段 | 成长轨 |
|---|---|---|
| 人·自动轨 | `HP_max`、`will_fort`/`body_fort` | 随等级自动（下），加点不可选 |
| 人·加点轨 | 技巧/灵活/运气/决心 | c 节点加点（§10.1） |
| 人·静态底值 | `speed` `sight` `move` `AP_max`、acc/eva 底板 | 种族给定，不随级 |
| 技术 | acc/eva/crit_rate 的成长 | 熟练度+perk（人身只有底板/添头） |
| 招式 | `coeff` 动作值、`crit_dmg`（120＝全招式默认值）、暴击率（无人身底率） | 技能条目字段 |
| 外物 | `atk`、甲三件套、甲抗/固减、格挡两键 | 装备（人身归零） |
| 调制层 | 四效能桶 | buff/地块/熟练度阶段 |

**自动轨**（纯等级奖励，写实向"老兵底盘"）：
- **HP**：种族成长曲线（人类很低；将来矮人类偏高但整体不高；数值见种族终表）——"变肉但没变很肉"（生物普遍高攻低防，武器强化攻、防具弥补防）。⚠️ HP 基准（40 量级）的伤害/护甲全标尺连锁重校＝数值轮记账（§8）。
- **双强韧**：全种族固定随级提升（幅度见种族终表）——高级角色更能扛异常、更容易从鬼门关扛过去。
- 速度不随级涨（种族底值；回合序公式见下）。

**加点轨**：Lv 2/5/7/10/13/15/17/19/20 共 9 节点，每节点 2 点（共 18 点，允许双点同投一属性，增量统一 +1/点）；**固定幅度零随机**（反 SL 🔒）；四属性底值＝种族给定（见终表）、不随级自动提升；敌人加点烘焙进原型×等级纯函数（§6）。

| 属性 | 键 | 战斗职责①② | 生活（第二职责，钩子随系统后到） |
|---|---|---|---|
| 技巧 | `finesse` | 命中添头 · 暴击率添头 | 加工/医疗类精度作业 |
| 灵活 | `agility` | 回合速度 · 闪避 | 潜行/采伐类身手作业 |
| 运气 | `luck` | 免被暴击 · 全 d20 检定补正（含死门） | 生活检定天然覆盖（同一条规则） |
| 决心 | `resolve` | 气势/压力检定修正 +1/点（衰减检定·满气势 AP 检定 → [模块_战斗_设计.md](模块_战斗_设计.md)「气势系统」🔒） | 意志类坚持/抗压检定 |

**数值定案 🔒（2026-07-07 晚，已实装）**：
- 四属性底值按种族给定（见终表）；加点增量统一 +1/点（强弱在每点效果四件套）。
- **公式**：命中 ＝ 武器命中＋技巧 − 闪避 − 灵活（acc/eva 人身底 0，武器 mods 承载命中、修正落点承载闪避）；**暴击无底率**＝招式/武器 crit_rate ＋ 技巧×0.5 − 受击方运气（钳底 0）；**回合序**＝speed 面板（底 0，装备/buff 落点）＋**灵活/2 向下取整**（`Unit.initiative()`；闪避仍吃满灵活——压双重叠加、给 speed 装备词条留权重；鸟妖灵活底 14 配偶数取整）；死门 debuff 的减半作用于灵活。
- **自动轨**：HP/双强韧按种族分化随级成长（races.json `growth` 块，见终表）、当前 HP 随涨；**20 级封顶**（超额经验冻结）。

- **暴击伤害基础值＝120%**（🔒 全招式默认；实际爆伤＝120＋运气×0.5）。
- 成长节奏数据形＝races.json `growth` 值支持**数组循环**（按新等级 % 数组长取值：人 `[1,0]`、鸟妖 `[1,0,0]`、蜥蜴人 `[1,2]`），面板永远整数。

- **〈水生动物〉`aquatic` tag 🔒**：蜥蜴人种族**常驻**自带（无需任何切换，水陆自由）——深水对其可通行、深/浅水成本恒 1（普通人深水禁入、浅水 2；语义上是半水生，图上无水下故从简）；对照：鸟妖 `flying` 是**起飞后才有**的切换态。
- **条件移动力机制 🔒**：races.json `move_overrides`（`when_self_tag` 查自身 tag / `when_tile_tag` 查脚下地块 tag）——条件命中＝**替换种族基础移动力**（随地形块变动的基础属性）、装备/词条修正差量照叠；实装 `Unit.move_allowance(tile_tags)`，预览/购点/AI 同口径。
- 命中语义补记（用户例）：熟练度/技能/perk 的命中类增益**通常应条件于「使用匹配武器的能力」时生效**（如 剑熟练度增益只在用剑系能力时计入）——现阶段 stage_mods 装载即全局挂，按〔装备 tag ∩ 能力 tag〕条件化归技能系统阶段 4 conditional 一并做（勿单独造轮）。
- 武器命中重灌（🟡 占位 30 档）：长剑/龙枪 acc+30、狼爪 +32、拳脚 +25、比路兹双爪各 +15（防双爪全局叠加双计——副手 mods 全局生效的已知待定 §10.4）。
- 基线互殴观感：命中 ≈25%（拳）~45%（剑 vs 空手）、暴击 ≈0%（技巧10×0.5−运气5 恰好抵消，加点后才浮现）——刻意的"新兵打不准也不暴"，数值轮再调。

- **双栖规则 🔒**：属性必须先有战斗增益（哪怕很小）才有资格入列；生活增益是第二职责，不设纯生活属性。
- **物理/信息判据 🔒**：属性只作用于信息与身体机能，**不豁免物理效果**（掩蔽"砍不着"是物理，不可被感知类属性穿透）；固定规则（灌木邻格显形等）不做成属性伸缩数值。
- **幅度纪律 🔒（添头原则）**：属性的意义＝"十级老兵拿新武器不等于一级新人"的**跨武器地板**，专精天花板永远在熟练度；每点幅度已定（上表）、18 点允许同投一属性（有意放宽）——「武器熟练度持续供给命中、闪避主要靠加点」＝命中侧天然随熟练度成长对冲极限闪避流。
- **防具-灵活闭环 🔒**：防具 mods 降低灵活（→回合速度+闪避双惩罚）；防具域（`style_armor`）的职责就此明确＝**缓解甲的灵活惩罚**（穿甲的技术）。
- **死门检定 🔒**：`1d20 ＋ 运气 ＋ 肉体强韧/5`，DC 逐轮 **5/10/15/20/25** 递增（自动轨与加点轨在鬼门关汇合——等级越高越扛、点命硬真命硬）；±3 条/被命中−1 等现行机制沿用与否＝实现时裁。

### 10.5 格斗／体术拆分

格斗与体术分立两域——徒手流与持械者同构（剑+单手 ↔ 格斗+体术）：

- **格斗＝武器页域**（拟 `wp_brawling`；match_tags＝`unarmed`/`weapon_claw`）：徒手战斗**技术**；熟练度解锁更多徒手攻击方式＝**EWS 首个试点**（细则仍 §8 待定）。
- **体术＝风格页域**（`style_unarmed`）：身体**能力**——回避/摔绊/翻滚等；奖励偏闪避/机动/摔投能力。**喂养来源 🟡 待定**（徒手攻击 match 归格斗域；候选＝闪避成功/移动/挨打行为，需新喂养挂钩）。
- **perk 可赋予能力 🔒**：perk＝技能编辑器条目、主动块可用（§2.3 既定）。能力获取渠道全景＝**武器 attack / EWS 解锁 / perk / 天赋节点** 四条。
