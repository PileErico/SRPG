## 1. 核心语义（对齐既有 🔒）

- **玩家移动＝世界回合**：时间只随玩家活动流逝（M2 🔒），WorldSim 只在 WorldClock 推进后被喂小时数——玩家不动，世界单位不动。战斗不耗世界时间 🔒 ⇒ 战斗中世界同样冻结。
- **每单位速度＝`hours_per_cell`**（每格行进耗时）：推进 N 小时→攒 N 点 budget，够一格走一格（跨 tick 不丢零头）。玩家速度参照＝2 小时/成本点。
- 分层沿用三段式：**类型定义**＝`data/world_units.json`（`WorldUnitDB`）/ **实例状态**＝`WorldState.world_units`（纯 dict 随档）/ **推进逻辑**＝`WorldSim.tick(ws, hours, world)`（不认识场景节点，宿主鸭子接口）。

## 2. v1 已实现

| 类型 | 行为 | 说明 |
|---|---|---|
| 商队（帝国） | `trade_route` | 在城/村间往返，到站停靠 `rest_hours` 再选下家（交易功能待经济系统） |
| 帝国巡逻队 | `patrol` | 绕 home 城 `radius` 内巡逻；`sight` 内发现 `hunts` 派系单位（劫道者）→ 追击 → 邻格**摩擦战**（d4+power 高者胜、输家覆灭，抽象结算不进战斗）；玩家若与帝国敌对也会被追 |
| 兽群 | `wander` | 随机游荡（中立，永不敌对；狩猎/食物待烹饪系统） |
| 劫道者游团 | `hunt` | 绕巢（劫道者营地）游荡；派系对玩家敌对（劫道者默认敌对）且玩家进 `sight` → **追击**，追上（同格/邻格）→ 进战斗 |

- **追上玩家 → 战斗闭环**：复用 M5/M7 契约——`BattleSetup.context{world_unit_uid, faction_id}` → 战胜 → `apply_result` 把该单位从世界移除；战败/弃战 → 单位留场但入 `calm_until` 冷静期（占位 12h，防原地连环追击）。
- **一次推进至多一场战斗**（先到先得；`_start_battle_with` 对同帧连环触发也有闸）。
- 表现：画布 token（派系色圆+类型字形，敌对红外环）/ 悬停显名字·派系·敌对 / 摩擦战与追击进日志。
- 生成：开局一次（`flags.world_units_seeded` 幂等）——商队 2、每城巡逻 1、兽群 2、游团 2（绕巢）。

## 3. 与声望（M9）的关系

M9 的「敌对遭伏」伪触发器（暗骰）与 WorldSim 的「可见游团追击」**并存**：前者代表看不见的伏击风险、后者是地图上可躲可迎的活体威胁。若验收后觉得重复，把 factions.json 里 ambush.chance 归零即可只留活体路线（全数据可调）。

## 4. 待定（勿自行实现，验收讨论）

1. **数值**：各类型速度/视野/半径/数量/power、冷静期时长——全占位。
2. **重生成**：覆灭的商队/巡逻/游团是否定期补充（据点刷新式惰性判定即可接）。
3. **交互扩展**：商队交易（进背包/经济后）、兽群狩猎（食材）、游团劫商队（`hunts` 已支持派系单位互猎，暂只给巡逻队配了）、玩家主动攻击中立单位（宣战/声望后果）。
4. **城内安全区**：现状追击可发生在城边/休整中；是否城市周边 N 格禁止敌对单位进入。
5. **遭遇规避**：追上是否给「逃跑检定/绕开」选项（BB 式），现为直接开战。
6. **派系间关系矩阵**：现只有「玩家↔派系」声望；单位互猎靠类型 `hunts` 白名单，将来若要「派系↔派系」宣战需要关系表。
