## ✅ 已实现

### 功能

**UnitFactory＝单一序列化口**（proto↔活 Unit 往返全收此处；Sandbox/MapEditor/CharacterEditor/事件 spawn_unit 共用）

| 层 | 函数对 | 内容/口径 | 存放 |
|---|---|---|---|
| proto | `make_unit`/`unit_to_proto` | 定义+养成：name/id/race/tags/trait/equip(模板id)/skills{id:level}/stats 差异/profs/AI 兜底 | `res://data/unit_prototypes.json` |
| preset | `save_preset`/`load_presets` | proto 同形（name=预设名，同名覆盖） | `user://unit_presets.json` |
| campaign | `unit_to_campaign`/`unit_from_campaign` | proto ⊕ uid/equip_uids(slot→实例uid)/hp/armor/injured_until；复原＝make_unit 后**覆写 vitals**（绕 init_vitals 注满、战损保留）；装备实例重挂 `equip_instance`（词条保真；失败响亮警告+按模板补新件兜底） | WorldState/SaveIO |
| battle 快照 | `unit_to_battle_snapshot`/`unit_from_battle_snapshot` | **全量运行态原样存**（位置/AP/移动点/effects/modifiers/死门条/skills{level,cd,uses}/equipment/ai_aggroed/tags/prof_*）；复原＝`Unit.new()` 后**整份覆写**（绕 make_unit/init_vitals/learn_skill/set_trait 重置陷阱 🔒） | `BattleState.to_dict/restore` |

- `make_unit` 组装序：tags → `RaceDB.apply_to`（种族底值先落）→ speed/level/exp/trait/equip → **proto.stats 差异覆盖** → skills → profs（烘焙 force 装载、不走槽位校验 🔒）→ AI 字段 → `init_vitals` → `_sync_hands_to_state`。
- `unit_to_proto` 口径：阵营立场/flying/deaths_door **不入 tags**（运行时态）；equipment uid→模板 id 按 uid 去重（双手同件记一条；词条属实例态、campaign 层才保真）；**stats 只写与「引擎基线+种族底值」的差异 🔒**（调 races.json 平衡可传导既有原型）；AI 字段仅 enemy/neutral 写。
- 原型库写盘（仿 ItemDB）：`get_prototype`/`save_prototype(proto, replace_id?)`/`delete_prototype`——upsert 按 id、改名移除旧、整数归一化、写盘失败传导 false；`all_prototypes` 每次现读无缓存→写后免 reload。

**unit_prototypes.json**（内置原型；地图落子/沙盒/事件 spawn 同读一份）
- 字段：`id`/`name`/`default_faction`/`portrait`/`icon`/`tags`/**`race`**（id 与 race tag 同词表）/`level`/`exp`/`exp_max`/`trait`/`equip`(模板 id 列表)/`skills`(列表或 {id:level})/**`stats`**（对种族底值的差异覆盖）/**`profs`**（{known,slots,xp}，出身自带/敌方烘焙）/`ai_threat`/`ai_region`/`ai_group`/`_preset`。

**RaceDB + races.json**（种族底值单一数据源；属性重做 🔒 §3）
- human/lizardmen/harpy；`apply_to(u, race_id)`＝stats 底值直写（面板 base，修正管线再叠）+ 种族 tags 并入 + 记 `race_id`；空/未知＝no-op（引擎默认基线）；刷新＝`reload_data`（DB 铁律）。

**CharacterEditor**（StartMenu 独立入口，写回 unit_prototypes.json）
- 界面＝**真·角色状态页照搬 🔒**：复用 `UnitStatusPanel.editor_mode`（默认关→游戏内路径零改动，新分支全 `if editor_mode` 守卫；宿主注入 `on_portrait_pick`/`on_equip_slot`/`on_bag_slot`/`on_edit`）；编辑活 scratch Unit → 保存 `unit_to_proto` 落盘。**两列布局**（编辑器优化 §31，2026-07-13）：左=角色卡（CARD_SIZE 定尺寸）、右=编辑列（身份条+能力+技艺，纵向滚动）——1080p 消滚动、吃掉横向闲置；只动本编辑器容器编排，未碰 UnitStatusPanel。
- 身份/标签条：id · 默认阵营 · 精英 elite 勾选（非我方死门资格）· **种族下拉**（同时驱动 race_id+底值直落面板；四维编辑已删 🔒；**换种族确认** §34：现存 stats 差异覆盖非空 → `EditorUI.confirm` 弹窗，取消=下拉回退；确认=重铺底值+**补走成长轨** `_walk_growth`——level>1 换族后保存仍零 diff）· 生物类型 · **派系下拉→`camp_<id>` tag 🔒**（非字段，随 tags 序列化；≠阵营立场）· 棋子图标 picker · 自由标签（只列单位可用：排 `NON_UNIT_CATS`/运行时 tag）。
- **能力/技艺编辑**（编辑器优化 §7，2026-07-13）：能力区＝SkillDB 下拉+等级+添加 → chip 行（名+等级 SpinBox〔max_level 封顶〕+✕；改级/删除＝摘净 `skill:<id>` 被动修正再重学，vitals 按比例缩放）→ 写 `u.skills`；技艺区＝已识下拉（按 `UnitStatusPanel.PROF_PAGES` 三页分组）+行内「装载」勾选（`slot_prof(force)` 烘焙路径 🔒 §6）+✕ → 写 `u.prof_known`/`prof_slots`；**xp 不设编辑口**（随档原样往返）。**悬空引用保值**：SkillDB 查无的技能 / 不在已识的槽位引用 → `_lost_skills`/`_lost_slots` 兜住、⚠ 行显示、`_collect_proto` 原样写回，显式 ✕ 才删（`_ensure_meta_option` 同律）。⚠ 帝国树暂缓（用户令）：只有编辑器能力，data/*.json 未填任何技能内容。
- **AI 移出 🔒**：ai_* 归关卡编辑每处放置决定；`unit_to_proto` 仍写默认 ai_threat 兜底。
- 装备槽点选＝按 `EquipSlots.accepts` 筛物品+定向落位（`equip(id, target_slot)`）；**物品选择器**（编辑器优化 §23，2026-07-13）＝`EditorUI.item_picker` 通用弹窗：搜索过滤（名字/id）+行图标（TextureCache）+悬停 `ItemTooltip.render` 富预览——DeployPanel 将来可共用同款（宿主备料 entries 即接）；背包占位**不入档**；左列表＝按阵营折叠+立绘卡片；未保存守卫/Ctrl+S；外观组 `_appearances`（立绘+棋子成对，顶层 portrait/icon 镜像默认外观）。
- 遗留：卡内提示「填四维」字样在 `UnitStatusPanel.gd:218`（editor_mode 抬头）——UI 并行线敏感区未动，待该线顺手改。
