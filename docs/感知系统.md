# 感知系统（视野 / 迷雾 / 环境）· 设计规格

> 状态：**Phase 1 ✅ 已实现**（视野/LOS/迷雾/AI/重塑，2026-07-01）+ **Phase 2 环境 ✅ 已实现**（日夜 + 天气〔运行时机 + `set_weather` 触发器 + 编辑器面板〕+ **天气 VFX 视觉叠层**〔Alenia Studios 素材〕，2026-07-01）。实录见 [实现现状.md](实现现状.md)「感知系统」。定位：**独立地基子系统**——LOS/视野/迷雾/环境一次建好。
> 前置已满足：战斗数值地基·修正管线已通 → `sight` 直接当「被修正的 stat」，环境＝新的修正来源。
> **范围校正（2026-07-01 🔒）**：**去掉「子地图隔离」**——那只是 LOS 的副产物注脚；子地图本身另行排期，不在本轮。

## 分期（🔒）
- **Phase 1（核心 · 本轮先做）**：视野 `sight` + 视线 LOS + 三态战争迷雾 + AI 视野驱动 + 重塑 targeting/悬停。
- **Phase 2（环境）**：日夜（静态）+ 天气（动态表 + `set_weather` 触发器）+ 编辑器「环境」面板。
- **later**：天气**视觉滤镜**（画面染色 / 雨雾粒子）+ 天气带来的**其他效果**（雨→火弱、雪→移动↑…，都走「多挂修正」）。
- **远期**：**局部天气**（非全局）——地图一半下雨、一半起雾。

## 视野 `sight`（🔒）
- **新 stat `sight`**：兵种基础值 + 被 skill / effect / 环境(天气·日夜) 影响，全走**修正管线**（`effective_stat("sight")` ＝ 当前视野）。这是「数值先做」的直接受益点。
- 基础值 ＝ **数据、可调**（默认暂定 5，各兵种后续在原型里给）。
- 单个单位可见格 ＝ 以己为心、半径 `sight`、被 LOS 裁剪。

## 视线 LOS（🔒）
- **新 `_hex_line(a,b)`**：cube 线性插值 + round + 微 epsilon 避顶点歧义（现有 `_line_cells` 是沿 6 方向的直线、**不适用**于任意两格）。
- 线上**中间格**任一带 `blocks_sight` tag → 挡。**数据已齐**：森林 / 山地 / 废墟 / 墙 已挂 `blocks_sight`（`terrains.json`）。
- **只有地形挡视线、单位不挡**（默认；六边形战棋惯例）。
- **终点格自身**的 `blocks_sight` **不挡**（看得到森林边缘的人，只是看不穿过去）。
- 地形给视野**加成**（高地看得更远）＝**暂缓**（🔒 先只做「挡/不挡」）。

## 三态战争迷雾（🔒）
- **黑**＝未探索（从没看到过）：全黑，地形/单位都不显。
- **灰**＝探索过、当前无实时观测：**记住地形、但单位隐藏**（人走了 → 只知地形、不知单位状态）。
- **常态**＝我方/友方当前视野内：一切实时正常显示。
- **数据模型（按侧各存两样）**：① `seen`（曾看到过的格集）→ 黑 vs 非黑；② 每次移动/回合重算的 `visible`（当前可见格集）→ 灰 vs 常态。单位只在 `visible` 内渲染；`seen − visible`（灰）只画地形。
- `visible` ＝ 我方/友方全体单位视野格的**并集**（团队视野）。
- 灰格敌人：**完全隐藏**（🔒；「最后已知位置」残影＝后加）。
- **双方都有迷雾**：玩家侧渲染三态；敌方 AI 用它自己的 `visible` 感知（见下）。
- **调试开关**：「全知 / 关迷雾」，快捷键切换。**默认 ＝ 开（迷雾生效）**（🔒 真实体验；沙盒自测时手动切全知）。

## 敌方 AI × 视野（🔒）
现有三种警觉 tag 正好对接，不用新框架，只改 `ai_threat` 的触发口（`_ai_update_aggro`，Sandbox.gd ~902 就地改）：
- `ai_threat`（**纯感知**）：从「进我移动+攻击范围」改成「**敌人进我 `sight` 且有 LOS**」才警觉。
- `ai_region`（**区域触发**）：**不受视野影响**（进房间即惊动守军）——不动。
- `ai_group`（**连锁**）：组内一员激活 → 全组连锁，照旧。

## 环境：日夜 + 天气（Phase 2 ✅ 已实现 · 数值可调）
- **日夜（静态）**：地图字段 `time`（day/night/…）。战斗时间跨度小、**战中不变**。**夜 ＝ 视野「最终乘子」🔒**：`_effective_sight = round(effective_stat("sight") × time_sight_mult)`，`time_sight_mult` 夜=0.5（**在天气/装备/技能等所有 flat/pct 加减之后再乘**——「其余都是加减，夜晚最终减半」）；**不走 flat 修正管线**。夜另带 **全屏变暗滤镜**（`time` 的 `tint`，Sandbox `_night_overlay` 呈现）。
- **天气（动态，数据驱动）**：地图级 **`weather_table`** ——
  - schema：`[{weather, weight, min_rounds, max_rounds}]`。
  - 运行时：开场按 `weight` 摇一个 + 在 `[min,max]` 摇持续回合；到期摇下一个。表空＝默认晴。
  - **作者定点变天** ＝ 复用触发器 `do:{action:"set_weather", weather, duration}`（关卡编排）；`weather_table` 管随机氛围——两者分工。
  - 天气 → `sight` 修正（雨 −Y、沙暴 −Z）。**近期只影响视野**（🔒 首发不带别的效果）；将来影响别的＝多挂修正。
  - 变天瞬切（某回合起换）；摇下一个允许连续同种（先如此）。
- **环境 ＝ `sight`（及将来其他 stat）的修正来源**，吃修正管线。
- 具体数值（夜 / 雨 / 沙暴 的 −X/−Y/−Z）＝ **数据、可调**。

## ⚠️ 会重塑现有战术功能（非纯加层——这轮碰现有战斗代码最多处）
- **悬停预览敌方范围**：迷雾里的敌人不该被看到 → 悬停只显可见。
- **攻击 / 技能目标**：只能打 **可见 + LOS + 射程**。
- **AI 警觉**：改视野驱动（见上）。

## 与其他系统的接点
- **修正管线**：`sight` 是被 skill/effect/环境影响的 stat（尤其「环境」这个新修正来源）。
- **触发器层**：定点变天 ＝ 新增 `do:set_weather`（复用现成触发器框架）。
- **编辑器**：地图加「环境」小面板（日夜下拉 + 天气表增删行），跟 `terrain_overrides` 并列做（地图级 authoring 数据）。
