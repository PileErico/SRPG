# 模块：地图美术（地块渲染 / 瓦片 / 线特征 / 地块工坊 / 放置物 / 天气 VFX）

> 常驻·模块文档。设计真值 → [架构.md](架构.md)「画布契约/三套坐标序」＋本文。上半=✅已实现，下半=🟡规划；开发＝把下半搬进上半。

## ✅ 已实现

### 功能

**地块渲染单一实现（HexTileRender）**——三画布（编辑器/战斗/大地图）＋笔刷缩略图共用一份，杜绝「笔刷格 ≠ 地图格」
- **瓦片对齐 🔒（2026-07-04）**：赤道＝贴图**最宽像素带的最高一行** ↔ 格心水平线；等比 1.5×（art 32px → 格宽 48px）；竖向探出（山峰/树冠）/收缩（水/冰）全由 art 像素自带，不手算竖向锚点；art 底 3 行＝崖裙（边线/假高度，非本体）。
- 瓦片规格：32×28（flat-top 2/√3；对齐 Unciv FantasyHex 与角色 32px 像素密度）；NEAREST 放大呈块状像素。
- **战斗自绘规格（2026-07-20 用户定向：战斗地块自绘，两套素材硬隔离——FantasyHex 只留大世界）**：画布规格**逐条目可调** `art_px:[w,h]`（缺省 32×28 旧规格零回归；`TerrainDB.art_px_of`）；六边形**比例/外形恒定**——满宽 w、高 √3/2·w 向上取整、**底对齐**，多出的高＝顶部界外物件留白（`HexTileRender.hex_center_px/hex_contains_px/hex_anchor_row` 双规格判定：旧 32×28 居中判定逐像素不动）；对位＝**整画布锚行**（`art_anchor`＝几何中心行，96×96→54；放置物在画布内摆好相对位、渲染整幅贴合）。战斗词表骨架 `bt_*` 十条已立（96×96/锚行54/scope battle：草地·泥土·旱草·雪地·墓园 底地形 + 森林·悬崖·溪流·道路·掩体 放置物——无 art 走程序兜底、画一张挂一张）。PHBT v0.6.5 参考包（personal-use 许可、只参考不入库）＝该规格的摆位实证来源。
- 手绘 art 变体优先（terrains.json `art` 数组、seed 确定性选张）→ 程序烘焙像素底兜底（顶光/轻噪/像素边缘一圈压暗/3 变体缓存）；`BAKED_DECOR=[grass,wave]` 已像素化、其余地形仍叠矢量线稿 decor。
- `anchor` 固定锚行＝放置物（非六边形叠加）钉赤道。
- 过渡边：`_draw_terrain_seams` 相邻异色公共边描同色系深线（纯按色、无地形语义）；`_seam_cell` 对 art 格跳过。

**静态层 / 分块渲染（HexCanvas）**
- 地形+线特征+过渡边入 `_static_root`（Node2D）下 **16×16 格/块** Node2D 网格；悬停/范围/单位留本体 `_draw` → 悬停不卡。
- 涂一格只重画所在块（`refresh_cell`，实测 8.9ms vs 全图 93ms）；跨块过渡边连带重画邻块。
- 平移/缩放走节点变换（GPU、不重画）；离屏块按内容 AABB 自动剔除 → 成本 ∝ 可见面积、与地图总大小无关。
- `_draw` 自愈：有 editor 无块时 `call_deferred("request_fit")` 补建（任意宿主进场路径稳）；`_size_static_to_map` 防 size=(0,0) 误剔坑；`clip_contents` 裁静态子树；子类静态覆盖走 `_static_overlay()` 钩子。实测细分成本 ≈0.037ms/格（单线程 GDScript）。
- **绘序＝Diamond-Down**：按 `hex_center().y` 升序、下方格后画盖侧壁；每格二遍＝地形→放置物；层序 单位 > 放置物 > 地形。

**线特征 v4（河/路/桥，大地图专属语义）**
- 数据＝格对 `[[x1,y1],[x2,y2]]`；边键归一单一源 `HexGrid.edge_key`（无向）＋`HexGrid.adjacent`；`rivers`/`roads`＝`[{id,label,pairs}]`、`bridges`＝裸格对表。
- 渲染单一实现 `HexCanvas._draw_line_features`：河＝深衬底+亮水面双色·端点圆头（行带分隔边天然蜿蜒）；路＝**锚定边中点**+抖动格心+Chaikin 平滑+**长短交错虚线**（土路观感）；桥＝沿心连线方向木板。
- 编辑器线特征层（第 5 图层）：河刷（沿边拖画，`nearest_edge_at` 边拾取）/ 路刷（沿格连路，跳格 `HexGrid.line` 补齐）/ 桥刷（只架已有河边）；擦河顺带拆桥；stroke＝一段拖动一次撤销。
- 通行单一实现 `Overworld._move_cost_between`：河边无桥＝−1 硬阻断 🔒、桥/道路边＝`min(格成本,1)`；寻路与行程扣时同源；WorldSim 移动+交战同源吃边（`_passable_neighbors`/`_reachable_adjacent`，隔无桥河不 engage）。
- 战斗侧只渲染不参与规则、全链透传保真（`_load_map`/`load_from_memory`/`save_units_to_map`/suspend `to_dict/restore`）。

**地形 scope 分层（方案 A 🔒）**
- terrains.json 每条 `scope: battle/overworld/both`（缺省 both 零迁移）；`TerrainDB.in_scope` 单一判定；只过滤编辑器笔刷 authoring（`_apply_brush_filter` 只藏不重排），渲染/通行照常认 tile。
- **当前关闭中**：`MapEditor.SCOPE_FILTER_ON=false`（笔刷全通用；机制/测试保留，可随时开回）。

**地块绘制工坊（TerrainArtWorkshop，独立场景·主菜单进）**
- 左清单＝**分类两级折叠**（吃 `TerrainDB.categories()` 既有分组、与 MapEditor 笔刷同序：用户分类在前/待定垫底）+ **过滤框**（label/terrain/variant 子串，只重灌列表不丢输入焦点）+ **懒构建**（折叠组展开才建行；含当前选中的组自动展开），145 地形按组收纳。右预览 + overlay 像素绘制（PixelDrawCanvas：铅笔/橡皮/直线/矩形/矩形填充/油漆桶/取色/选区/魔棒）。
- **绘制浮层＝`PixelDrawOverlay` 共享组件**（与外观工坊同一份：工具列/调色列/保存编排；宿主差异经 `setup(opts)` 注入；色块预设持久化两侧都有——地块侧 `data/terrain_swatches.json`、用户加预设才生成）。**满窗布局**（2026-07-20 修复）：浮层全屏铺满随窗缩放——左工具列/中画布（撑满）/右调色+实时拼贴预览；进树后铺满必用 `set_anchors_and_offsets_preset`（布局守则，与 DialogueUI 同条）。
- **无缝外扩 `HEX_PAD=0.75`（2026-07-20）**：非旧规格的六边形判定（遮罩/轮廓/存盘清界外同源）外扩 0.75px——数学六边形（√3 比例）比无缝拼贴所需瘦约 1px（96 宽＝83.1 行 vs 实拼 84 行，PHBT 实测边缘画满），不外扩则拼贴漏黑缝；旧规格 32×28 不外扩（已画瓦片逐像素不动）。
- **`_rebuild` 保折叠+滚动**：折叠字典随开合即记、`scroll_vertical` 重建后回填（外观工坊同款）。
- **绘制中实时拼贴预览＝WYSIWYG（2026-07-20 用户令）**：`PixelDrawCanvas.image_changed` → 灰白 hex 轮廓参考线（与画板同判定 `_hex_border_img`）合成在画作**下层** → live 纹理经 `TextureCache.put_file` 挂虚拟路径 `live://terrain_edit` → 浮层内嵌 mini `TilePreview`，**七格全部只画当前画布**（art 池单元素＝[live]，任何 seed 都命中——画什么显示什么，绝不混抽既有变体）；**无任何程序垫底**（要铺底走「以其他地块为底稿」）；地形块 anchor 钉 hex 遮罩赤道行、放置物钉 entry `art_anchor`。
- **预览可交互（2026-07-20）**：`TilePreview` 滚轮整数级缩放（像素不糊）/ 左键拖拽平移 / 右键复位——接缝细节可放大检视（主对照预览与绘制中 mini 同享）。
- **对照预览＝地图同口径**：`TilePreview` 七格按 Diamond-Down（y 升序）画（与 `HexCanvas._paint_chunk` 同序，崖裙/探出重叠一致）；放置物条目透传 `art_anchor` 钉赤道 + 先铺程序兜底地面再叠 art（仿地图「地形→放置物」两遍绘制）。
- **像素画布增强**：redo 栈（新笔画清空，Ctrl+Y/Ctrl+Shift+Z + 浮层 ↷ 钮）；悬停像素框（按笔刷足迹）+坐标角标、笔刷粗细 1/2/3px（`stamp_pts`）。
- **⧉ 复制为新变体**：以所选变体 Image 为底稿新建，差分变体不从零画。**🎨 以其他地块为底稿…**（2026-07-20）：弹窗列全库手绘变体缩略（带过滤），点任一张作底稿画进**当前所选条目**的新变体（跨条目版复制；尺寸不符自动缩放到目标画布）。**导入 PNG 全文件系统**（ACCESS_FILESYSTEM 与外观侧对齐；导入即复制进项目、不引用外部路径；尺寸不符按该条目 art_px 缩放）。
- **锚行存盘写死（2026-07-20）**：工坊保存/导入时条目无 `art_anchor` → 写死＝该画布 hex 遮罩赤道行（32×28→13 / 96×96→54）。「最宽行自算」只对画满六边形的图成立，稀疏内容（一条曲线/几株草）会钉错高度——工坊出品不猜。
- **素材整理进工坊（2026-07-20 用户令）**：左栏「＋新建分类」（空分类也显示、可收新条目）/「＋新建地块」（起名+组/变体 id+归类+适用图 battle/overworld/both+放置物+本辅色；`TerrainDB.add_entry` 写口、id 小写强制+撞键拒绝；通行/效果等数据细调仍走地图编辑器·地形数据单一编辑口）；右栏条目整理行＝改名/移到分类/删除条目（删条目保留 PNG）。**两级排序**：分类头 ↑↓（categories 数组相邻交换，待定恒垫底）、条目头 ↑↓（`TerrainDB.move_entry` 分类内最近邻交换——顺序与 MapEditor 笔刷栏共用 `_palette` 单一源）。**层级色**：一级分类头深底金字、二级条目头浅底白字（`make_foldable` header_bg/header_font 参数）。

**表现层微升级**
- decor 坐标扰动：`(col,row)` hash 确定性 ±2.5px（`_decor_seed`/`_jo`）；seed=0 零扰动（笔刷缩略图规整）；规整类 decor（车辙/砖墙/田垄/桥板）不扰或只扰长短。
- 区域边界虚线：`draw_region_outline`（深衬底+区域/派系色；语义暂纯视觉）；大地图经 `Overworld.regions_for_draw()` 静态层描边。
- 天气调色：`EnvDB.weather_tint`/`apply_weather_tint` + Sandbox `_weather_overlay`（夜幕之上、天气 VFX 之下）；environment.json 各天气克制 tint。
- 地点名字标签：瓦片=地点 🔒（2026-07-13）——地点长相＝fh 瓦片美术本身，无独立标记图标；`HexCanvas.draw_location_label` 只补瓦片给不了的两样：名字（缩放 ≥DECOR_MIN_ZOOM 才画）+ 据点状态（已肃清＝格上薄灰纱+灰字）；大地图/编辑器地点层共用。
- 笔刷图块化：`TerrainSwatch`（46×44，`set_tile`）——笔刷直接显示完整六边形地块，所见即所得。

**天气 VFX（全自绘/程序化 🔒，无第三方素材·无署名负担）**
- 雨/雪/沙暴/雷暴＝GPUParticles2D 自绘像素粒子（NEAREST）；雾＝`weather_fog.gdshader` 大尺度平滑噪声；雷暴＝雨粒子+全屏白闪（ColorRect 亮度脉冲，`_process` 驱动）。
- 挂 SandboxCanvas 子节点：屏幕空间、覆盖战场视口不盖侧栏 UI、点击穿透、不随镜头平移缩放。
- 天气→fx/tint 映射＝数据（EnvDB / environment.json）。

**验收工具**：`tools/screenshot.gd` 通用截图 harness（窗口跑场景→存 PNG→退出，`--scene/--out/--w/--h/--frames/--setup`），供 AI 协作目检 UI/美术。
