## 成长四词

| 概念 | 中 | 英 | 定义 | 代码符号 |
|---|---|---|---|---|
| A | 技能 | Skill | 可学习＋装备的域（剑/盾/烹饪），有熟练度 | `ProfDB` `data/proficiencies.json` `Unit.prof_xp/prof_known/prof_slots`（内部旧名 prof/技艺）|
| ↳等级 | 熟练度 | Mastery | 5 阶 生疏→娴熟→老练→专家→大师 | `ProfDB.STAGE_THRESHOLDS`=[0,100,300,600,1000] `MASTER_XP_CAP`=1500 `Unit.prof_stage()` |
| B | 专长 | Perk | 熟练度到阶解锁的被动特化（每技能 4 次）| 待建；现 `proficiencies.json` `stage_mods` 占位 |
| C | 天赋 | Talent | 等级解锁的能力树，到层选一（层 3/6/9/12/15/18）| 原型 `skill_tree` · `SkillTreeDB`(待建) · `skill_trees.json`(待建)（旧名 职业树）|
| ↳C1 | 角色天赋 | Character Talent | 具名角色个人树 | |
| ↳C2 | 派系天赋 | Faction Talent | 派系共享树（帝国步兵/士官），节点 `only_units/exclude_units` 门控 | |
| D | 能力 | Ability | 主动招式（战场救治/武器攻击/法术）＝战斗选单 | `SkillDB` `data/skills.json`（内部旧名 skill；UI「技能」选单→「能力」）|

轴：技能(练)→专长 · 天赋(升)→能力。"能力"旧文档另指面板效能→待改称"面板属性/效能"。

## 概念 ↔ 代码符号

| 概念 | 代码符号 |
|---|---|
| 种族底值 | `RaceDB` `data/races.json`(human/lizardmen/harpy) `Unit.race_id` |
| 特性 | `TraitDB` `data/traits.json` `Unit.trait_id`（≠专长）|
| 效果 buff/debuff | `EffectDB` `data/effects.json` `Unit.effects`；`fort_will/fort_body` tag→强韧豁免 |
| 物品模板 / 实例 | `ItemDB` `data/{weapons,armor,accessories}.json` ／ `ItemInstances`(uid) `Unit.equipment`(存uid) `view(iuid)` |
| 词条 affix | 实例 `affixes[]`；禁键源 `StatMeta.ITEM_FORBIDDEN_STATS` |
| 派系 | `FactionDB` `data/factions.json` `camp_*` tag（≠阵营立场 player/ally/enemy/neutral）|
| tag | `TagDB` `data/tags.json` |
| stat 键→标签/白名单 | `StatMeta`（`LABELS`/`SERIALIZABLE_BASE_STATS`/`EDITOR_STATS`/`ITEM_FORBIDDEN_STATS`）|
| 修正 modifier | `Unit.modifiers`；source 前缀 `trait`/`equip:<iuid>:<idx>`/`buff:<id>`/`prof:<域>`/`env:*` |
| d20 检定 | `Checks`（`check(unit,attr,dc)` / `check_flat(bonus,dc)`）|
| 伤害结算 | `CombatResolver` |
| 战斗模型层 | `BattleState`(RefCounted)，宿主 Sandbox |

## 属性 / 抗性键

- 面板：`HP_max` `atk` `acc` `eva` `crit_rate` `crit_dmg`(160=×1.6) `block_rate` `block_power` `AP_max` `move` `speed` `sight` `armor_max`
- 效能桶(base 100=中性)：`atk_eff` `def_eff`；`hit_eff` `eva_eff`(mod-only)
- 人抗 `res_phys`/`res_nature`(%减伤) · 甲抗 `armor_res_phys`/`armor_res_nature`(默认0，无甲=无) · 强韧 `will_fort`/`body_fort`(豁免率%，永不入物品)
- 固减 `dr_flat_human`/`dr_flat_armor`(最后减，底0)
- `damage_kind`：physical/fire/ice/thunder/holy → 归轨 physical→phys，其余(含holy)→nature（`CombatResolver.RES_SUFFIX`）
