### 功能

**地图 schema（JSON，format_version 4；完整真值＝`MapIO.gd` 头注，与本表同步维护）**

| 字段 | 起版本 | 内容 | 主要消费 |

| `tiles[row][col]` | v1 | 每格 `{terrain,variant}`＋可选 `object` 放置物（→[模块_地图美术.md](模块_地图美术.md)）；tags/move/effects 按 terrains.json 查表 | 渲染/通行 |

- 兼容套路＝**加字段＋读端 `.get` 兜底**（旧 v1/v2/v3 图零影响）。
- 容错：缺格/坏格回退草原、未知地形渲染品红、region cells 过滤越界格、尺寸超 50 先钳再建 tiles、线特征坏格对 normalize 丢弃/非相邻忽略。

**MapIO（地图读/写单一入口；static 伪单例）**
- `read_file(path)`（失败 `{ok:false}`）/ `normalize(dict)`（校验＋钳制＋逐格兜底；文件读与内存试玩共用）/ `to_dict`/`write_map(path,w,h,tiles,opts)`（**opts 字典**，2026-07-03 从 11 位置参数收敛，加字段不连坐调用面）/ `grassland(w,h)` / `peek_type`（轻探 map_type 供列表标注，免全量 normalize）。
- 取代 MapEditor/Sandbox 各自分叉解析——**统一尺寸钳制策略**（旧坑：编辑器钳 50、沙盒不钳上限→同图两侧尺寸不一致）；regions/units 原样透传（各方按内存形再转）。

**六图层（`current_layer`；左侧栏 3 列网格互斥切换，线/地点层仅大地图显示；画布左右键按当前层分派 `primary_paint`/`secondary_paint`）**
- **地形层**：笔刷竖列（`TerrainSwatch` 完整六边形所见即所得＋分类折叠管理→[模块_地图美术.md](模块_地图美术.md)）；左键画（stroke 拖动＝一次撤销）/右键取色；数字键 1~9 选第 N 支可见笔刷（scope 过滤后的序；焦点在输入框不抢键）；下方「地形数据」编辑区（见下）。
- **地形工具四件套（2026-07-07）**：工具行 画笔/填充/矩形/直线 互斥＋画笔半径 SpinBox(0~4)——画笔半径＝六边形距离 ≤N 一片（`_paint_radius`）；油漆桶＝同底地形(terrain/variant)连通块 BFS 整片刷、一次按下只填一回（`_flood_fill`＋`_fill_stroke_done`）；矩形/直线＝两点工具：按下定起点、拖动画布黄描边预览（`EditorCanvas._draw_shape_preview` ← `shape_preview_cells()`）、松开在 `end_stroke` 落形（直线走 `HexGrid.line`）；三者最终都逐格 `paint_cell`（放置物/橡皮/去重/分块重绘单一实现），一段 stroke 一步撤销照旧。⚠️ 选刷注意：工坊化后同名条目可能是放置物刷（写 `object` 子字段不动地形，如森林）。
- **线特征层**（第 5 层，河/路/桥 authoring）：河刷沿边画/路刷沿格连/桥刷点河边架，右键按工具擦（擦河顺带拆桥）——数据/渲染/通行 → [模块_地图美术.md](模块_地图美术.md)。
- **区域层**：区域＝`{id,label,color,kind,cells}`（稀疏）；左键加格/右键移除（均 stroke）；工具栏＝列表（行显〔部署〕名(格数)·区域色·单击选中）＋新建（自动 id＋循环配色）/改名/删除＋颜色（ColorPickerButton 实时改、不入撤销栈）＋类型下拉（触发区/部署区，可撤销）；绘制＝半透明色块，当前层非区域整体压淡、当前区域更亮＋描边；悬停信息追加「区域: 名」。
- **单位层**：阵营下拉（默认敌方）＋原型列表（`UnitFactory.all_prototypes`）；左键空格落子/点已放单位开深编、右键删；一次拖动首格锁定模式（首格空＝续落 / 有单位＝编辑，不误落）；token＝阵营色圆＋黑描边＋原型图标（`_draw_units`，非本层半透明）。**深编**＝右侧浮动面板（`_build_unit_edit_win` 内嵌 `editor_mode` DeployPanel，隐战斗宿主钮）：`map_units[idx].proto`→`UnitFactory.make_unit` 造活 Unit→面板编辑→宿主回调即时 `unit_to_proto` 序列化回 `map_units[idx]`＋重绘；整段编辑＝一步撤销（会话首次改动压 `_snapshot`），换层/换图/删/undo 均关面板防下标失效——序列化口径/面板内部 → [模块_单位模板.md](模块_单位模板.md)。
- **触发器层**：列表（新建/删除）＋表单（标签/区域下拉/触发方/只一次）＋ do 动作动态编辑（添加/逐行 ✕ 删）；**动作菜单/缺省值/参数表单全据 EventEngine 注册表数据驱动**（`_build_action_field` 控件工厂：text/int/proto/faction/weather 五型）——加新动作零编辑器改动；`_trig_loading` 守卫填表不回写；spawn 坐标 SpinBox（将来可改点图取点）。执行/评估 → EventEngine（[实现现状.md](实现现状.md) M3）。
- **地点层**（瓦片=地点 🔒 2026-07-13）：地点增删＝**地形层**画/铲地点瓦片；本层点地点格编辑注记（id/名字/讨伐图/对话，类型只读＝瓦片推导）、右键/「删除注记」钮删注记（恢复自动 id）；列表 ●有注记/○自动/⚠孤儿（画布红圈警示）；派生视图＝`LocationDB.derive_locations`（与 Overworld/lint 同源）；标签渲染 → [模块_地图美术.md](模块_地图美术.md)。

| 中键拖动 / 滚轮 | 平移 ／ 缩放（光标为中心，0.2×–4×） |
| `Ctrl+Z` / `Ctrl+Y`(`Ctrl+Shift+Z`) | 撤销 / 重做 |
| `Ctrl+S` | 保存（有文件覆盖，无文件另存为） |
| 数字键 `1`~`9` | 快选第 1~9 支可见笔刷（地形层） |
| 悬停 | 高亮当前格（线层另高亮最近边）；左下角坐标＋地块/区域/地点/线特征信息 |

### 界面

| 区块 | 内容 |
|---|---|
| 顶栏 | 宽/高输入·尺寸预设·新建·**地图类型下拉（战斗图/大地图）**·保存/另存/加载·撤销/重做·适配窗口·状态文字 |
| 左侧栏 | 图层切换（3 列网格；线/地点仅大地图）＋当前层工具（笔刷+地形数据 / 线工具 / 区域 / 单位 / 触发器表单 / 地点） |
| 中部 | 六边形画布（平移/缩放/悬停高亮/左下信息） |
| 右侧栏 | 地图库（路径+选择文件夹/刷新+列表+新建）→ 环境面板 → 文件名+脏标记 → 最近操作列表 |

| 撤销上限 / 缩放范围 | 50 步 / 0.2×–4× |
