## 1. 成长体系词汇 🔒（2026-07-07 定）

四个核心概念 + 两条成长轴。**术语切割**：这四个词各指一物，勿混用。

| 概念 | 中文 | 英文 | 定义 | 怎么长 / 拿 |
|---|---|---|---|---|
| A | **技能** | Skill | 剑/盾/烹饪…可**学习＋装备**的域；每个域有独立**熟练度** | 用则涨熟练度；学＝师承/自悟 |
| A的等级 | **熟练度** | Mastery | 某技能的掌握深浅，5 阶 生疏→娴熟→老练→专家→大师 | 战斗/使用累积 xp |
| B | **专长** | Perk | 熟练度**到阶解锁**的被动特化（每技能 4 次选择权） | 技能熟练度里程碑 |
| C | **天赋** | Talent | **等级解锁**的能力树，到层免费选学 1 个（层 3/6/9/12/15/18） | 升级到层 |
| └ C1 | **角色天赋** | Character Talent | 具名角色的**个人**树（各自独有） | 同上 |
| └ C2 | **派系天赋** | Faction Talent | **派系共享**树（帝国步兵/帝国士官…），旗下多模板共用；节点按单位门控 | 同上 |
| D | **能力** | Ability | 主动使用的招式（战场救治/武器攻击/法术）＝战斗里点角色弹出的选单 | 由天赋树 / 武器(BAS) 授予 |

**两条成长轴**：**技能（练）→ 专长** ・ **天赋（升）→ 能力**。

## 3. 属性 / 抗性键（当前 · 真值以 `StatMeta.gd`/`data/races.json` 为准）

- **面板核心**：`HP_max` `atk`(攻击) `acc`(命中) `eva`(闪避) `crit_rate`(暴击率) `crit_dmg`(暴击威力,如160=×1.6) `block_rate`(格挡率) `block_power`(格挡性能) `AP_max` `move`(移动力) `speed`(速度) `sight`(视野) `armor_max`(护甲上限)。
- **效能桶**（base 100＝中性）：`atk_eff`(攻击效能·增伤) `def_eff`(防御效能·减伤)；`hit_eff`(命中效能) `eva_eff`(闪避效能) ＝ mod-only（无面板基）。桶名映射见 `BattleState` L388-391。
- **抗性四轨 🔒**（[属性与成长系统.md](属性与成长系统.md) §5）：
  - 人抗 `res_phys` / `res_nature`（%减伤，挂人）
  - 甲抗 `armor_res_phys` / `armor_res_nature`（挂防具，默认 0，无甲＝无甲抗）
  - 强韧豁免 `will_fort`(意志强韧) / `body_fort`(肉体强韧)（豁免率%，见 §4.6；**永不入物品**）
- **固减**：`dr_flat_human` / `dr_flat_armor`（最后做减法，封底 0）。
- **damage_kind**（细分，喂异常/内容层，非抗性轨）：`physical`/`fire`/`ice`/`thunder`/`holy`。**减伤归轨**：`physical→phys`，其余（含 `holy`）`→nature`（`CombatResolver.RES_SUFFIX`）。元素特异性弱点走异常侧/专项逻辑、不走抗性轨。

## 4. 战斗公式（当前实现 · 🔒 数学结构已定，数值/内容可调）

### 4.1 修正三层（所有战斗数值共用）
1. **面板 stat**：单位基础值（`Unit.stats`）。
2. **补正 modifier**（逐属性）：`有效值 = 面板 + Σflat + 面板 × Σpct/100`。
   **去重 🔒**：同一 `source` 对同一 `(stat, op)` 只算一次、**取高**（重复挂不叠、数值不同取大）；不同 source 才累加；无 source 各自独立。（`Unit.effective_stat_f` L129）
3. **效能层（乘算）**：
   - 增益桶 `eff_mult(b) = max(0, 面板b/100 若b是面板效能stat 否则1) × Π(1+各源%/100)`；同源取高，每因子 clamp≥0（单条 −100%→0，永不为负）。（L156）
   - 减免桶 `eff_reduce(b) = Π(1−各源%/100)`；同源取高，每因子 clamp≥0。（L172）

### 4.2 命中率（`BattleState` L426-429）
```
命中率 = clamp( (命中调整 − 闪避调整) × eff_mult(hit_eff) × eff_reduce(eva_eff) × 地块因子 , 5, 95 )
```
命中/闪避调整＝各自面板走 §4.1 补正；命中/闪避效能同层连乘（攻方 hit_eff、守方 eva_eff、守方地块「森林掩蔽」等）。

### 4.3 判定序 🔒：命中 → 格挡 → 暴击
- **命中**先判，未中即止。
- **格挡**（守方）：roll < `block_rate` → 注入 `block_power`（全域%减伤）。招架同算法、同时只一条**取高**。
- **暴击**（攻方）：roll < `crit_rate` → 暴击倍率 `cmult = crit_dmg/100`（多来源**加算**，未暴＝1）。

### 4.4 输出伤害（`BattleState` L459-462）
```
输出 = effective_stat_f("atk") × 技能系数coeff × 暴击倍率cmult × 攻击效能aeff   (+ 伤害补正flat，不吃效能)
```
- `coeff`＝技能/武器伤害系数（普攻单体≈1，AoE/多目标常<1）。
- `aeff = eff_mult("atk_eff") × 攻方地块攻击效能`。
- 伤害补正＝额外 flat（如撕裂/抓取的等效换算值），不吃效能。

### 4.5 减伤链（全乘算 · `CombatResolver.resolve`）
```
G = max(0, 1 − block_power/100) × def_factor          ← 全域，整击一次
def_factor = max(0, 2 − def_eff/100) × 守方地块防御效能
抗因子(prefix,属性) = max(0, 1 − 抗/100)                ← 抗>100→0免疫；抗<0脆弱→>1放大

【非穿甲分量 → 先进甲】
  到甲 = max(0, 输出 × ratio × G × 甲抗因子 − 甲固减)
  到甲 ≤ 护甲池:  池 −= 到甲
  破甲:          溢出 = 到甲 − 池; 池 = 0
                到血 = max(0, 溢出 × 人抗因子 − 人固减)   ← 溢出保留原伤害类型，再过人抗+人固减
【穿甲分量(比例 p)】
  人部分 = 输出×p → 到血 = max(0, 人部分 × G × 人抗因子 − 人固减)
  甲部分 = 输出×(1−p) → 走上面「非穿甲」甲流程
【无护甲】 直接人通道：到血 = max(0, 输出 × G × 人抗因子 − 人固减)
```
验算：输出50 / 甲抗50% / 护甲池20 / 人抗20% / G=1 / 固减0 → 到甲=25>20 破甲，溢出5 → 到血=5×0.8=4 →（护甲0，HP−4）。

### 4.6 异常施加 + 强韧豁免（`BattleState._try_inflict_state` L528 / `_fort_key_for` L562）
```
施加 roll:  randf×100 < inflict.chance  → applied
强韧豁免:   效果带 fort_will/fort_body tag → 取对应强韧值 fort%
            fort_roll = randf×100;  shrugged = fort_roll < fort
净施加 = applied 且 未 shrugged
```
- 豁免时机 🔒：**遭受第一时间掷一次 ＋ 此后每回合开始各掷一次**（成功＝完全不受影响 / 立即挣脱）。
- `ignore_fort:true` → 两处豁免一并跳过。不带维度 tag 的效果（一切 buff、死门/重伤等纯机制）不参与豁免。

### 4.7 死门检定（`Sandbox._door_turn_check` / `Checks.check_flat`）
```
1d20 + 求生  vs  DC          求生 = 5 + floor(body_fort/5)
DC = 15/20/25…（首回合15，每回合+5）    过 +1 / 不过 −1；被命中 −1
门条域 −3~+3：−3 倒下（铁人=真死，否则重伤离场）/ +3 爬回（HP保底1）
```
