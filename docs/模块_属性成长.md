> 常驻·模块文档。设计真值 → [模块_属性成长_设计.md](模块_属性成长_设计.md) 🔒（§7 翻案 / §8 待定勿实现 / §9 衔接）＋[表单-专用术语.md](表单-专用术语.md)。上半=✅已实现，下半=🟡规划；开发＝把下半搬进上半。

范围：属性面板 / 种族底值 / 抗性四轨 / **技能 Skill**＝熟练度域（代码旧名 prof/技艺）/ 等级节拍。专长 Perk 内容与天赋 Talent 树见 [模块_技能.md](模块_技能.md)。

## ✅ 已实现

### 功能

- **等级零数值 🔒**：四维（STR/DEX/INT/STA）+ 10 条派生公式 + 升级属性/技能点全删；等级只推 技能槽 1/5/9/13/17 + 天赋树层 3/6/9/12/15/18 解锁节拍；原派生键（HP_max/atk/acc/eva/格挡/暴击…）降级基础面板 stat、入 `StatMeta` 序列化/编辑器白名单
- **种族底值**：human/lizardmen/harpy（id＝race tag 同词表）；`make_unit`＝底值直落 → proto.stats 差异覆盖；扁平血量（底值不随等级涨）
- **抗性四轨 🔒**：`res_phys`/`res_nature`（全元素含神圣归轨，`damage_kind` 保留细分）＋`will_fort`/`body_fort` 强韧豁免掷（遭受瞬间+每回合各 1 次；效果按 `fort_will`/`fort_body` tag 归轨；`ignore_fort` 穿透两处；防具永不提供强韧）；`res_status`/五元素轨已删
- **死门检定**＝1d20＋求生（5＋body_fort/5），走 `Checks.check_flat`（⚠️ 新公式 1d20+运气+肉体强韧/5 已定 🔒 §10.6，代码待改→下半）
- **四属性全键落地 🔒（§10.6 数值定案，2026-07-07 晚实装）**：`finesse` 技巧（人底 10，加点 +2/次——命中等额相加＋暴击 ×0.5）/ `agility` 灵活（人底 10，+1/次——回合序 `Unit.initiative()`=speed+灵活＋闪避等额；死门 debuff 减半改打它）/ `luck` 运气（人底 5，+1/次——受击压对方暴击等额）/ `resolve` 决心（0，+1/次——初始士气+2/点、士气损失抵消 1/点保底 1）；全入 StatMeta 三白名单
- **种族重基 🔒（§10.6）**：人类 HP 40（鸟妖 35）；atk/acc/eva/crit_rate/格挡/speed 人身底值**全部归 0**（武器承载命中 30 档占位、修正落点承载闪避）；crit_dmg=160 全招式默认
- **自动轨成长 🔒**：races.json `growth` 块（HP+1/级·当前 HP 同补、双强韧+2/级）→ `Unit._apply_level_growth`（gain_exp 内）；**15 级封顶**（LEVEL_CAP，超额经验冻结）；技艺槽改 1/4/7/10/13（`prof_slot_capacity`）
- **加点数据层（战后结算 🔒）**：c 节点（Lv 2/5/8/11/14）每级 `attr_picks` +2；`apply_attr_pick(key)` 按属性各自增量落面板；序列化三层（proto `attr_picks`>0 才写 / battle 快照 / campaign 经 proto）；四选二"同节点不同属性"约束留加点 UI
- **天生武器实装 🔒（§10.4）**：weapons.json `unarmed_fists` 拳脚（innate+natural、atk 2.5/acc 25、tags unarmed/melee/common 无持握）；races.json `natural_weapon` 全族指向；`Unit.ensure_natural_weapon`（生成/卸主手后自动入位）+ `equip_instance` 顶替分档（natural 可顶→`_displace_slot` 销毁实例；锁定 innate 不可顶）+ `unequip(slot, auto_natural)`；`unit_to_proto` 排除 natural；比路兹双爪 acc 各 15（防全局双计）
- **格挡物品化管线 🔒（§10.3）**：`Unit.effective_stat_f` 格挡两键 equip 来源按件聚合取高（`BLOCK_MAX_KEYS`）；**条件 mod 基建** `requires_prof` 字段（`_mod_active`，三循环全接）——武器格挡/`triple_vs` 类条件修正的共用口子；斗盾（15/35 无门槛）现成生效
- 测试：`tools/test_attributes.gd`（种族重基/公式/成长/加点/天生武器/格挡取高/条件 mod/序列化，30 套全绿）
- **技能（熟练度域）子系统**：31 域三页（风格10 / 武器9+2异种 / 生活10）；五阶段 生疏→娴熟→老练→专家→大师（阈值 0/100/300/600/1000·大师计量满值 1500，🟡可调参）＝4 次进阶＝4 次专长选择权（专长内容后置）；前置 `requires{all,any}` 跨页（镰刀=AND、太刀=AND+OR）；派生/异种域阶段浮现（锚＝老练 `REQ_STAGE=3` 🟡）
- **三态**：未学 → 已学（`prof_known`，可装载）→ 装载（`prof_slots`）；熟练度永不丢失（卸下冻结）；一次性学习资格闸门（资格看 xp 不看装载）
- **装载＝总开关**：`prof:<域>` source mods 挂/摘；阶段补正取 `stage_mods` ≤当前阶段的最高一档（不叠加）
- **战斗涨值**：仅装载中可涨；权重 攻击＞格挡＞挨打 🔒、威胁缩放＝等级差线性 🟡、挥空也算练习；行为匹配＝武器/攻击 tags ∩ 域 `match_tags`（一次行为同喂所有匹配域；徒手喂「体术」）
- **BattleIO 回流**：涨值发生在战斗副本 → `apply_result` 回写 xp/known/slots + 按新阶段重挂 `prof:` 补正（唯一回流点；无 prof 字段旧结果安全跳过）
- **三层序列化**：proto `profs` 块（烘焙 force 装载，敌方不走槽位校验 🔒）/ campaign / battle 快照（补正随 modifiers 整份）
- **状态页「技艺」tab（视觉稿 v1，真数据已接）**：顶部 5 装备格＝`prof_slots`（竖向计量槽＝档位内进度·档位色；容量外＝未解锁标 Lv）+ 三级 tab（L2 类型页 / L3 具体域，阶段浮现过滤）+ 右侧「已习得」列（熟练度高→低）；档位名/阈值读 ProfDB 单一源、配色 UI 侧；图标管线＝域 `icon` 字段（res:// 路径即显，🟡素材待画）
- **数据重灌**：原型 four→race / 天性武者等效换算 / 爪类 flat atk 9.5 / 龙枪 res_ice→res_nature / 狼人 pct→flat / maps 8 处嵌入单位同步
