## ✅ 已实现

### 功能
- **Overworld 场景**（M4）：左键=移动指令 → Dijkstra 最小成本路径 → **伪即时行军**（`_process`→`_tick_time` 连续时钟：token 沿段像素插值滑行、地块成本越高过格越慢）→ 落格评估 `enter_tile`（chance/冷却/全局间隔）、跨整点推 `WorldClock`+WorldSim+`timer`（`clock_hours` 恒整数，浮点累加器只驱动插值）。**时钟可播放/暂停 🔒**（空格总开关；播放即流动＝行军 or 原地等待；点目的地=自动播放、抵达/模态事件=自动暂停；战斗仍不耗世界时间。2026-07-08 修订旧「时间仅移动/扎营时流动」→ [meta层需求提炼_1.md](meta层需求提炼_1.md) §1.1 注记）。
- **大世界地块成本（明显档 🔒 2026-07-08，`Overworld.OVERWORLD_COST`）**：拉开地块差令寻路自然、**道路(放置物)恒最优**——草原/荒野/灌木 2、沙/雪/浅水/碎石 3、林/丘 4、山 6；道路 line-feature 经 `_move_cost_between` 的 `min(_,1)=1` 自动最低。`HOURS_PER_COST` 2→**1**（道路 1h/格、平原 2h、山 6h）。**战斗地图不受影响**（战斗走 `TerrainDB.move_cost` 原 `cost`）；未列地形回退地形 `cost`。数值层后调。
- **扎营** +8h（占位）；日夜＝时钟推导 → 顶栏「第 X 天 HH:00·昼/夜」+ EnvDB tint 夜幕叠层。
- **自动存档**：移动完成/扎营/返回菜单 → `auto` 槽。**current 生命周期契约 🔒**：返回主菜单＝退出战役清空 `WorldState.current`（防战役档污染沙盒）。
- **☰ ESC 菜单**（2026-07-12 减顶栏堆积）：ESC 键 / 顶栏 `☰` 同开居中小菜单（⚙ 设置〔复用主菜单 Settings 覆盖层〕/ 💾 存档 / 🚪 返回主菜单）——开菜单即停表、模态事件（对话/待切战斗）中不开（同空格停表规则）；ESC 再按或点外关闭。顶栏原「💾 存档」「返回菜单」两钮收入菜单。
- **战役入口**（StartMenu）：新开局=`WorldState.start_new()`（第 1 天 8 点）→ Overworld；继续=读 `auto` 槽 activate（无档置灰）。
- **schema**：`map_type`(overworld/battle，缺省 battle 旧图兼容) 进 MapIO，编辑器/沙盒透传保真；深水/墙对空 tags 队伍＝天然屏障（`PARTY_TAGS` 预留船/坐骑）；通行成本单一实现 `TerrainDB.move_cost`（与战斗侧共用）；河阻断/桥·路折扣 `_move_cost_between`。
- **编辑器「环境」日夜下拉**：第 0 项「跟随时钟」=不写 `time` 键（运行时按战役时钟推导）；显式昼/夜才落键。
- **WorldSim 动态单位 🟡 v2（2026-07-12 计划移动）**：商队/巡逻/兽群/游团（+雪原匪帮），**时间推进＝世界回合**（移动/原地等待皆推进；budget 累积制，速度=`hours_per_cell`）。四行为 `trade_route`/`patrol`(猎杀 hunts 派系＝d4+power 摩擦战+敌对追击)/`wander`/`hunt`；追上玩家（同/邻格）→`BattleSetup.context{world_unit_uid}`→战胜覆灭/败·弃战=冷静期 12h 占位；一次推进至多一场。**v2 预定行为**：不再一步一决策——巡逻/游荡采样航点（距 home 锚 2..radius）规划整段 `route`（[[c,r],…] 随档）连走，走完在航点歇 `pause_hours`（缺省 2）；商路全程路径缓存（治每步全图 Dijkstra，技改 §2-8 销）；追击按目标格缓存路径（目标动才重规划）；route 失效自动清理重规划、采样失败退回随机邻格旧行为。`Overworld._advance_world`＝推钟→世界回合→表现 统一入口；**滑行队列动画**：`WorldSim.last_trails`（每 tick 实走格序，纯表现静态字典）→ `_wu_anim{pts,t,sps}` 逐格追加，段速＝`TIME_RATE/hours_per_cell×WU_CATCHUP(1.1)` 与逻辑步速匹配＝**连走不顿挫**；积压超 `WU_MAX_QUEUE(4)` 段丢队首快进、传送/重生成直接落位。
- **全局事件池 + 📜面板**（2026-07-08）：`data/events.json`+`EventDB`（跨地图 when/do 事件池，复用触发器 schema、EventEngine 原样消费；id 全局唯一防与图 trigger 串档）——与每图 `triggers` 并行评估：落格 `_check_cell_events` 传该格有效地形 id（`_terrain_id_at`，覆盖只换 move/effects 不换身份）、timer 统一走 `_eval_all_timers`（落格/扎营/休整全口径）；引擎 `enter_tile` 新增 `when.terrain` 地形条件（不传参数=旧行为）。顶栏 **📜 事件** 面板（当前可用 / 完整池+徽章 可用·冷却中·已触发·未到节拍；判定/文案＝`EventEngine.event_status/when_text/gate_text` ④ schema 描述层——闸门单一源 `gate_status`，评估与面板同实现、面板纯消费）。**可禁用事件**（每条 ☑→`WorldState.event_disabled{tid}`、引擎 `_gates_open` 硬闸跳过、随档；徽章增「已禁用」）＋ **⚔ 大地图遭遇战总开关**（`overworld_combat_off`：关＝无派系伏击〔`_hostile_ambush_triggers` 空〕+ 世界单位不 engage 玩家〔`_check_engage_player` 早退〕、且不追击玩家〔`_step_patrol`/`_step_hunt` 追击支路同门控——避免安全模式下敌人堆叠本格 + 复开级联〕，摩擦战照常；随档）。**事件池 11 条**（2026-07-11 波2 扩容）：灵泉驻足/路遇旅人 + 林间采药·浅滩收获·废弃营地（give_item 掉落）/ 路边钱袋·流寇勒索（give_gold ±）/ 行脚商人（dialogue）/ 山巅远眺·丘上瞭望（风味）/ 帝国信使（add_rep）。
- **give_gold 动作 + 讨伐赏金（波2 收入闭环第一环 2026-07-11）**：EventEngine 动作表 +`give_gold{amount 可负}`→宿主原语 `Overworld.event_give_gold`（余额钳 0、💰 随 `_ui_sig` 刷新）；**讨伐赏金**＝开战点把 bounty 解析进 context（游团=`world_units.json` 类型 bounty〔marauders 40/herd 20〕、据点=`locations.json` 类型 bounty〔lair 60/ruin 80〕）→ 胜后 `BattleIO.apply_result` **单点入账并返回入账额** → Sandbox 战报播报「💰 讨伐赏金 +N」。数值全占位、数值轮再调。
- **流寇遭遇图 `maps/bandit_ambush.json`**（2026-07-11）：sandbox 地形为底+流寇敌阵（小卒×2/割喉手×1/头目×1〔elite〕，原型=波2 新增 bandit_* 三兵种）——劫道者所有入口（游团 engage/劫道者营地/ow_ambush 触发器/流寇派系伏击）战斗图统一指向；帝国/野兽/蜥蜴人伏击仍用 sandbox.json（各派系专图待铺）。
- **👥 队伍面板 + 角色状态卡**（2026-07-11 波2 切片首环——大地图看得见自己的人）：顶栏 **👥 队伍** → 花名册逐人行（立绘缩略/名·等级/❤HP〔半血下红〕/🤕重伤徽章），点行 → **UnitStatusPanel 角色状态卡**（与战斗侧同一份：非模态浮卡/ESC 关/`<``>` 翻页）。宿主契约两口（面板 host 鸭子接口）：`board_units()`＝翻页集合（大地图=roster）、`set_viewed_unit`＝棋子高亮（大地图空转）。
- 默认大地图 `maps/overworld/world.json` **v5 40×28**（2026-07-12 换代）：北境雪原/帝国腹地/南野密林/黄沙残境四区（regions 描边＝区域解锁可视化预热）；双城（阿斯特拉/维林——per_city 巡逻自动×2）三村双巢双遗迹；**FantasyHex 风味瓦片转正**（fh_城市/农场/营地/遗迹/野兽/矿点/灵泉/绿洲/台地——`overworld_cost` 已在 terrains.json 补齐 22 条，防「成本 1 寻路磁铁」）；霜河+界河双河三桥、主道贯山口双城+三岔道；3 触发器（劫道者移至南桥头 16,14）。由 `tools/gen_overworld_map.gd` 再生成（**唯一官方再生成路径，勿删**）；⚠ 测试地标同步：test_overworld/test_mapfeatures 顶置 v5 常量、test_worldsim 全动态推导。**老档换图救援**：`_ensure_party_placed` 对越界/站进不可通行格的旧档就地 BFS 最近可走格。

### 代码架构
| 类/文件 | 关键成员 |
|---|---|
| `Overworld.gd` | `_travel`/`_advance_world`(推钟→世界回合→表现)/`_move_cost_between`(河/桥/路)/扎营/声望·职务·地点面板/`_open_party_panel`+`_open_status_panel`(👥 队伍→角色卡，宿主契约 `board_units`/`set_viewed_unit`)/`_toggle_esc_menu`(☰ ESC 菜单：设置/存档/返回主菜单) |
| `OverworldCanvas.gd` (extends HexCanvas) | 队伍金 token+目的地标记+WorldSim token/悬停 |
| `EventDB.gd` + `data/events.json` | 全局事件池注册表（`all_events`/`event`/`reload_data`；`_path_override` 测试缝） |
| `WorldUnitDB.gd` + `data/world_units.json` | 动态单位类型注册表 |
| `WorldSim.gd` | `tick(ws,hours,world)`（宿主鸭子接口，headless 可测）；v2：`_step_planned_idle`/`_chase_step`/`_plan_route`/`_follow_route`（route 计划移动）+ `last_trails`（每 tick 实走格序，宿主动画钩） |
| `WorldState` | `party_col/party_row`(-1=首进 BFS 落位)/`world_units`(实例随档) |
| `tools/gen_overworld_map.gd` | world.json 生成器（道路 overlay+边线河+桥） |
| 测试 | `test_overworld.gd`（寻路/耗时/落位，不碰玩家 auto 档 🔒）/`test_worldsim.gd`（生成幂等/budget/商路/追击闭环/冷静期/摩擦战）/`test_eventdb.gd`（池读取/注入缝/兜底/面板纯逻辑） |
