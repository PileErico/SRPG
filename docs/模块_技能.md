## ✅ 已实现

### 功能

- **能力管线（SkillDB）**：`Unit.skills` 已学态 `{level,cd,uses}`；`learn_skill`（max_level 封顶）/ `skill_ready`（冷却+次数）/ `consume_skill`（进冷却+扣次数）/ `reset_skill_charges`（战斗开始重置）；冷却按本单位 turn −1（`refresh_for_turn`）
- **战斗施放**：选单「技能」子菜单（列已学主动能力；冷却/用尽灰显+数字标剩余冷却）→ `skill_mode` range 圈绿高亮选目标 → `_do_skill` 扣 AP+进冷却+扣本战次数
- **battlefield_heal 战场救治已删 🔒**（2026-07-06 属性重做 §7）：`skills.json`＝`[]`；heal 语义保留，§10 阶段2 重建示例条目做 schema 验收
- **效果注册表（§10 阶段1A ✅）**：效果＝有 id 的 buff/debuff（`effects.json`）；`_add_effect_by_id` 同 id 刷新时长 / `stackable` 叠层≤`max_stacks`；无 id 匿名内联旧路径向后兼容（死门/重伤）；`hot_flat` HoT 回合末回血；`on_expire_apply` 两段式到期连锁（决策20）；`duration` 双形（裸标量 / `{base,per_stat}` 现只读 base，公式待阶段2 `resolve_num`）
- **失能状态机（§10 阶段1B ✅）**：`Unit.has_state(tag)` 扫活跃 effects tags（不污染 permanent tags）；`incapacitated` 回合跳过（不行使 ZOC/借机）；`fort_will`/`fort_body` tag→强韧豁免掷（遭受时+每回合；`duration_model:"resist"` 已可跑）、`ignore_fort` 穿透
- **buff↔modifier 桥**：效果带 `mods` 同挂 `modifiers`（source=`buff:<id>`），到期/清除/重开按 source 摘；防御类 stat（甲抗/格挡/def_eff）可被能力增幅 🔒
- **地基对齐（§10 阶段0 ✅）**：`damage_kind` 正字（element 废弃；`CombatResolver.RES_SUFFIX` 白名单+未知回退物理）；`refresh_for_turn` 改读 `effective_stat("AP_max")`；比路兹恒读主手+`set_airborne` 主副手 uid 对调；golden 伤害基线落地
- **能力三分类 tab 框架**（UnitStatusPanel）：通用（13 通用序列数据驱动）/ 第三页二选一＝具名 `char_*`→专属（占位）· 杂兵→职业＝天赋树（占位）
- **首条效果内容**：bleeding 流血（`fort_body` 归轨 / `dot_pct_max_hp` 5 / 2 回合 / 无视护甲）

### 代码架构

| 类/文件 | 关键成员 |
|---|---|
| `SkillDB.gd` | `get_skill(id)` · `by_seq`(1-13 通用序列) · `all()`；⚠️ 无写盘口（阶段2 补 `save_skill/delete_skill/reload_data`） |
| `EffectDB.gd` | `get_effect` · `all` · `reload_data`（DB 铁律命名）· `_write_array`（整数归一化写盘口）· `_path_override`（测试注入缝） |
| `Unit.gd` | `skills` · `learn_skill` · `skill_ready` · `consume_skill` · `reset_skill_charges` · `skill_uses_max` · `has_state(tag)` · `basic_attack()`/`UNARMED_ATTACK`（BAS 现内联武器 attack dict，阶段3 并入）· `set_airborne` |
| `BattleState.gd` | `_add_effect`（匿名兼容分派）· `_add_effect_by_id`（同 id 刷新/叠层）· `_hang_effect_mods`（桥）· `_eval_effect_duration` · `_cleanse_effects_with_tag` · `_apply_turn_end_effects`（DoT/HoT/到期连锁）· `_try_inflict_state`（强韧豁免）· `_resolve_compute`（damage_kind） |
| `Sandbox.gd` | `_skill_submenu` · `skill_mode`/`_enter_skill_mode` · `_do_skill` · 失能跳回合（`has_state("incapacitated")`） |
| `UnitStatusPanel.gd` | `_build_common_skill_page` · `_build_profession_skill_page`（占位）· `_build_exclusive_skill_page`（占位）· `_has_exclusive_skills`（char_* 前缀判定） |
| `CombatResolver.gd` | `RES_SUFFIX` · `res_suffix(damage_kind)` · `resolve`（分量化减伤链） |
| 数据 | `data/skills.json`（现 `[]`）· `data/effects.json`（bleeding）· `data/tags.json`（`fort_will`/`fort_body`；⚠️ `incapacitated`/`silenced`/`verbal` 未注册＝护栏6 tag 同步纪律余项） |
| 测试 | `tools/test_effect.gd`（叠层/刷新/HoT/连锁/失能/has_state）· `test_effectdb.gd` · `test_data_lint.gd`（引用完整性/形状/禁键/阶段护栏机械执法）· `test_basic_attack.gd`（比路兹主副手）· `test_combat_golden.gd`（伤害 golden）· `test_bleed_inflict.gd` |
