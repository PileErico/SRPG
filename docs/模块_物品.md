## ✅ 已实现

### 功能

**模板层（ItemDB，纯模板源）**
- 四文件路由（`kind_of`：显式 `kind` 字段优先 → 否则按 `slot` 推）：weapon→`data/weapons.json`、armor→`data/armor.json`、accessory→`data/accessories.json`、**item（消耗品/任务物品/素材/食物/医疗物品）→`data/items.json`**（非装备类无 slot、写显式 `kind:"item"`；后三者首次存该类才生成文件）。
- `save_item(item, replace_id?)`：按 id upsert；改 id 传旧 id＝旧条目全文件移除（改名≠复制）；换类别（slot 改）清其它文件同 id；写盘失败传导 false。
- 落盘＝`res://data/` 🔒；整数归一化 `_intify`（1.0→1，防 diff 噪音）；测试注入缝 `_paths_override`（headless 重定向 user://，不碰真数据）。
- ⚠️ DB 铁律：刷新叫 `reload_data` 不叫 `reload`（外部 `XxxDB.reload()` 命中原生 `Script.reload()`＝静态全重置）。

**实例层（ItemInstances，静态门面）**
- 实例形：`{uid:int, tpl_id, affixes:[], durability:int(-1=未启用), condition:String(""=无), enhance_count:int}`。
- uid 主键＝`WorldState.mint_uid`（unit/item 共用存档域计数器 🔒）；撞号防御＝跳号不覆盖。
- 库归属 🔒：数据在 `WorldState.current.item_instances`；current==null（沙盒）→ `_transient` 临时库（不落盘、uid 域隔离）；换档＝换 current，无全局副作用。
- `view(iuid)` 合成视图＝**战斗/UI 唯一消费口**：模板深拷 ⊕ 词条并入 mods（每条打 `affix` 名标记）⊕ 实例字段。
- 模板热改语义 🔒：view 实时读模板；已装单位修正是装备时**烘焙**的——运行期不重挂、读档/重新装备按新模板生效；删模板前确认无实例引用（否则 view→null）。
- 三雷已排 🔒：① get_item 共享引用污染→view 深拷；② 双手字符串配对误伤→uid 配对；③ 同 source 去重吃词条→每条 mod 唯一 source。
- 存档 GC：只导出 roster 可达实例（防孤儿膨胀）；`from_dict` 计数器自愈（next_uid≥存量 max+1）。
- 收编迁移：`WorldState.add_to_roster` 自动把沙盒域装备迁进档内库（`take_transient` 迁库+重铸 uid+修正 source 重写）。
- `destroy(iuid)`：⚠️ 调用方须保证无单位在穿（否则烘焙修正残留+equipment 悬空）。

**装备资格（EquipSlots + Unit）**
- 槽位×tag 模型 🔒：`main_hand`/`off_hand` 等＝**槽位、非物品 tag**；资格 tag＝`one_handed`/`two_handed`/`shield`/`head`/`body`/`accessory`；位置类效果按【槽位占用】判（读 `equipment["off_hand"]`）、不靠 tag。
- `accepts(slot,item)`：main_hand=单/双手；off_hand=单手/盾；head/body/accessory=对应 tag；`innate` 天生豁免（按 slot 字段放置、永不卸下）；无资格 tag 旧物品回退比 slot 字段。
- `Unit.can_equip`/`can_equip_in(item,slot)`（UI 校验）+ `equip(id, target_slot?)`（造新实例便捷口）/`equip_instance(iuid, target_slot?)`（读档重挂/背包·铁匠路径）——可选目标槽＝单手进副手双持；空＝旧行为零改动。
- 双手占两槽按 uid 配对；`requires` tag 门槛（装备者须全部具备）；修正 source=`equip:<iuid>:<n>` 每条唯一，卸装 `remove_modifiers_by_source_prefix("equip:<iuid>")` 前缀全摘。

**编辑器（ItemEditor，StartMenu 独立入口）**
- 左栏分类清单：武器/防具/饰品/**物品**四折叠组＋类型→种类排序插分隔标签＋行卡片（图标·名〔稀有度色〕/id）＋搜索·计数·选中金框·记折叠态。搜索匹配 id/名字/**tags**（提案§22 2026-07-13：tag 英文 id 与 `TagDB.cn` 中文名双向可中——输「melee」或「近战」都过滤到，`_search_match`）。
- tag 级联：武器【类型】单选互斥→级联【种类】可选项（投掷无种类、盾不显握持）；防具＝部位+轻中重；自由 tag 下拉按语境过滤（`NON_ITEM_CATS` 全排——含 `skill_weapon`/`biotype`〔技能/单位词表非物品，用户校准 2026-07-13〕、需求只给 `REQUIRE_CATS`、攻击只给 `ATTACK_CATS`）。
- **武器固有属性 🔒（决策33 + 三轮校准 2026-07-13，真值→[模块_技能_设计.md](模块_技能_设计.md)「决策33」节）**：`atk/block_rate/block_power` 三项必填顶层字段（0=无此项；格挡两项百分比）——表单固定三行 spin，非 mods；**命中不在此列**（基准命中=武器技能 hit〔决策32〕、物品侧命中=普通 acc mod，编辑器随存清旧 acc 键）；装备时 `Unit._apply_item_mods` 折 equip 源修正（source=`equip:<uid>:i_<key>`）。mods 表单＝**额外**修正（词条/附魔）＝`STAT_GROUPS`（进攻/生存/人抗/甲抗/固减/行动；**无强韧——禁键 🔒**）；视觉状态 mod（nightvision/blind，非数值、走 `Unit.has_vision_state`）。
- **On-Hit 板块 🔒（决策33；二轮校准：甲伤同族）**：`armor_dmg` 甲伤%（对护甲额外伤害——不论用什么技能挥舞都破坏护甲；0=无）+ `on_hit_effects: [{effect, chance}]` 行编辑（EffectDB 下拉+概率%）——武器普攻/武器技能/借机命中都触发，与技能攻击块 `inflict` 叠加（技能施加=用这招才有；武器施加=持械全招触发）。
- **武器技能下拉一视同仁**（2026-07-13 用户校准）：BWS/EWS 两下拉同源清单＝勾选 weapon_skill ∧ `weapon_kinds` 种类匹配（`_ws_option_ids`；kinds 空=通用），EWS 位排掉当前 BWS 所选；主动/可跑块闸撤除（攻击形 EWS 可入库，施放=阶段6 战斗菜单灰显）。
- 预览列＝ItemTooltip 即时渲染；未保存守卫/Ctrl+S/另存副本/改名走 replace_id。
- UI chrome 退栈公共层 `EditorUI`+`EditorTheme`（与地图/角色编辑器共用）。
- **物品大类下拉**（`KIND_PAIRS`，基础区 id 上方：武器/防具/饰品/物品）＝ kind 选择器,替掉旧的 4 个「＋类别」按钮;改选即 `_on_kind_changed` 换 kind、按新骨架重建表单(保留 id/名/图标)。左栏新建收成单个「＋新建」。
- **BWS/EWS 引用位「↗」跳转**（提案§26 2026-07-13）：BWS 下拉与每条 EWS 技能位旁「↗」钮（`_skill_jump_btn` 共用工厂）→ 脏守卫先行 → 跳技能编辑器并定位该条目。机制＝静态传参（SandboxConfig.battle_setup 同型先例）：写 `SkillEditor._open_with_id` 再 `change_scene_to_file`，SkillEditor `_ready` 消费即清（悬空 id＝报错不载入）；同款口子 `EffectEditor._open_with_id` 已通——SkillEditor apply_effect 块效果引用位也带「↗」跳效果库。
- **desc 风味文本字段**（提案§33 2026-07-13）：weapons/armor/accessories/items 四 schema 通用**可选键**（空串保存不落键、读端 `.get` 兜底——旧数据零迁移）；表单基础区多行 TextEdit（随大类切换携带，同 id/名/图标语义）；tooltip 置底渲染（见下）。⚠ 只开能力，数据内容未填。
- **物品（非装备类）授权**（`_build_item_form`/`_collect_item`）：标签区＝稀有度 + ☑可使用（=`usable` tag，**门控 on_use**）+ ☑任务物品（=`quest_item`）+ 自由标签区（食物/医疗/素材…可叠、手动置入）。勾「可使用」才显 on_use 段：使用设置（作用对象 target〔友方/敌对/自身；敌对=投掷类〕/使用距离 range〔≠自身时显，`_update_range_visible`〕/可叠加 stack）+ **动态效果行**（仿武器 mods 的「＋添加使用效果」：`_add_ou_row` 效果类型下拉〔`OU_EFFECTS`：回血%/回血固定/回疲劳%〕＋数值＋✕删除，collect 从 `_ou_rows` 组装成 `on_use` 字典）。可使用＝战斗/大地图皆可（**无 use_scope**）。无装备槽/mods/BAS。使用机制（消耗→施 on_use）＋队伍背包＝后续切片。

**tooltip（ItemTooltip，共用渲染）**
- 游戏内（UnitStatusPanel）与编辑器共用一份 `render(item)`：稀有度边框/名色＝`TagDB.color`、tag→`TagDB.cn`、stat→`StatMeta.label`、图标→`TextureCache`；含种类·部位/标签/需求/**固有属性行（攻/命中/格挡×2/甲伤，决策33）**/mods/**击中施加行（on_hit_effects）**/攻击 skill 块（含命中/伤害属性/伤害类型/穿甲行）。
- `mod_line`：±值绿/红、pct 语义键自动 `%`；**词条来源行尾注〔词条名〕**（读 mod["affix"] 标记）；vision_state 显状态名（蓝）。
- **desc 风味文本区**（提案§33）：`desc` 键非空时置底渲染（RPG tooltip 惯例位，HSeparator 分隔）——斜体灰（`_desc_label`：FontVariation 仿斜、参数同引擎默认主题 italics_font，CJK 实测生效）+ 自动换行。

**装备穿卸交互 + 角色背包（2026-07-12 用户实装令）**
- **角色背包**＝`Unit.bag`（装备实例 uid 列表，上限 `Unit.BAG_CAP=8`＝状态页可用格单源；区别于队伍背包 inventory 的消耗品计数模型）。序列化三层全通：proto 存模板 id（`"bag"`，空不写）/ campaign 存 `bag_uids` 引用 / 战斗快照整份（护栏#3 白名单）；`remap_equip_uid`/`_adopt_equipment` 收编重铸含 bag。
- **模型 API**（Unit）：`unequip_to_bag(slot)`（innate 拒/包满拒/拳脚回位）、`equip_from_bag(iuid, target_slot)`（全套资格闸；**被顶旧件自动落包**——`_displace_slot`「将来进背包」兑现，顶替爆包预检拒）、`transfer_hand(from,to)`（单手武器主↔副：目标被占＝互换、拳脚被顶＝收回销毁、腾空主手拳脚回位；直接对调 equipment 不重挂修正——比路兹起降同族手法）。
- **状态页交互**（UnitStatusPanel，`equip_interact` 开关＝Sandbox/Overworld 游戏内开、editor_mode 旧路不动，仅 player 阵营生效）：**交互分工 🔒（用户 2026-07-12）＝左键拖拽、右键菜单**（菜单挂左键会抢输入、拖拽启动不了——踩过）。右键装备槽 → 菜单〔卸下（包满灰显）/转移到副手·主手〕；右键背包件 → 菜单〔装备/装备到副手〕；左键**拖拽**同语义（装备槽↔背包、主手↔副手），ItemSlot 通用拖拽管道（`drag_payload`/`can_drop`/`on_drop`——策略全在面板）＋**拖拽中可落靶绿框高亮**（DRAG_BEGIN/END 通知、逐槽 can_drop 判定）。背包格游戏内显示实例（稀有度边框+富 tooltip 与装备槽同款）。
- **战斗内费用 🔒（用户 2026-07-12）**：装备/卸下/换手各 **1 AP**——`Sandbox._equip_gate(u, commit)` 费用闸（布置期/战后免费；战斗中仅当前行动者且 AP≥1，扣费+日志「整备装备」）；资格不满足＝菜单灰显提示、拖放静默拒。大地图（Overworld 角色卡）免费。
- 顺手修真 bug：`unit_from_campaign` 重挂装备原不传槽位 → 换手/副手装备读档会回跳默认槽——已改按存档槽位重挂。

**队伍背包（inventory，消耗品/素材）**
- 计数模型 🔒＝`WorldState.inventory {tpl_id: count(int)}`（可堆叠；品质＝分档 id；**不进 ItemInstances**——实例库只装带个体状态的装备）；随档序列化往返（`_int_valued`＋`.get` 零迁移）；助手 `inv_add`/`inv_remove`/`inv_count`（扣到 0 抹键）。
- 入库口＝EventEngine `give_item` 动作＋宿主原语 `event_give_item`（Overworld 落 `inv_add`＋log；事件「装水得道具」/烹饪食材获取共用挂点）。
- Overworld 顶栏 **🎒 背包** 面板：列 名×数量＋效果摘要；战外可用回血消耗品（`usable` ∧ 非敌对 ∧ on_use 含回血）出「使用」→选花名册成员→施 on_use 回血（回疲劳待疲劳系统、暂跳过）→扣一件。**战斗内使用（回合动作/目标选取/使用距离/敌对投掷/AOE）＝后续切片**（需战斗 UI 设计）。
