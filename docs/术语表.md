## 属性 / 抗性键

- 面板：`HP_max` `atk` `acc` `eva` `crit_rate` `crit_dmg`(160=×1.6) `block_rate` `block_power` `AP_max` `move` `speed` `sight` `armor_max`
- 效能桶(base 100=中性)：`atk_eff` `def_eff`；`hit_eff` `eva_eff`(mod-only)
- 人抗 `res_phys`/`res_nature`(%减伤) · 甲抗 `armor_res_phys`/`armor_res_nature`(默认0，无甲=无) · 强韧 `will_fort`/`body_fort`(豁免率%，永不入物品)
- 固减 `dr_flat_human`/`dr_flat_armor`(最后减，底0)
- `damage_kind`：physical/fire/ice/thunder/holy → 归轨 physical→phys，其余(含holy)→nature（`CombatResolver.RES_SUFFIX`）

## 战斗公式（当前）

修正三层 / 有效值（`Unit.effective_stat_f` L129）：
```
有效值 = 面板 + Σflat + 面板 × Σpct/100      同source同(stat,op)取高，异source累加
eff_mult(b) = max(0, 面板b/100 或 1) × Π(1+各源%/100)   同源取高，因子≥0   (L156)
eff_reduce(b) = Π(1−各源%/100)                          同源取高，因子≥0   (L172)
```

命中（`BattleState` L426）：
```
命中率 = clamp( (命中调整−闪避调整) × eff_mult(hit_eff) × eff_reduce(eva_eff) × 地块因子 , 5, 95 )
```

判定序 命中→格挡→暴击：格挡 roll<block_rate→注入 block_power(全域%减伤，招架取高)；暴击 roll<crit_rate→cmult=crit_dmg/100(多源加算，未暴=1)。

输出伤害（`BattleState` L459）：
```
输出 = effective_stat_f("atk") × coeff × cmult × aeff   (+ 伤害补正flat，不吃效能)
coeff=技能系数(普攻≈1,AoE<1)   aeff = eff_mult("atk_eff") × 攻方地块攻击效能
```

减伤链 全乘算（`CombatResolver.resolve`）：
```
G = max(0, 1−block_power/100) × def_factor           整击一次
def_factor = max(0, 2−def_eff/100) × 守方地块防御效能
抗因子 = max(0, 1−抗/100)                             抗>100→0免疫；<0→>1放大

非穿甲→先进甲：
  到甲 = max(0, 输出×ratio×G×甲抗因子 − 甲固减)
  ≤池: 池−=到甲   破甲: 溢出=到甲−池;池=0; 到血=max(0, 溢出×人抗因子 − 人固减)
穿甲(p)：人部分=输出×p→到血=max(0,人部分×G×人抗因子−人固减)；甲部分=输出×(1−p)走上
无甲：到血 = max(0, 输出×G×人抗因子 − 人固减)
```

异常施加 + 强韧豁免（`BattleState._try_inflict_state` L528）：
```
applied = randf×100 < inflict.chance
效果带 fort_will/fort_body → fort=对应强韧值; fort_roll=randf×100; shrugged = fort_roll < fort
净施加 = applied 且 未shrugged        豁免时机：遭受时1次 + 每回合开始1次；ignore_fort 跳过
```

死门（`Sandbox._door_turn_check` / `Checks.check_flat`）：
```
1d20 + 求生 vs DC     求生=5+floor(body_fort/5)   DC=15/20/25…(每回合+5)
过+1/不过−1；被命中−1   门条−3~+3：−3倒下(铁人真死/否则重伤离场)，+3爬回(HP保底1)
```
