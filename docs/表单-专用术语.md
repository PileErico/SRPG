## 概念 ↔ 代码符号

| 概念 | 代码符号 |

| 种族底值 | `RaceDB` `data/races.json`(human/lizardmen/harpy) `Unit.race_id` |

| 效果 buff/debuff | `EffectDB` `data/effects.json` `Unit.effects`；`fort_will/fort_body` tag→强韧豁免 |

| 派系 | `FactionDB` `data/factions.json` `camp_*` tag（≠阵营立场 player/ally/enemy/neutral）|

| stat 键→标签/白名单 | `StatMeta`（`LABELS`/`SERIALIZABLE_BASE_STATS`/`EDITOR_STATS`/`ITEM_FORBIDDEN_STATS`）|
| 修正 modifier | `Unit.modifiers`；source 前缀 `trait`/`equip:<iuid>:<idx>`/`buff:<id>`/`prof:<域>`/`env:*` |
| 天生武器/徒手 | 拳脚＝weapons.json 条目(待建，tags `unarmed`/`melee`/`common`＋innate、无持握 tag)；**实装占主手·可替换**（被顶替/空位回位）；`races.json natural_weapon`(待建)；锁定型=比路兹爪·默认型=拳（§10.4）|
| 技能类别 `category` | skill（技巧）/ spell（魔法，后置）——⚠ 2026-07-13 改词：旧键 `nature` 废（与修正对象的 nature〔buff/debuff〕分家），lint 禁回流 |
| **武器技能（WS）**＝BWS / EWS | 家族统称武器技能、词缀统一 `ws` 🔒；**身份＝显式勾选 `weapon_skill`**（🔒 决策29 2026-07-13，翻案决策27 形状判定/`is_ws_shaped` 已删）＋`weapon_kinds` 适用武器种类（wcat tag 多选）＋动态 tag（占位 skill_weapon、被引用武器解析 skill_<种类>）；BWS＝普攻位(键 `bws`，装备即用；⚠ 普攻路径不结算冷却/次数/等级) / EWS＝额外技能位(武器域熟练度解锁，键 `ews`)——**引用位之分在武器侧配置时决定**；武器＝技能库纯引用，专属技能＝独立条目（决25/26/29）|
| d20 检定 | `Checks`（`check(unit,attr,dc)` / `check_flat(bonus,dc)`）|
| 伤害结算 | `CombatResolver` |

## 属性 / 抗性键

- 面板：`HP_max` `atk` `acc` `eva` `crit_rate` `crit_dmg`(160=×1.6) `block_rate` `block_power` `AP_max` `move` `speed` `sight` `armor_max`
- 格挡 🔒（§10.3＋决策31 已实装）：`block_rate`/`block_power` 人底0＝物品承载——盾天生激活（恒计）；手持武器（物品 slot=main/off_hand）的格挡属性**默认休眠**、须能力键 `weapon_block`≥1 激活（`Unit._block_source_active` 来源过滤）；防具/饰品与非装备来源恒计；装备来源按件取高，buff/perk 叠加其上
- 能力键 stat 🔒（决策31，0/1 语义、perk 经被动桥 `passive_stat_mods` 走修正管线授予）：`offhand_ws` 副手武技（≥1＝副手位武器技能一律按 EWS 论，`Unit.can_use_offhand_ws`）· `dual_strike` 双武连携（普攻两段，`Unit.dual_strike_active`）· `weapon_block` 武器格挡激活
- 四属性 🔒（§10.6 终表 2026-07-08，每点效果）：技巧 `finesse` 1命中+0.5%暴击 · 灵活 `agility` 1闪避+0.5先攻(floor) · 运气 `luck` −1被暴击+0.5%爆伤(另全d20检定补正) · 决心 `resolve` 1初始士气+0.5损失抵抗(floor保底1)；底值（人/鸟/蜥）技巧 10/12/8·灵活 10/14/6·运气 5/3/3·决心 0/0/4；加点 9 节点 18 点可同投（`Unit.attr_picks`/`apply_attr_pick`）
- 等级 🔒（二次修订＝20级制）：LEVEL_CAP=20；技艺槽 1/4/8/11/16；自动轨 growth 数组循环（人 HP[1,0]→50·双韧+2/+2｜鸟 HP[1,0,0]→41·意+2·肉+1｜蜥 HP[1,2]→73·意+1·肉底5+2；HP 底 40/35/45）；一切结算在战后
- 条件移动力 🔒（2026-07-08）：`move_allowance(tile_tags)` 读 races `move_overrides`——命中替换基础值+修正差量照叠；移动底值 人4/鸟4(flying→6)/蜥3(water→4)；〈水生动物〉`aquatic`＝蜥蜴人常驻（深水可入、深/浅水恒1）
- 天生武器 🔒（§10.4 已实装）：`unarmed_fists` 拳脚(innate+natural,atk2.5/acc25)；races `natural_weapon`；`ensure_natural_weapon`/`_displace_slot`/`unequip(slot,auto_natural)`；natural 可被顶替·销毁重造、不入 proto；锁定 innate(比路兹爪)不可顶
- 条件 mod 🔒（§10.3 已实装）：修正带 `requires_prof:"<域id>"` → 须装载才生效(`Unit._mod_active`)；格挡两键 equip 来源按件聚合取高(`BLOCK_MAX_KEYS`)
- 自动轨 🔒（§10.6）：HP 种族成长曲线(基准拟抬40量级) + 双强韧全种族固定每级；速度不随级
- 士气 🔒（§10.7；骨架已实装 2026-07-07＝`Unit.morale`+`BattleState._morale_add/_morale_turn_tick`，档位战斗判定未接）：0~50 五档 崩溃0~9/动摇10~19/稳定20~29/高昂30~39/狂热40~50（每10一档·各配图标），初始25+2×决心，无溃逃；事件 命中+2/失手−1/击杀+3/友军死亡−5/邻近差/回归±1；档效 ±5/10% 命中·伤害 ✅ 2026-07-08 接线（`morale_combat_mod`）
- 死门 🔒（§10.6）：`1d20+运气+肉体强韧/5` vs DC 5/10/15/20/25 逐轮递增（旧 5+body_fort/5 退役）
- crit 🔒（§10.6 二次修订）：无人身底率——暴击率=招式+技巧×0.5−对方运气；爆伤=`crit_dmg`(**120**=全招式默认，原160作废)+运气×0.5
- 效能桶(base 100=中性)：`atk_eff` `def_eff`；`hit_eff` `eva_eff`(mod-only)
- 人抗 `res_phys`/`res_nature`(%减伤) · 甲抗 `armor_res_phys`/`armor_res_nature`(默认0，无甲=无) · 强韧 `will_fort`/`body_fort`(豁免率%，永不入物品)
- 固减 `dr_flat_human`/`dr_flat_armor`(最后减，底0)
- **伤害属性** `damage_category`（原 `damage_kind` 已改词 2026-07-13 禁回流）：大类 physical/fire/ice/thunder/holy → 归轨 physical→phys，其余(含holy)→nature（`CombatResolver.RES_SUFFIX`）
- **伤害类型** `damage_type`（创伤，2026-07-13 新增·从技能 tags 迁入攻击块字段）：slashing 斩击/piercing 穿刺/bludgeoning 打击（词表＝tags.json cat damage；引擎暂不消费＝内容层挂点）
- 攻击块 hit 键（2026-07-13 定序）：`coeff` 伤害系数（＋属性修正 per_stat 独立行）· `hit` 命中系数%（决策32，缺省0、可负/可破100）· `damage_category`/`damage_type` · `armor_pen` 破甲（**0~1 小数**，0.3=30% 直击人体、1=无视护甲）· `sure_hit` 必中（跳过命中对抗）· `inflict` 命中施加 {effect,chance}
- **异常优先级 🔒（决策34）**：效果键 `priority`（缺省0不落键）——同族（共享 cat=effect 异常 tag）异 id 恒高者起效（单击低者不掷、跨击高顶低/低被压）；**同 id 单击多来源＝概率取高只掷一次**；同族禁同级（lint 规则12）
- **武器固有属性 🔒（决策33·三轮校准）**：`atk/block_rate/block_power` 三项武器条目顶层必填字段（0=无；格挡两项%）——非 mods；**命中不属武器固有**（基准命中=武器技能 hit、物品侧命中=acc mod）；装备折 equip 源修正（source=`equip:<uid>:i_<key>`）。**On-Hit 族**＝`armor_dmg` 甲伤%（对护甲额外伤害、只放大啃甲——任意招式都触发，二轮校准归此族；编辑器可选行 2026-07-15）+`on_hit_effects: [{effect,chance}]` 击中施加（普攻/武器技能/借机都触发）。⚠ **键级统一（2026-07-15）**：技能攻击块旧键 `inflict` → 同形 `on_hit_effects` 数组（双读+随存即迁+lint 禁回流；结果单列 `r["on_hit"]`）；效果库键 `on_hit_ok`＝可作 On-Hit 引用白名单（缺省不可）
- **兼用武器 / 有效握持 🔒（决策35）**：持握 tag `versatile`（兼用）——占槽全套单手行为，单/双手＝动态状态（判据＝另一手是否空置，拳脚视同空手；读口 `Unit.effective_grip(slot)`）；武器子键 `one_handed:{atk,block_rate,block_power}`＝单手形态面板（顶层三键＝双手形态；source `i_`/`i1_` 门控放行）；技能可选键 `grip`（one_handed/two_handed）＝**运行时可用性条件**（非解锁；菜单灰显「需单/双手持」；BWS 禁带）；副手无额外惩罚（只走 offhand_eff）
